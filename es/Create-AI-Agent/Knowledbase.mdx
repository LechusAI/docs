## Para qué sirve la Base de conocimiento

La **Base de conocimiento** es el lugar donde guardas información que tus agentes de IA pueden usar durante las conversaciones, para que no dependan solo del prompt principal. Es ideal para contenido largo o detallado, como manuales, preguntas frecuentes o políticas, que no cabe en el prompt.

Casos de uso habituales:

- Responder preguntas sobre tu negocio (servicios, precios, políticas, horarios).
- Guiar a los usuarios en procesos (pasos para un reembolso, preparación de una cita, alta de cliente).
- Mantener respuestas coherentes entre varios agentes.

Accede aquí: [Base de conocimiento](https://app.callin.io/knowledge-base)

La página tiene dos pestañas, arriba a la derecha:

- **Archivos**: documentos que subes (PDF, DOC, DOCX, TXT), organizados en grupos.
- **Web**: páginas web (URLs) de las que aprende el agente, que puedes organizar en carpetas.

> **Consejo:** Piensa en la Base de conocimiento como “material de referencia aprobado” que el agente puede consultar cuando una persona hace preguntas detalladas.

## Cómo se conecta con los agentes de IA

El contenido no se añade directamente dentro de un agente. En su lugar:

1. Creas el contenido aquí, en la Base de conocimiento (archivos o URLs web).
2. Después, en el editor del agente, abres la pestaña **Base de conocimiento** y **añades los documentos** que quieres que use ese agente.

Un mismo documento lo pueden usar varios agentes.

## Base de conocimiento con archivos

La pestaña **Archivos** sirve para subir documentos de los que debe aprender tu agente (por ejemplo: una política en PDF, un guion en DOCX o unas preguntas frecuentes en TXT). Los archivos se organizan en **grupos**, para mantener juntos los documentos relacionados.

Junto a **Crear base de conocimiento** puedes cambiar entre dos vistas: una **lista** con todos tus archivos o tus **grupos** mostrados como carpetas. Usa **Buscar archivos...** para encontrar un documento.

### Crear un grupo de archivos y subir documentos

1. Abre la pestaña **Archivos**.
2. Haz clic en **Crear base de conocimiento**.
3. En la ventana **Subir archivos**, escribe un **Nombre del grupo** (obligatorio). Los archivos que subas quedarán agrupados con ese nombre.
4. Añade tus documentos:
   - Arrastra y suelta los archivos en la zona de subida, o
   - Haz clic en **Seleccionar archivos** para buscarlos.
5. Haz clic en **Subir archivos** para terminar.

Formatos y límites admitidos (según el cargador):

- PDF, DOC, DOCX, TXT
- Máximo 5MB por archivo

> **Error común:** Subir documentos no relacionados dentro del mismo grupo. Si tienes casos de uso diferentes (Ventas vs. Soporte), crea grupos separados para asignar el conocimiento correcto a cada agente.

### Administrar y actualizar archivos en un grupo

Cuando ya existe un grupo, puedes abrirlo para gestionar lo que contiene:

- Añadir más documentos.
- Ver la lista de **Archivos actuales** que ya incluye.
- Quitar los archivos que ya no quieres que consulte el agente.

> **Consejo:** Usa nombres de grupo claros como **“Políticas de soporte”**, **“Precios y planes”** o **“Guion de admisión de clínica”** para que sea fácil encontrar los documentos correctos más adelante.

## Base de conocimiento con URLs web

La pestaña **Web** sirve para que tu agente aprenda de páginas web. Es útil cuando tu información de referencia está en tu sitio web (centro de ayuda, documentación, páginas de políticas, landing pages).

La lista muestra cada URL con su **Nombre**, su dirección y su **Última actualización**. Usa **Buscar en la base de conocimiento...** para encontrar una.

### Agregar una URL

1. Abre la pestaña **Web**.
2. Haz clic en **Agregar URL**.
3. Rellena:
   - **Carpeta superior**: dónde guardarla. Por defecto, **Base de conocimiento (nivel superior)**.
   - **Título** (obligatorio): un nombre claro para esta página (por ejemplo, “Página de precios”).
   - **URL** (obligatoria): el enlace a la página web.
4. (Opcional) Activa la **Actualización automática** para que Callin vuelva a leer la página cada cierto tiempo. Después elige el **Intervalo** y la **Unidad de intervalo** (**Días** u **Horas**). Por defecto, cada **7 días**.
5. Haz clic en **Agregar URL** para guardarla.

### Organizar las URLs en carpetas

Para mantener juntas las páginas relacionadas (por ejemplo, todas las páginas de tu web), haz clic en **Crear carpeta**:

1. Elige la **Carpeta superior** (o deja **Base de conocimiento (nivel superior)**).
2. Escribe el **Nombre de la carpeta** (obligatorio).
3. (Opcional) Activa la **Actualización automática** para actualizar todas las URLs de la carpeta con el intervalo que elijas.
4. Haz clic en **Crear carpeta**.

Después, al agregar una URL, elige esa carpeta en **Carpeta superior**.

> **Consejo:** Mantén las carpetas enfocadas. Por ejemplo, una carpeta para las páginas de **“Precios y facturación”** y otra distinta para las de **“Política de reembolsos”**.

### Ver, actualizar o eliminar una URL

Haz clic en **⋯**, a la derecha de una URL, para abrir su menú:

- **Ver detalles**: abre un panel con el **ID de documento**, la **Última actualización**, el **Tamaño del documento**, la **URL de origen** y la **Actualización automática**, y a la derecha el **Contenido de la URL** (el texto que tu agente lee realmente de esa página). Haz clic en **Actualizar contenido** para volver a leer la página en ese momento.
- **Copiar ID**: copia el ID del documento.
- **Eliminar**: quita la URL de la Base de conocimiento.

## Seleccionar una Base de conocimiento para un agente

Cuando ya tienes tus documentos (archivos o URLs web), los asignas a un agente desde el editor del agente.

### Asignar un grupo a un agente

1. Ve a **Agentes de IA** y abre un agente para editarlo.
2. Abre la pestaña **Base de conocimiento**.
3. Haz clic en **Añadir documento**.
4. Usa **Buscar documentos...** para encontrar el documento que quieres y haz clic en él para añadirlo al agente.
5. Repite el paso para cada documento que necesite el agente.

Si el documento que necesitas todavía no existe, haz clic en **Añadir documento** al final de la lista. Te lleva a la página **Base de conocimiento** para crearlo.

> **Consejo:** Si tienes varios agentes con roles distintos, dale a cada uno solo los documentos que necesita, para que se mantengan enfocados y no respondan fuera de su alcance.

## Ejemplo práctico

Imagina que tienes una clínica dental y dos agentes:

- **Agente de recepción** (citas, horario, cómo llegar)
- **Agente de facturación** (precios, facturas, preguntas sobre seguros)

Una buena configuración sería:

- Grupo de archivos: **“Preguntas frecuentes de la clínica (TXT)”** para respuestas rápidas y guiones
- Carpeta web: **“Páginas de precios y seguros”** con las páginas públicas de tu web, con la **Actualización automática** activada

Así:

- El **Agente de recepción** recibe los documentos de preguntas frecuentes.
- El **Agente de facturación** recibe las páginas de precios y seguros.
