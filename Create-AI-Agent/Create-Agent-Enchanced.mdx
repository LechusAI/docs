## Before You Begin

**An agent** can handle complex flows: nuanced intent, long instructions, accurate data capture, and **inbound**, **outbound**, or **both** call directions.

If you only need greetings, **simple FAQs**, or **basic data capture** at low cost, a **Basic** agent is enough.

**External actions (set up separately, then link):**

- **Scheduling:** Google Calendar
- **Transfers:** Call Transfer

---

## Step 1. Create the agent

Go to **AI Agents** → **Create Agent** → **Start from Scratch**, enter a clear name (for example: **“Support EN – Sales”**), select the appropriate **Version**, and click **Create Agent**.

Recommendation: name agents by **function + language** to avoid confusion later.

---

## Step 2. Choose call direction: Inbound, Outbound, or Both

In **Agent** → **Call Direction**, pick what mirrors your operation:

**Inbound:** the agent receives calls. Use for support desks, reception, service lines.\
Tip: enable **Transfer Call** to escalate when needed.

**Outbound:** the agent initiates calls. Use for reminders, confirmations, surveys, collections.\
Tip: keep scripts short and set **allowed hours**.

**Both Directions:** one agent for inbound and outbound.\
Use when tone and logic are shared; it requires more testing to avoid mixed goals.

**Also set:**

- **Maximum Call Duration (minutes):** auto-hang threshold (for example, 10).
- **Greeting Message:** the first thing the caller hears.

**Greeting example (EN):**\
Hi, this is {agent_name}. How can I help you today? This call may be recorded for quality purposes.

---

## Step 3. Voice, language, and Temperature

In **Voice & Language**:

- **Language / Secondary Language:** set a primary language and add a secondary only if needed.
- **Voice:** choose a tone/accent that fits your brand.
- **Speed:** start at **Normal**, then tune after testing.
- **Temperature:** controls creativity.

**Quick Temperature guidance:**

- **0.2–0.5:** more deterministic (best for booking/compliance).
- **0.6–0.8:** more conversational (FAQs, sales).

Use **Test Call** to listen and adjust.

---

## Step 4. LLM: what it is and how to choose

**What it is:** the LLM (Large Language Model) is the “brain” that understands and generates responses. You can choose a provider/model to balance **accuracy**, **latency**, and **cost**.

**How to choose (quick rule):**

- **Short/simple flows** (triage, FAQs): fast/low-cost model.
- **Multi-step flows** and **data extraction**: balanced model.
- **Long**, **multilingual**, **high-precision** tasks: advanced model.

**Signals to adjust:**

- Vague or inconsistent answers: move up a tier.
- Solid answers but too slow/expensive: move down a tier.

For booking and forms, pair a stable LLM with **low Temperature**.

Important: set the agent **Timezone** to match your customers or the calendar to prevent wrong-hour bookings.

---

## Step 5. Conversation Prompt (operating script)

Define the agent’s **goals**, **tone**, and **rules**.

**Goal:**

1. Warm greeting and identify the reason in 1–2 questions.
2. Resolve or route: schedule, transfer, or send a summary.
3. Confirm critical details: name, phone, date/time.

**Style:**

- Plain, empathetic, no jargon.
- Summarize next steps before closing.

**Rules:**

- No sensitive data.
- Transfer on request or when blocked.

**Tools:**

- Use Google Calendar and Transfer **only** when appropriate and **after confirmation**.

---

## Step 6. Call Actions

### 6.1 Schedule on Google Calendar

First, set up the integration in **Google Calendar** and enable **Appointments** for the chosen calendar.

In **Call Action**, enable **Schedule Appointment on Google Calendar** and select that calendar (use the gear icon if shown).

In the prompt, explain how to confirm **time** and **timezone**.

**Booking line (EN):**\
I can offer Tuesday 10:30 or Wednesday 12:00 (your local time). Which works?

---

### 6.2 Transfer call

Create a configuration in **Call Transfer** (destination, hours, queue).

In **Call Action**, enable **Transfer Call** and select that configuration.

Add a handoff line to the prompt.

**Handoff line (EN):**\
I’ll connect you with the right specialist now. Please stay on the line.

---

### 6.3 Data Extraction

In **Call Action** → **Data Extraction**, define the entities to capture:

- **firstName:** contact’s first name (string or null).
- **appointmentDate:** date/time (ISO string or null).
- **issueType:** main reason (values: billing, support, sales).

Reference them in the prompt with one or two examples to improve capture.

---

### 6.4 Post-call webhook

Enable it to push call details to your system.

Example content (plain text):\
Agent: Support EN – Sales. Direction: both. Entities: firstName Alex; appointmentDate 2025-10-30T10:30:00-03:00; issueType sales. Also: recording link and transcript link.

---

## Step 7. Call Settings

In **Call Settings**:

- **Record Calls:** store audio and transcripts (recommended for QA/compliance).
- **Voicemail Detection:** hang up on voicemail to save minutes.
- **Background Ambience:** subtle background noise for a natural feel.
- **Greeting Message Delay (ms):** a short pause before the greeting (for example, 1200).

---

## Step 8. Test and save

Run **Test Call** in each tab (Agent, Voice & Language, Call Action). Validate greeting, language, speed, booking, transfers, and entities.

Click **Save** and place a real verification call. Check **Call History** for audio, transcript, and extracted values.

---

## Advanced setup (optional)

- **Keyword routing:** in the prompt, define terms that trigger booking (book, reschedule) or transfer (talk to human, supervisor).
- **Double confirmations:** ask callers to repeat date/time before booking.
- **Multilingual:** use Secondary Language only if you truly serve two languages; otherwise disable it.
- **Temperature by goal:** low for booking/transfer; medium for FAQs/sales.

---

## Common errors and fixes

**“This calendar does not have an appointment action.”**\
The calendar lacks Appointments. Go to Google Calendar, enable it, or pick another calendar with the action active.

**Banner: “Select a Google Calendar…”**\
In Call Action, open the gear on Schedule Appointment and select the correct calendar.

**Banner: “Select a Transfer Configuration…”**\
Create and save a profile in Call Transfer, then select it in the agent.

**Wrong-hour bookings**\
Align the agent Timezone with the calendar and confirm the caller’s local time.

**Language mixing**\
Keep the prompt in one language; set Language/Secondary Language properly and pick a matching voice.

**Entities missing**\
Define clear types (string/boolean/ISO), mention entities in the prompt, lower Temperature, or try a more capable LLM.

**Webhook enabled without URL (“Webhook Url is required…”)**\
Add a valid endpoint before enabling Post-Call Webhook or disable it while testing.

## Close

Your agent can now understand complex contexts, book accurately, escalate calls, and feed clean data to your systems. Start with a balanced LLM, test with real calls, and tune—this foundation will let you scale without friction.
