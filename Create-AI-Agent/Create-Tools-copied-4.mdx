## Überblick

**Tools** (Webhooks) ermöglichen es Ihrem Callin-Agent, sich **in Echtzeit** während eines Gesprächs mit externen Systemen zu verbinden.

Mit einem Tool kann Ihr Agent:

- **Daten senden**, die der Nutzer während des Anrufs angibt (z. B. Name, E-Mail, Telefonnummer, Anliegen).
- **Daten abrufen** aus einem externen System (z. B. Status, Verfügbarkeit, Verifizierung).
- **Automatisierungen auslösen** in externen Plattformen (CRM, Tickets, Messaging, Workflows usw.).

In Callin folgt die korrekte Einrichtung immer dieser Reihenfolge:

1. **Tool erstellen** im Bereich **Tools**.
2. **Tool dem Agent zuweisen** im Bereich **AI Agents**.
3. **Im Feld Conversation Prompt festlegen**, wann es ausgeführt werden soll und was der Agent mit dem Ergebnis tun muss.

Wenn einer dieser 3 Schritte fehlt, wird das Tool nicht wie erwartet ausgeführt.

---

## Schritt 1 — Ein Tool (Webhook) erstellen

So erstellen Sie ein Tool in Callin:

1. Öffnen Sie **Tools** im Callin-Dashboard.
2. Klicken Sie auf **+ Add Tool**.
3. Füllen Sie die wichtigsten Felder aus:

- **Name**  
  Verwenden Sie einen kurzen, klaren und stabilen Namen. Empfehlung: **Verb + Ziel**.  
  Beispiele: `registrierungslink-senden`, `kundenstatus-pruefen`, `lead-erstellen`.

- **Description**  
  Erklären Sie **was** das Tool macht und vor allem **wann** es verwendet werden soll.  
  Beispiel: „Den Haupt-Registrierungslink nur dann senden, wenn der Nutzer bestätigt hat, dass er fortfahren möchte, und E-Mail sowie Telefonnummer bestätigt sind.“

- **Method**  
  - Verwenden Sie **GET**, wenn Sie Informationen **abrufen**.  
  - Verwenden Sie **POST**, wenn Sie Informationen **senden** (am häufigsten, wenn der Agent Daten sammelt und an einen Webhook sendet).

- **URL**  
  Fügen Sie den HTTPS-Endpoint Ihrer API oder den Webhook Ihrer externen Plattform ein.

> Stellen Sie sicher, dass die URL **HTTPS** ist und öffentlich erreichbar. Wenn der Endpoint nicht erreichbar ist, funktioniert das Tool nicht.

### „Body parameters“ konfigurieren (wenn Sie POST verwenden)

Wenn Ihr Tool Informationen (POST) sendet, definieren Sie exakt, welche Daten gesendet werden:

1. Gehen Sie zu **Body parameters**.
2. Klicken Sie auf **Add property**.
3. Konfigurieren Sie jedes Feld:

- **Type**: Datentyp (Text, Zahl, wahr/falsch usw.).
- **Identifier**: der exakte Feldname, den Ihr Endpoint erwartet (z. B. `email`, `telefon`, `voller_name`).
- **Required**: aktivieren, wenn das Feld verpflichtend ist.
- **Description**: erklären, was das Feld bedeutet und welches Format erwartet wird (z. B. „Telefonnummer im internationalen Format“ oder „Gültige E-Mail“).

> Praktische Empfehlung: Wenn Sie ein Feld als **Required** markieren, muss der Agent (im Conversation Prompt) angewiesen werden, es **abzufragen und zu bestätigen**, bevor das Tool ausgeführt wird. Andernfalls erhält der Webhook unvollständige Daten oder der Ablauf scheitert.

### Header und Authentifizierung (falls erforderlich)

Wenn Ihr Endpoint Authentifizierung benötigt (z. B. Token oder Schlüssel), müssen Sie diese gemäß den exakten Anforderungen Ihrer API konfigurieren (welche Header notwendig sind und mit welchen Werten).

4. Klicken Sie auf **Save**, um das Tool zu speichern.

---

## Schritt 2 — Tool einem Agent zuweisen

Das Erstellen des Tools reicht nicht aus. Sie müssen es dem Agent zuweisen:

1. Gehen Sie zu **AI Agents**.
2. Wählen Sie den Agent aus, den Sie konfigurieren möchten.
3. Scrollen Sie im Agent-Editor zur Sektion **Tools**.
4. Klicken Sie auf **+ Add Tool**.
5. Wählen Sie das Tool aus und speichern Sie.

**Schnellcheck:**  
Wenn das Tool im Agent aufgelistet ist, ist es korrekt zugewiesen. Wenn es nicht erscheint, kann der Agent es nicht ausführen.

---

## Schritt 3 — Verwendung des Tools im „Conversation Prompt“ festlegen

Das ist der wichtigste Schritt. Der Agent führt das Tool nur aus, wenn der **Conversation Prompt** klar festlegt:

- **Welche Daten vor der Ausführung gesammelt werden müssen** (Pflichtfelder).
- **Wie diese Daten bestätigt werden sollen** (zur Reduzierung von Fehlern).
- **Wann** es ausgeführt werden soll (der genaue Zeitpunkt im Anruf).
- **Was unmittelbar danach gesagt werden muss** (inklusive exakter Sätze, falls Ihr Prozess das verlangt).
- **Was NICHT getan werden darf** (um Abläufe nicht zu vermischen oder Links zur falschen Zeit zu senden).

### Was Sie in den Conversation Prompt schreiben (erfundenes, leicht anpassbares Beispiel)

Unten steht ein vollständiges (erfundenes) Beispiel mit zwei Tools: ein Hauptlink während des Anrufs und ein Portal-Link am Ende.

**Tool 1: Registrierungslink_Senden (Link A)**  
**Ziel:** den Hauptlink senden, über den der Nutzer den gesamten Hauptprozess abschließt.  
**Wann verwenden:** während des Anrufs, nur wenn der Nutzer bestätigt, dass er fortfahren möchte, und E-Mail + Telefonnummer bestätigt sind.

**Link A umfasst (im Link selbst):**
1. Erstregistrierung (Pflichtdaten)
2. Prüfung/Bestätigung der Informationen
3. Auswahl eines Plans oder einer Option
4. Zahlungseinrichtung (falls erforderlich)
5. Annahme von Bedingungen oder Unterschrift (falls erforderlich)
6. Dokumenten-Upload (falls erforderlich)
7. Endbestätigung

**Bedingungen, um „Registrierungslink_Senden“ auszuführen:**
- Der Nutzer sagt klar, dass er fortfahren möchte.
- Die E-Mail ist bestätigt (wiederholt und vom Nutzer bestätigt).
- Die Telefonnummer ist bestätigt (wiederholt und vom Nutzer bestätigt).

**Exakter Satz nach dem Senden von Link A (erfundenes Beispiel):**
> „Öffnen Sie den Link, den wir Ihnen gerade gesendet haben, und scrollen Sie zum Abschnitt ‚Erstregistrierung‘. Füllen Sie Ihre Angaben aus und sagen Sie mir Bescheid, wenn Sie bereit sind weiterzumachen.“

**Regeln während des Anrufs (sehr wichtig):**
- Bitten Sie den Nutzer nicht, Link A zu verlassen, um während des Anrufs Schritte an anderer Stelle zu erledigen.
- Bitten Sie nicht um einen separaten Portal-Login, während der Hauptprozess abgeschlossen wird.
- Führen Sie den Nutzer Schritt für Schritt und bleiben Sie stets bei dem aktuellen Schritt.

---

**Tool 2: Portal_Link_Senden (Link B)**  
**Ziel:** den Link zum sicheren Portal senden, um später den Fortschritt zu prüfen.  
**Wann verwenden:** ausschließlich am Ende des Anrufs.

**Exakte Sätze nach dem Senden von Link B (erfundenes Beispiel):**
> „Hier ist der Link, um auf Ihr sicheres Portal zuzugreifen.“  
> „Wir haben Ihnen außerdem E-Mails mit Ihren Zugangsdaten gesendet.“  
> „Wenn Sie sie nicht finden, nutzen Sie die Suche in Ihrem E-Mail-Postfach und geben Sie den Namen unseres Unternehmens ein, um sie zu finden.“

**Abschlusssatz (erfundenes Beispiel):**
> „Vielen Dank für Ihre Zeit. Wenn Sie bei irgendeinem Schritt Hilfe benötigen, stehen wir Ihnen gerne zur Verfügung.“

## Schritt 4 — Tool testen, bevor Sie es produktiv nutzen

Bevor Sie das Tool mit Kunden verwenden, prüfen Sie:

- Die Anfrage wird korrekt ausgeführt.
- Felder kommen mit den erwarteten Namen an (Identifier).
- Pflichtfelder (Required) sind immer vorhanden.
- Der Endpoint antwortet schnell und konsistent.

Eine gute Praxis ist, den Webhook zuerst mit einer temporären Prüf-URL zu testen (um zu sehen, was ankommt) und anschließend mit Ihrem echten Endpoint.

## Häufige Fehler und Lösungen

| Problem | Wahrscheinliche Ursache | Lösung |
| --- | --- | --- |
| Tool wird nicht ausgeführt | Es ist dem Agent nicht zugewiesen | Gehen Sie zu **AI Agents > Ihr Agent > Tools** und fügen Sie es hinzu |
| Keine Daten erreichen den Endpoint | Endpoint nicht erreichbar oder falsche URL | Prüfen Sie, dass die URL **HTTPS** ist und öffentlich erreichbar |
| Felder fehlen | „Identifier / Required“ falsch konfiguriert oder Agent sammelt sie nicht | Prüfen Sie **Body parameters** und passen Sie den **Conversation Prompt** an, um Daten einzufordern und zu bestätigen |
| Ausführung zur falschen Zeit | Conversation Prompt definiert keine klaren Bedingungen | Definieren Sie Regeln wie „nur am Ende“, „nur nach Bestätigung von E-Mail und Telefonnummer“ |

---

## Abschließender Hinweis

Für ein stabiles Ergebnis:

- Starten Sie mit einem einfachen Tool.
- Definieren Sie anfangs nur wenige Pflichtfelder.
- Seien Sie im Conversation Prompt eindeutig bezüglich:
  - **Ausführungsbedingungen**,  
  - **Ablaufreihenfolge**,  
  - **exakter Formulierungen** (falls erforderlich),  
  - **und Verbote** (was der Agent nicht tun darf).
