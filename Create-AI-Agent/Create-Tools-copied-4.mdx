## Vue d’ensemble

Les webhooks permettent à votre agent Callin d’interagir avec des systèmes externes en temps réel. Concrètement, à chaque fois que votre agent émet ou reçoit un appel, il peut automatiquement **envoyer ou demander des données** à un autre service via une simple requête HTTP.

C’est utile si vous souhaitez que votre agent récupère des informations client, crée des enregistrements dans des outils externes, ou déclenche des automatisations — pendant une conversation en direct.

Dans Callin, les webhooks sont créés sous forme d’**outils** (Tools), des composants réutilisables que vous pouvez attribuer à n’importe quel agent vocal.

---

## Étape 1 : Créer un outil Webhook

Pour commencer, vous devez créer un nouvel outil dans le tableau de bord Callin :

1. Allez dans [Tools](https://app.callin.io/tools) dans votre [espace de travail Callin](https://app.callin.io).
2. Cliquez sur **\+ Add Tool**.
3. Renseignez les champs suivants :
   - **Name** : `get-customer-data`
   - **Description** : `Récupère les informations client à partir du numéro de téléphone.`
   - **Method** : choisissez `GET` si vous récupérez des données, ou `POST` si vous envoyez des données.
   - **URL** : indiquez l’endpoint de l’API externe, par exemple `https://api.mycompany.com/customers`

> ✅ Assurez-vous que l’URL utilise HTTPS et qu’elle est accessible publiquement. Sinon, le webhook ne fonctionnera pas.

4. Cliquez sur **Save** pour créer l’outil.

---

## Étape 2 : Assigner l’outil à un agent vocal

Une fois l’outil créé, vous devez le relier à l’agent qui l’utilisera :

1. Allez dans [AI Agents](https://app.callin.io/agents).
2. Choisissez l’agent que vous souhaitez configurer.
3. Faites défiler jusqu’à la section **Tools** et cliquez sur **\+ Add Tool**.
4. Sélectionnez l’outil que vous venez de créer et enregistrez vos modifications.

Votre agent est maintenant prêt à exécuter ce webhook dès qu’il en a besoin pendant un appel.

---

## Étape 3 : Tester votre webhook

Avant de l’utiliser en production, il est important de tester que votre webhook est correctement configuré.

Vous pouvez utiliser [Webhook.site](https://webhook.site) — un outil gratuit qui vous fournit une URL temporaire pour recevoir des requêtes de test et inspecter les données.

Voici un exemple de payload que Callin peut envoyer :

"call_id": "ab12cd34", "agent_name": "Laura AI", "duration": 145, "direction": "outbound", "caller_number": "+34123456789", "summary": "Customer requested a follow-up."

Vérifiez que le payload arrive bien et qu’il correspond à ce que votre API externe attend.

---

## Étape 4 : Automatiser avec d’autres plateformes

Une fois que votre webhook fonctionne, vous pouvez l’utiliser avec des outils d’automatisation comme :

- [**Zapier**](https://support.callin.io/Create-AI-Agent/Connect-Zapier) : déclenchez des automatisations dans plus de 3 000 applications.
- [**n8n**](https://support.callin.io/Create-AI-Agent/Connect-N8N) : créez des flux conditionnels et des workflows avancés de manière visuelle.
- [**Make.com**](https://support.callin.io/Create-AI-Agent/Connect-Make) : concevez des scénarios puissants sans écrire de code.

Ces outils peuvent exploiter la réponse du webhook pour envoyer des messages Slack, créer des leads CRM, déclencher des emails, et bien plus encore.

---

## Erreurs courantes et solutions

| Problème                 | Cause probable                         | Solution                                                   |
| ------------------------ | -------------------------------------- | ---------------------------------------------------------- |
| URL du webhook manquante | Le champ URL est vide                  | Ajoutez un endpoint HTTPS valide                           |
| L’outil ne s’exécute pas | L’outil n’est pas assigné à l’agent    | Allez dans l’agent \> onglet Tools \> ré-assignez l’outil   |
| Aucune donnée reçue      | L’API n’est pas accessible             | Testez l’URL avec Webhook.site                             |
| Erreur de timeout        | L’API met trop de temps à répondre     | Augmentez le délai de réponse du webhook dans l’outil      |

---

## Conseil final

Les webhooks sont l’un des moyens les plus puissants d’étendre les capacités de votre agent Callin.

Commencez par quelque chose de simple :\
mettez en place un webhook `GET` pour récupérer les informations client par numéro de téléphone. Une fois que cela fonctionne, passez à des flux plus avancés avec **Zapier**, **n8n** ou **Make.com**.

En combinant la voix en temps réel et l’automatisation, votre agent IA peut non seulement parler — il peut aussi récupérer des données, déclencher des actions et générer des résultats dans tous vos outils.
