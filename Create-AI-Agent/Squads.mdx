## What is a squad

A **squad** is a team of AI agents that work on the same call. One agent answers, and when the caller needs something more specific, it **hands off** the call to the right specialist without hanging up. For example, a front desk agent greets the caller and passes the call to a booking agent when the caller wants an appointment.

Squads work with **Enhanced** agents only (marked **Ultra-low latency**). You’ll find them in the left menu, under **Build** ([open it here](https://app.callin.io/squads)).

## Create a squad

  Video: Create squad → name the squad → Add agent → set the role and specialization of each agent.
</p>

1. Go to **Squads** and click **\+ Create squad**.
2. In **Name your squad**, type a name your team will recognize (for example, _Clinic front desk squad_) and click **Continue**. You can rename it at any time from the box at the top left.
3. The squad editor opens: a canvas on the left and a **Get started** panel on the right with the three steps: **Add agents**, **Configure an agent**, and **Create handoffs**.

### Add agents

1. Click **\+ Add agent** (top right of the canvas, or in the middle of an empty canvas).
2. Search for and pick one of your Enhanced agents. It appears on the canvas.
3. Repeat for every agent you want in the squad.

The first agent you add gets the **Starts call** label: it’s the one that answers the call.

### Configure each agent

Click an agent on the canvas to open its settings on the right:

- **Role**: a short name for what the agent does (for example, _Greeter_, _Qualifier_, or _Scheduler_).
- **Specialization**: the agent’s narrow responsibility and when it should take over.
- **Set as entry**: makes this agent the one that **starts the call**.
- **Remove agent**: takes the agent out of the squad.

The icon next to the agent’s name opens that agent, so you can change its prompt, voice, or tools.

## Create handoffs

A **handoff** is the connection that passes the call from one agent to another.

<div style={{ border:"2px solid #e5e7eb", borderRadius:"12px", padding:"8px", boxShadow:"0 4px 12px rgba(0,0,0,0.10)", maxWidth:"100%", overflow:"hidden", backgroundColor:"#0b0b0b", marginBottom:"0.75rem" }}>
  <video autoPlay muted loop playsInline src="/images/squads-handoff.mp4" style={{ width:"100%", display:"block" }} />
</div>

<p style={{ marginTop:"0", marginBottom:"1.5rem", color:"#6b7280", fontSize:"0.95rem" }}>
  Video: connect two agents → fill in the Handoff panel → choose the Context plan.
</p>

1. Drag from the bottom of one agent to the other agent. A connection appears, and the first agent shows **Handoff to** with the name of the second.
2. Click the connection to open the **Handoff** panel and fill in:
   - **When to hand off**: the condition for passing the call (for example, _“The patient wants to book, move or cancel an appointment.”_). By default it says _Caller needs this specialist_.
   - **Transition brief**: an internal note for the next agent. It’s never spoken to the caller.
   - **Context plan**: how much of the conversation the next agent receives:
     - **All messages**: the whole conversation so far.
     - **Last N messages**: only the most recent messages. Set how many in **Max messages**.
     - **Previous agent only**: only what the previous agent said.
     - **None (fresh start)**: nothing; the next agent starts from scratch.
     - **User + agent only**: only the caller’s and the agent’s messages.
   - **Pass variables**: comma-separated variables to keep across the handoff (for example, `patient_name, reason`).
   - **Silent handoff**: don’t announce the handoff to the caller. Turn it off to speak a short transfer line first.
3. Use **Remove handoff** to delete the connection.

## Save and test the squad

While you edit, a bar at the bottom shows **You have unsaved changes**. Click **Save** to keep the squad, or **Clear** to discard the changes.

To save, the squad needs:

- A name (otherwise you’ll see **Name this squad**).
- At least **2** Ultra-low latency agents on the canvas (otherwise, **Need more agents**).
- At least one handoff between two different agents, with a description of when the starting agent should hand off (otherwise, **Add a handoff**).

You’ll see **Squad created** the first time and **Squad saved** after that.

### Use and manage your squads

Each squad in the list shows how many agents and handoffs it has, and which agent is the entry. From there you can:

- **Assign number**: give the squad a phone number so it can receive and make calls. Use **Change number** or **Unassign number** to change it. Without a number, the squad shows **No number assigned** and can’t receive or make phone calls.
- **Test Squad**: call the squad in your browser. Handoffs work the same as on the phone.
- **Test Call**: call a phone number with the squad. Enter the **Customer number** in international format (for example, `+14155550123`) and click **Start call**. The entry agent speaks first, and handoffs follow your canvas.
- **Open canvas**: open the squad editor to change agents or handoffs.
- **Delete squad**: removes the squad. Its member agents are not deleted.

Use **Search squads…** to find a squad by name.

## Tips & best practices

- **Give each agent one clear job.** Short, specific specializations make handoffs more reliable.
- **Write handoff conditions like rules.** _“The caller asks about prices or wants to buy”_ works better than _“sales”_.
- **Choose the context carefully.** **All messages** keeps the full story; **None (fresh start)** is useful when the next agent shouldn’t see earlier details.
- **Keep the transition brief short.** One or two sentences with what the next agent must know.

## Troubleshooting

**Issue:** I can’t find an agent when I click Add agent.\
**Cause:** It isn’t an Enhanced (Ultra-low latency) agent.\
**Fix:** Use an Enhanced agent. Squads only work with that stack.

**Issue:** I can’t save the squad.\
**Cause:** It has no name, fewer than 2 agents, or no handoff with a condition.\
**Fix:** Check the message that appears and complete what’s missing.

**Issue:** The call never moves to the next agent.\
**Cause:** The handoff condition doesn’t match what callers say, or the squad wasn’t saved.\
**Fix:** Make **When to hand off** clearer and click **Save**.

**Issue:** The squad doesn’t receive phone calls.\
**Cause:** It has no number assigned.\
**Fix:** Use **Assign number** on the squad.

**Issue:** The next agent asks again for information the caller already gave.\
**Cause:** The context plan or variables don’t pass that information.\
**Fix:** Use **All messages** or add the fields to **Pass variables**.
