## Resumen

Los webhooks permiten que tu agente de Callin interactúe con sistemas externos en tiempo real. Esto significa que, cada vez que tu agente hace o recibe una llamada, puede automáticamente **enviar o solicitar datos** a otro servicio mediante una simple petición HTTP.

Esto es útil cuando quieres que tu agente obtenga información del cliente, cree registros en herramientas externas o dispare automatizaciones — todo durante una conversación en vivo.

En Callin, los webhooks se crean como **Tools**, que son componentes reutilizables que puedes asignar a cualquier agente de voz.

---

## Paso 1: Crea una herramienta de webhook

Para empezar, tendrás que crear una nueva Tool dentro del panel de Callin:

1. Ve a [Tools](https://app.callin.io/tools) en tu [Callin workspace](https://app.callin.io).
2. Haz clic en **\+ Add Tool**.
3. Rellena los siguientes campos:
   - **Name**: `get-customer-data`
   - **Description**: `Recupera información del cliente por número de teléfono.`
   - **Method**: Elige `GET` si vas a recuperar datos, o `POST` si vas a enviarlos.
   - **URL**: Indica el endpoint de la API externa, por ejemplo `https://api.mycompany.com/customers`

>  Asegúrate de que la URL use HTTPS y sea accesible públicamente. De lo contrario, el webhook no funcionará.

4. Haz clic en **Save** para crear la Tool.

---

## Paso 2: Asigna la Tool a un agente de voz

Una vez creada tu Tool, tienes que conectarla al agente que la usará:

1. Navega a [AI Agents](https://app.callin.io/agents).
2. Elige el agente que quieres configurar.
3. Desplázate hasta la sección **Tools** y haz clic en **\+ Add Tool**.
4. Selecciona la Tool que acabas de crear y guarda los cambios.

Ahora tu agente está preparado para ejecutar este webhook cuando sea necesario durante una llamada.

---

## Paso 3: Prueba tu webhook

Antes de usarlo en producción, es importante probar que tu webhook esté correctamente configurado.

Puedes usar [Webhook.site](https://webhook.site) — una herramienta gratuita que te da una URL temporal para recibir peticiones de prueba e inspeccionar los datos.

Aquí tienes un ejemplo de un payload que Callin podría enviar:

"call_id": "ab12cd34", "agent_name": "Laura AI", "duration": 145, "direction": "outbound", "caller_number": "+34123456789", "summary": "Customer requested a follow-up."

Comprueba que el payload llega y coincide con lo que espera tu API externa.

---

## Paso 4: Automatiza con otras plataformas

Cuando tu webhook funcione, puedes conectarlo a herramientas de automatización como:

- [**Zapier**](https://support.callin.io/Create-AI-Agent/Connect-Zapier): Dispara automatizaciones en más de 3.000 apps.
- [**n8n**](https://support.callin.io/Create-AI-Agent/Connect-N8N): Crea flujos condicionales y workflows avanzados de forma visual.
- [**Make.com**](https://support.callin.io/Create-AI-Agent/Connect-Make): Diseña escenarios potentes sin escribir código.

Estas herramientas pueden tomar la respuesta del webhook y enviar mensajes a Slack, crear leads en un CRM, disparar emails y mucho más.

---

## Errores comunes y cómo solucionarlos

| Problema             | Causa probable             | Solución                                         |
| ------------------- | -------------------------- | ------------------------------------------------ |
| Falta la URL del webhook | El campo URL está vacío     | Añade un endpoint HTTPS válido                   |
| La Tool no se ejecuta    | No está asignada al agente  | Ve al agente \> pestaña Tools \> vuelve a asignar la Tool |
| No se reciben datos      | La API no es accesible      | Prueba la URL usando Webhook.site                |
| Error de timeout         | La API tarda demasiado      | Aumenta el timeout de respuesta del webhook en la Tool |

---

## Consejo final

Los webhooks son una de las formas más potentes de ampliar lo que tu agente de Callin puede hacer.

Empieza con algo simple:\
Configura un webhook `GET` para obtener detalles del cliente por número de teléfono. Cuando eso funcione, pasa a flujos avanzados con **Zapier**, **n8n** o **Make.com**.

Al combinar voz en tiempo real con automatización, tu agente de IA no solo puede hablar — también puede obtener datos, ejecutar acciones y generar resultados a través de todas tus herramientas.
