## Overview

Your contacts are the base of everything in Callin. From this screen you can add people one by one, upload big lists, search quickly, and take bulk actions like starting calls.  

Think of it as your address book — clean data here makes every campaign smoother.

---

## Step 1 — Add a Contact Manually

Open **Contacts** and click **+ Add Contact**. You’ll see a small grid where each row is one contact.

1. Fill in the first row:  
   - Name → type first and last name.  
   - Phone → required, always in international format (e.g. `+12025550101`).  
   - Email → optional, but must be valid if used.  

2. Add more rows:  
   - Press Enter to move to the next.  
   - Use **+ Add Row** for several at once.  
   - Or paste straight from Excel/Sheets — values fall into place.  

3. Check validation as you type:  
   - Invalid or missing phone? Red border.  
   - Length should be 7–15 digits.  

4. Save and return to the list. Search your new contact to confirm it looks right.  

 Outcome: the contact is stored and ready for calling or campaigns.

---

## Step 2 — Import a File

For big lists, use CSV or Excel (max 10 MB). Clean the sheet first: remove dashes, spaces, and duplicates.

1. In **Contacts**, click **Upload CSV** and drop your file.  
2. Map your columns: **Phone** is mandatory. Others (Name, Email, Company, Address…) are optional.  
3. If numbers miss a prefix, pick the country (e.g. +1 US). The system adds it.  
4. Need an extra field? Add it on the spot with **+ Add Column**.  
5. Fix any red cells (wrong phone format, empty required fields). Then continue.  

 Outcome: all rows appear in the main contact list, ready to filter and use.

**Sample CSV (US test data):**

name,email,phoneNumber,company_name,address_line_1,address_line_2,town_city,county,post_code  
Amelia Brown,amelia.brown@example.com,+12025550101,Brookline Supplies,125 Beacon St,Suite 400,Boston,MA,02108  
Michael Reed,michael.reed@example.com,+13105550112,Northwest Manufacturing,742 Pine Ave,,Seattle,WA,98101  

---

## Step 3 — Work with the List

- **Search**: type any field (name, company, city) and results appear instantly.  
- **Filter by agent**: narrow the view to one agent’s portfolio.  
- **Open a row**: see full details, edit, and save.  
- **Bulk actions**: select multiple contacts and choose Call or Delete. Always search first so you only hit the right records.  

 Outcome: your list is trimmed, verified, and ready to call or drop into a campaign.

---

## Pro Tips

- Always store phones in international format.  
- Normalize company names and remove duplicates before importing.  
- Use `555` numbers + `example.com` emails for test data.  
- Only import contacts with consent (compliance first).  

---

## Fixing Common Errors

- **“Phone number is required”** → Add a valid international number.  
- **“No valid phone number found”** → Check mapping or missing prefix.  
- **“Email must be valid”** → Fix format or leave blank.  
- **Cannot continue** → Phone not mapped or errors remain.  
- **Misaligned columns** → Wrong mapping. Re-upload and map again.
