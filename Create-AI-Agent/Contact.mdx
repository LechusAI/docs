## Overview

The **Contacts** page is where you manage who your agents will call. You’ll find it in the left menu, under **Telephony** ([open it here](https://app.callin.io/contacts)).

From here you can:

- **Add contacts manually**, one or many at a time.
- **Upload a CSV** to import a larger list.
- **Search and filter** your contact list.
- **View and edit** each contact.
- **Export** your contacts to CSV.
- **Start a campaign** with the contacts you select.
- **Delete** selected contacts (permanent).

If you don’t have any contacts yet, the page shows **No contacts found** with the **Add Contact** and **Upload CSV** buttons.

## Add contacts manually

Manual entry is best when you’re adding a few contacts quickly, or pasting them from a spreadsheet.

<Frame caption="Video: Add Contact → fill in two example contacts → Add Column → Save Contacts.">
  <video autoPlay muted loop playsInline src="/images/contacts-add.mp4" />
</Frame>

### Steps

<Steps>
  <Step>
    Click **\+ Add Contact**. The **Add Contacts** window opens with a grid.
  </Step>
  <Step>
    Fill in each row:
    - **Name**
    - **Phone Number** (required)
    - **Email** (optional)
  </Step>
  <Step>
    Click **Add Row** (or press **Enter**) to add more people.
  </Step>
  <Step>
    Click **Save Contacts**.
  </Step>
</Steps>

<Warning>
  **Phone Number is required** for every contact. If it’s missing, the window shows **Phone number is required**.
</Warning>

### Editing tips (like a spreadsheet)

The window lists these **Quick Tips**:

- Click and drag to select multiple cells.
- Use **Ctrl+C** (**Cmd+C** on Mac) to copy selected cells.
- Click any cell and press **Ctrl+V** (**Cmd+V** on Mac) to paste data.
- Press **Escape** to clear the selection.
- Double-click a cell to edit its content.
- Press **Enter** to add a new row.

<Tip>
  If your contacts are already in Google Sheets or Excel, copy the cells and paste them directly into the grid.
</Tip>

### Optional columns

Above the grid you can see the current columns (**Columns: name, phoneNumber, email**). Click **Add Column** to add your own field, for example _company_ or _city_. In **Add New Column**, type a **Column Name** and click **Add Column**. Names are converted to lowercase with underscores.

You can later use these columns in the contact filters.

## Import contacts from a CSV

CSV import is best for larger lists.

<Frame caption="Video: Upload CSV → Map Columns → review the contacts in Add Contacts.">
  <video autoPlay muted loop playsInline src="/images/contacts-csv.mp4" />
</Frame>

### Upload requirements

- **File type:** CSV only.
- **Max size:** 10MB.
- You can click to select the file or drag and drop it.

<Warning>
  **Common mistake:** Uploading an .xlsx file. Export it as **CSV** first.
</Warning>

### Upload a CSV

<Steps>
  <Step>
    Click **Upload CSV**. The **Upload CSV File** window opens.
  </Step>
  <Step>
    (Optional) Click **Download Template** to start from the recommended format.
  </Step>
  <Step>
    Click **Select File**, or drag the file into the upload area.
  </Step>
</Steps>

<Frame caption="Screenshot: the Upload CSV File window, with the CSV-only requirement and the 10MB limit.">
  <img src="/images/contacts2.png" alt="Upload CSV File window with the Download Template button, the drag and drop area, CSV files only (max. 10MB) and the Select File button" />
</Frame>

### Map your columns

After the upload, the **Map Columns** window shows the file name and how many contacts it has. Under **Map Your Columns**, choose which column of your file goes to each field:

- **Phone** (required)
- **Name**
- **Email**

If your numbers don’t include **\+**, choose their country in **Numbers don’t include “+”… choose a country**, so Callin.io can add the country code.

Below, you’ll see a preview of your contacts. Click **Continue**: the contacts open in the **Add Contacts** grid, where you can review or fix them before clicking **Save Contacts**.

<Warning>
  If **Phone** is not mapped, the import can’t continue.
</Warning>

### Validation rules (applies to manual + CSV)

- Phone numbers must include a **country code** (example: **\+1234567890**).
- Phone numbers must be **7–15 digits** (excluding the country code).
- Phone numbers are **required** for all contacts.
- Email addresses must be **valid** if provided.
- Fields with validation errors are highlighted with a **red border**.
- Empty fields are highlighted with a **red border**.

<Tip>
  If your CSV has phone numbers without country codes, choose the country when you map the columns, or add the code before importing.
</Tip>

## Manage your contact list

<Frame caption="Video: view and edit a contact → select contacts → Filters → Start Campaign → Delete Selected.">
  <video autoPlay muted loop playsInline src="/images/contacts-manage.mp4" />
</Frame>

### Search and filters

- Use **Search contacts...** to find people by name, phone, or email.
- Click **Filters** to open **Advanced Filters**, then **Add Filter**. Each filter has a field (**name**, **email**, **phoneNumber**, or any column you added), a condition (**Equals**, **Not Equals**, **Contains**, **Starts With**, **Ends With**, **Is Empty**, **Is Not Empty**), and a value.

The panel shows how many contacts match. Click **Select All Filtered** to select them all (for example, to start a campaign), or **Clear All** to remove the filters.

<Frame caption="Screenshot: a filter that finds the contacts whose name contains “Emma”.">
  <img src="/images/contacts-filters.png" alt="Advanced Filters with a filter name Contains Emma, 1 contact match and the Select All Filtered button" />
</Frame>

### View and edit

In the **Actions** column:

- The **eye** icon opens **Contact Details**, with the contact’s name, email, and phone number.
- The **pencil** icon lets you edit the contact directly in the list. Click the **save** icon to keep the changes. You’ll see **Contact edited successfully**.

### Export to CSV

Select contacts with the checkboxes and click **Export to CSV** to download them. The checkbox in the header selects all the contacts on the list.

## Start a campaign from Contacts

<Steps>
  <Step>
    Select one or more contacts using the checkboxes.
  </Step>
  <Step>
    Click **Start Campaign**.
  </Step>
  <Step>
    Enter a campaign name and choose an agent in **Select agent**.
  </Step>
  <Step>
    (Optional) Turn on **Follow-up Calls**.
  </Step>
  <Step>
    Click **Start Campaign**.
  </Step>
</Steps>

When **Follow-up Calls** is on, for each contact with an **unanswered** or **busy** call, follow-up attempts are scheduled:

- After **2 hours**
- After **1 day**
- After **3 days**

<Frame caption="Screenshot: starting a campaign with the selected contacts.">
  <img src="/images/contacts-campaign.png" alt="Start Campaign window with an example campaign name, a selected agent and Follow-up Calls turned on" />
</Frame>

<Tip>
  If you’re testing, start with a small selection (5–10 contacts) to check that your agent and script behave as expected.
</Tip>

## Delete selected contacts (permanent)

<Steps>
  <Step>
    Select the contacts you want to remove.
  </Step>
  <Step>
    Click **Delete Selected**.
  </Step>
  <Step>
    In **Delete Contacts**, type **DELETE** to confirm and click **Delete**.
  </Step>
</Steps>

<Frame caption="Screenshot: the deletion only goes ahead after you type DELETE.">
  <img src="/images/contacts-delete.png" alt="Delete Contacts window warning that this is a permanent action, with DELETE typed in the confirmation field and the Delete button" />
</Frame>

<Warning>
  This is a **permanent action** and cannot be undone. If you might need the contacts later, export them to CSV first.
</Warning>
