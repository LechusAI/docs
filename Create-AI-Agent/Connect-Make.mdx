## Overview
This guide explains how to connect your Callin.io account with Make.com. By linking both platforms, you’ll be able to:

- Trigger AI calls from Make scenarios (e.g., when a new row is added in Airtable).
- Receive transcriptions and call data directly in Make.

This video focuses on the **initial connection**. Separate guides will cover how to build complete automations.

## Steps

### 1. Install the Callin.io App in Make
1. Go to **Actions > Make.com** in the Callin.io dashboard.
2. Click **Connect**. This will open the Callin.io app listing on Make.com.
3. Click **Install**, and select the organization where you want to use the integration.

### 2. Generate and Copy Your API Key
1. In Callin.io, go to **Settings > API Keys**.
2. Click **Regenerate Key** (or copy the existing one).
3. Save it somewhere secure—you’ll need it in Make.

### 3. Create a New Scenario in Make
1. Log in to [Make.com](https://www.make.com/) and click **Create a new scenario**.
2. Click the **+** button to add a module.
3. Search for **Callin.io** and select it.

### 4. Choose a Module
Depending on what you want to do, you can choose:
- **Activate an Agent** — to trigger a phone call.
- **Get a Transcription** — to receive call data from an event.

### 5. Connect Your Callin.io Account
1. In the module, click **Add** next to "Connection".
2. Enter a connection name.
3. Paste the API key from Step 2.
4. Click **Save**.

### 6. Fill in Required Fields
Each module will ask for different fields like:
- **Phone** (the number to call)
- **Select an Agent** (from your Callin.io list)
- **Webhook URL** (if using the "Get a Transcription" module)

> You can map these values from other modules or enter them manually.

### 7. Add the Webhook in Callin.io (Optional for Transcriptions)
1. Copy the webhook URL generated by the Make module.
2. Go to **AI Agents > Edit Agent** in Callin.io.
3. Paste the URL into the **Webhook URL** field.
4. Click **Next** to save.

### 8. Test the Scenario
1. In Make, click **Run once** to test.
2. Trigger your scenario (e.g., send data from another app).
3. Check the execution and logs.

## Tips & Notes
- API Keys are sensitive. Regenerate immediately if exposed.
- For phone numbers, use international format (e.g., +14151234567).
- You can use any Make trigger (Google Sheet, Typeform, etc.) to launch the call.

## Troubleshooting
**Symptom:** Make returns "401 Unauthorized".  
**Cause:** Invalid or expired API Key.  
**Solution:** Go to Callin.io > Settings > API Keys, regenerate, and reconnect.

**Symptom:** Call not reaching target.  
**Cause:** Agent misconfigured or phone number format incorrect.  
**Solution:** Verify agent settings and retry with a valid number.
