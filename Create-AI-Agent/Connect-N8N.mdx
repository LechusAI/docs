## Overview

Create powerful automations between Callin.io and your favorite tools with n8n. Callin.io gives you its own n8n workspace at **n8n.callin.io**, with a ready-made **Callin.io** node that makes your AI agents start calls.

## Steps

### Step 1: What is n8n and Why Use It with Callin.io?

n8n (pronounced “en-eight-en”) is a workflow automation tool that connects different apps so they work together seamlessly.

With Callin.io, this integration lets you:

- **Trigger outbound calls from external events**: for example, when a new lead arrives in your CRM, when someone fills in a form on your website, or on a schedule. The **Callin.io** node has one action, **Start call**, which makes one of your AI agents call a contact.
- **Receive call data in n8n**: send the details of each finished call to an n8n workflow with the agent’s **Data Sync (Post-Call Webhook)** (in the agent’s **Call Action** tab), and from there to Slack, Google Sheets, your CRM, etc.

In short: n8n turns events in your other tools into calls, and calls into actions in your other tools.

<Warning>
  The **Callin.io** node has no triggers of its own. To start a workflow, use an n8n trigger (for example, **On a Webhook call**, **On a Schedule** or a trigger from your CRM) and then add the **Callin.io** node.
</Warning>

### Step 2: Access the Callin.io Integrations Panel

<Steps>
  <Step>
    Log in to your Callin.io account.
  </Step>
  <Step>
    From the left menu, click **Integrations → Actions** ([open it here](https://app.callin.io/actions)).
  </Step>
  <Step>
    Use the **Automation** filter (or scroll through **All**).
  </Step>
  <Step>
    Find the **N8N** card and click **Go to n8n**.
  </Step>
</Steps>

### Step 3: Sign In to Your n8n Account

<Steps>
  <Step>
    A new tab opens on **n8n.callin.io**.
  </Step>
  <Step>
    Enter your n8n **Email** and **Password** and click **Sign in**.
  </Step>
  <Step>
    If you don’t have access yet, contact your Callin.io administrator.
  </Step>
</Steps>

Once inside, you’ll see the n8n **Overview** with your workflows, and the **Create workflow** button.

### Step 4: Get Your Callin.io API Key

The **Callin.io** node needs an API key to act on your account.

<Steps>
  <Step>
    In Callin.io, open your **Profile** ([app.callin.io/profile](https://app.callin.io/profile)) and go to the **API Keys** tab.
  </Step>
  <Step>
    If you don’t have a key yet (“No API key found”), click **Regenerate Key** to create one.
  </Step>
  <Step>
    Use the copy icon to copy the key.
  </Step>
</Steps>

<Frame caption="Screenshot: Profile → API Keys, where you create and copy your API key.">
  <img src="/images/n8n-api-key.png" alt="The API Keys tab of the Callin.io profile with the Regenerate Key button, a security warning and the API key box with show and copy icons" />
</Frame>

<Warning>
  Keep this API key secure. If you click **Regenerate Key** when you already have one, the old key stops working, and any workflow that uses it must be updated with the new key.
</Warning>

### Step 5: Build Your First Automation

<Steps>
  <Step>
    In n8n, click **Create workflow**.
  </Step>
  <Step>
    Add a trigger that starts the flow (for example, **On a Webhook call** to receive a new lead from your website or CRM).
  </Step>
  <Step>
    Click **+** to add the next step, search for **Callin.io** and choose the **Start call** action.
  </Step>
</Steps>

<Frame caption="Screenshot: The Callin.io node in n8n, with its Start call action.">
  <img src="/images/n8n-node.png" alt="n8n workflow editor with a trigger connected to the Callin.io Start call node, and the Callin.io node details on the right: Activates an agent for calling purpose, with the Start call action" />
</Frame>

4. In **Credential**, click **Set up credential**, paste your Callin.io **Api Key** and click **Save**.
5. Fill in the **Start call** fields:
   - **Phone**: the number the agent will call.
   - **Name**: the contact’s name.
   - **Email**: the contact’s email.
   - **Agent Name or ID**: the agent that will make the call (the list appears once the credential is set up).
   - **Webhook Url (optional)**: a URL to send the call data to.
   - **Additional Fields**: click **Add Field** to send extra data as **Field Name** / **Field Value** pairs.

<Frame caption="Screenshot: The Start call parameters, filled in with an example contact.">
  <img src="/images/n8n-start-call.png" alt="Start call node parameters in n8n: Credential, Resource Callin, Operation Start Call, Phone, Name, Email, Agent Name or ID, Webhook Url (optional) and Additional Fields" />
</Frame>

<Tip>
  Instead of typing fixed values, map the data from the previous step with n8n expressions (for example, `{{ $json.phone }}` for the phone number your form or CRM sends).
</Tip>

### Step 6: Activate and Test

<Steps>
  <Step>
    Click **Execute step** (or **Execute workflow**) to run a test call with a real number you control.
  </Step>
  <Step>
    When everything works, click **Publish** so the workflow runs automatically.
  </Step>
</Steps>

## Tips & Notes

- **Map your data**: Use n8n expressions to pass values from the trigger (name, phone, email) into the **Start call** fields.
- **Conditional Logic**: Add **IF** or **Switch** nodes for more complex automations (for example, only call leads from a certain country).
- **Get call results back**: Paste the URL of an n8n **On a Webhook call** trigger into the agent’s **Data Sync (Post-Call Webhook)** to receive the details of every finished call in n8n.
- **Chained Flows**: Combine Callin.io with CRMs and messaging tools in one continuous process.

## Troubleshooting

**Symptom:** The **Agent Name or ID** list is empty\
**Likely Cause:** The credential isn’t set up or the API key is wrong. Set up the credential again with a valid key from **Profile → API Keys**.

**Symptom:** It stopped working after a key change\
**Likely Cause:** The API key was regenerated. Update the credential in n8n with the new key.

**Symptom:** Flow not running\
**Likely Cause:** Make sure the workflow is published and that its trigger is receiving data.

**Symptom:** The call isn’t made\
**Likely Cause:** Check that **Phone** contains a valid number in international format (for example, `+15550102040`) and that the agent has a phone number assigned.

## Final Note

Connecting Callin.io with n8n unlocks a world of smart automation.\
Start small—like calling every new lead from your website form—and soon you’ll see how n8n turns Callin.io into an intelligent automation hub.
