## Overview

**Call History** is where you review every past call in your workspace. From this page you can:

- **Search transcripts** and **filter** calls (by phone number, agent, squad, status, date, sentiment, and more).
- **See call outcomes** at a glance: voicemail detected, data extracted, and call transferred.
- **Export** the list to **CSV**, choosing exactly which columns to include.
- **Open call details** to read the transcript, see the summary and sentiment, check extracted data and goals, and review key moments.
- **Listen to** and **download** the call recording.

Use this direct link to open the page:
[Open Call History](https://app.callin.io/call-history)

<Tip>
  Bookmark the link above if you review calls every day.
</Tip>

## Open Call History

<Steps>
  <Step>
    In the left sidebar, go to **Evaluate**.
  </Step>
  <Step>
    Click **Call History**.
  </Step>
</Steps>

The table shows one row per call, newest first:

| Column | What it shows |
| --- | --- |
| **Call Info** | The caller's phone number and the date and time of the call. Test calls made from the browser have no phone number. |
| **Agent / Squad** | The agent or squad that handled the call. |
| **Duration** | How long the call lasted. |
| **Origin** | Where the call came from, for example **Application**. |
| **Status** | The final status of the call, for example **Completed** or **No Answer**. |
| **Call Outcomes** | Icons that summarize what happened during the call. See below. |

## Filter and search calls

At the top of the page you'll find:

- **Search transcripts...**: type a word or phrase to find calls where it was said.
- **Filter buttons**: click one to open its options. You can combine several.
- **Export CSV**: download the calls you're seeing.

| Filter | What it helps you do | Options |
| --- | --- | --- |
| **Phone Number** | Find calls with a specific number | Type the number |
| **Call ID** | Jump to a specific call | Paste the call ID |
| **Agent** | See calls handled by one agent | Pick from the list (with search) |
| **Squad** | See calls handled by one squad | Pick from the list |
| **Status** | Filter by call status | **In Progress**, **Completed**, **Cancelled**, **Busy**, **No Answer**, **Unknown** |
| **Direction** | Separate inbound and outbound calls | **Inbound**, **Outbound** |
| **Appointment** | Find calls where an appointment was scheduled | **Yes**, **No** |
| **Call Transfer** | Find calls that were transferred | **Yes**, **No** |
| **Voicemail** | Find calls where a voicemail or answering machine was detected | **Yes**, **No** |
| **Date Range** | Focus on a time window | **Today**, **Yesterday**, **Last 7 Days**, **Last 30 Days**, **This Week**, **This Month**, **Last Month**, **Custom Range** |
| **Call Duration** | Filter by length | **Under 1 minute**, **1 - 5 minutes**, **5 - 10 minutes**, **Over 10 minutes** |
| **Origin** | See where the call came from | **Application**, **Zapier**, **Make**, **N8N**, **Google Meet**, **Custom Webhook** |
| **Campaign ID** | See the calls of one campaign | Paste the campaign ID |
| **Sentiment** | Find calls by the caller's overall mood | **Positive**, **Neutral**, **Negative** |
| **Ticket ID** | Find the call linked to a ticket | Paste the ticket ID |

<Warning>
  **Common mistake:** Applying too many filters at once can return no results. If the table looks empty, remove one filter and try again.
</Warning>

## Understand call outcomes (icons)

The **Call Outcomes** column shows three icons for each call. An icon lights up in color when that outcome happened:

- **Robot icon (green)**: a **voicemail or answering machine** was detected.
- **Database icon (purple)**: the agent **extracted data** during the call. Open the call to see it in the **Extracted Data** tab.
- **Phone with arrow icon**: the call was **transferred** to another number or agent.

Gray icons mean that outcome didn't happen on that call.

<Tip>
  To find calls where an appointment was scheduled, use the **Appointment** filter.
</Tip>

## Export Call History to CSV

You can export the calls you're currently seeing, including any filters you applied.

<Steps>
  <Step>
    Click **Export CSV**.
  </Step>
  <Step>
    In the **Export Call History** window, select the columns you want to include. All 27 columns are selected by default.
    - Use **Select All** or **Deselect All** to speed things up.
  </Step>
  <Step>
    Click **Export CSV** to download the file.
  </Step>
</Steps>

The available columns are:

- **Call details**: Call ID, Contact Number, Contact Name, Customer Email, Direction, Status, Duration, Started At, Ended At, Created At, Call Origin, Campaign ID, Ticket ID.
- **Agent**: Agent Name, Agent ID.
- **Outcomes**: Machine Detected, Appointment Scheduled, Call Transferred, Extracted Data.
- **Call transfer**: Call Transfer Duration, Call Transfer Status, Call Transfer Recording URL, Call Transfer Transcription, Call Transfer Number, Call Transfer Agent Name.
- **Content**: Recording URL, Transcription.

## Open call details to analyze a call

Click any call row in the table. The **Call Details** panel opens.

At the top of the panel you'll find:

- The **call ID**. Click it to copy it.
- **Search in transcript...**: find a word or phrase in the conversation.
- **Copy**: copy the transcript.

### Transcript

The left side shows the full conversation, turn by turn. Next to each of the caller's messages, a label shows the **sentiment** of that turn (**Positive**, **Neutral**, or **Negative**) with its score.

### Analysis tabs

The right side has these tabs:

| Tab | What you'll find |
| --- | --- |
| **Overview** | A **Summary** of the call and its **Metadata**: Conversation ID, Start Date/Time, Agent (click it to open the agent), Status, Sentiment, Duration, and Call Origin. |
| **Extracted Data** | The fields the agent captured during the call, with how many have values. Empty fields show **Not captured**. Click **Copy as JSON** to copy them. Only appears when the agent extracts data. |
| **Goals** | Whether each goal of the agent was met on this call. If the agent has no goals, you'll see **No goals were evaluated for this call**. |
| **Key Moments** | The most important moments of the call. Each one shows who said it (**User** or **Assistant**), its type (for example **Question**, **Commitment**, **Objection**, **Buying signal**, or **Frustration**), and the exact words. |

<Warning>
  The summary, sentiment, goals, and key moments are generated by AI. As the panel says, they are an **AI-assisted analysis — use as a guide**.
</Warning>

## Download call audio (recording)

The recording player is at the bottom of the **Call Details** panel. From there you can:

- Click **Play** to listen to the call, and use the buttons on each side to skip back or forward.
- Click the speed button (**1.0x**) to change the playback speed: 0.5x, 0.75x, 1x, 1.25x, 1.5x, or 2x.
- Click the **download** icon on the left to **Download Recording**.

<Warning>
  If you don't see the player or the download icon, there's no recording for that call. Recording can be turned off in the agent's settings.
</Warning>
