**E-mail** est la boîte unifiée du Gestionnaire d'e-mails IA. Ouvrez-la depuis la barre latérale gauche, sous **Agents mail**.

Les messages traités par vos agents apparaissent ici, de toutes les boîtes connectées, avec la catégorie de chacun. C'est aussi là que vous relisez, modifiez et envoyez les brouillons préparés par vos agents.

Si vous n'avez pas encore connecté de boîte, l'écran affiche **Connectez une boîte mail pour utiliser l'e-mail** et les trois étapes pour le faire : ouvrez **Agents mail** et sélectionnez un agent, connectez Google, Microsoft ou IMAP dans l'onglet **Boîte mail**, puis revenez ici. Les boutons **Aller aux Agents mail** et **Créer un agent mail** vous y mènent directement.

## Retrouver vos messages

Une fois une boîte connectée :

- **Compte connecté** : choisissez la boîte à afficher.
- Dossiers : **Tous les e-mails**, **Boîte de réception**, **Envoyés**, **Brouillons**, **Suivis**, **Archivés** et **Corbeille**. Sous **Catégories**, vous trouverez les étiquettes de votre agent.
- Filtres : **Tous**, **Non lus**, **À examiner**, **Traités** et **Lus**. **À examiner** affiche les messages qui vous attendent.
- **Trier** : **Plus récents** ou **Plus anciens**.
- **Rechercher par expéditeur, objet ou contenu…** permet de trouver un message.
- **Actualiser les e-mails** charge les derniers messages.

En ouvrant un message, vous verrez quel **Agent e-mail** l'a traité, ainsi que ces actions : **Répondre**, **Répondre à tous**, **Transférer**, **Archiver**, **Supprimer**, **Marquer comme traité** et **Marquer comme lu**.

## Répondre avec l'IA

Cliquez sur **Répondre** pour ouvrir l'éditeur de réponse. Vous pouvez écrire la réponse vous-même ou laisser l'IA l'écrire :

<Steps>
  <Step>
    Choisissez le **Modèle**.
  </Step>
  <Step>
    Choisissez le **Ton** : **Professionnel**, **Amical**, **Concis**, **Empathique**, **Assuré** ou **Formel**.
  </Step>
  <Step>
    Cliquez sur **Générer une réponse**. Relisez et modifiez le brouillon.
  </Step>
  <Step>
    Si le client a écrit dans une autre langue, cliquez sur **Traduire dans la langue de l'expéditeur**.
  </Step>
  <Step>
    Cliquez sur **Envoyer**.
  </Step>
</Steps>

## Crédits pour les brouillons IA

Chaque brouillon IA consomme des crédits de votre solde. Quand vous créez votre premier agent mail, un essai gratuit commence : pendant ces jours, les brouillons IA sont gratuits, et un message indique combien de jours il reste.

Quand votre solde baisse, vous verrez **Le solde de crédits est faible**. S'il est insuffisant, vous verrez **Solde de crédits insuffisant** et aucun nouveau brouillon n'est généré. Cliquez sur **Ajouter des crédits** pour recharger.
