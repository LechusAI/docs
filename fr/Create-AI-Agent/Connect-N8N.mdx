## Aperçu

Créez des automatisations puissantes entre Callin.io et vos outils préférés avec n8n. Callin.io vous fournit votre propre espace n8n sur **n8n.callin.io**, avec un nœud **Callin.io** prêt à l’emploi pour que vos agents IA lancent des appels.

## Étapes

### Étape 1 : Qu’est-ce que n8n et pourquoi l’utiliser avec Callin.io ?

n8n est un outil d’automatisation qui relie différentes applications pour qu’elles fonctionnent ensemble.

Avec Callin.io, cette intégration vous permet de :

- **Déclencher des appels sortants à partir d’événements externes** : par exemple quand un nouveau lead arrive dans votre CRM, quand quelqu’un remplit un formulaire sur votre site ou à une heure planifiée. Le nœud **Callin.io** a une seule action, **Start call**, qui fait appeler un contact par l’un de vos agents IA.
- **Recevoir les données des appels dans n8n** : envoyez les détails de chaque appel terminé vers un workflow n8n avec la **Synchronisation des données (webhook post-appel)** de l’agent (dans son onglet **Action d’appel**), puis vers Slack, Google Sheets, votre CRM, etc.

En bref : n8n transforme les événements de vos autres outils en appels, et les appels en actions dans vos autres outils.

> **Important :** Le nœud **Callin.io** n’a pas de déclencheur propre. Pour démarrer un workflow, utilisez un déclencheur n8n (par exemple **On a Webhook call**, **On a Schedule** ou un déclencheur de votre CRM), puis ajoutez le nœud **Callin.io**.

### Étape 2 : Accéder au panneau d’intégrations Callin.io

1. Connectez-vous à votre compte Callin.io.
2. Dans le menu de gauche, cliquez sur **Intégrations → Actions** ([ouvrir ici](https://app.callin.io/actions)).
3. Utilisez le filtre **Automatisation** (ou parcourez **Toutes**).
4. Trouvez la carte **N8N** et cliquez sur **Aller vers n8n**.

### Étape 3 : Se connecter à votre compte n8n

1. Un nouvel onglet s’ouvre sur **n8n.callin.io**.
2. Saisissez votre **Email** et votre **Password** n8n, puis cliquez sur **Sign in**.
3. Si vous n’avez pas encore d’accès, contactez l’administrateur de votre compte Callin.io.

Une fois connecté, vous voyez l’écran **Overview** de n8n avec vos workflows et le bouton **Create workflow**.

### Étape 4 : Obtenir votre clé API Callin.io

Le nœud **Callin.io** a besoin d’une clé API pour agir sur votre compte.

1. Dans Callin.io, ouvrez votre profil ([app.callin.io/profile](https://app.callin.io/profile)) et allez dans l’onglet **Clés API**.
2. Si vous n’avez pas encore de clé (« Aucune clé API trouvée »), cliquez sur **Régénérer la clé** pour en créer une.
3. Utilisez l’icône de copie pour copier la clé.

### Étape 5 : Créer votre première automatisation

1. Dans n8n, cliquez sur **Create workflow**.
2. Ajoutez un déclencheur qui démarre le workflow (par exemple **On a Webhook call** pour recevoir un nouveau lead depuis votre site ou votre CRM).
3. Cliquez sur **+** pour ajouter l’étape suivante, cherchez **Callin.io** et choisissez l’action **Start call**.

</div>

<p style={{ marginTop:"0", marginBottom:"1.5rem", color:"#6b7280", fontSize:"0.95rem" }}>
  Capture d’écran : le nœud Callin.io dans n8n, avec son action Start call.

4. Dans **Credential**, cliquez sur **Set up credential**, collez votre **Api Key** Callin.io et cliquez sur **Save**.
5. Remplissez les champs de **Start call** :
   - **Phone** : le numéro que l’agent appellera.
   - **Name** : le nom du contact.
   - **Email** : l’email du contact.
   - **Agent Name or ID** : l’agent qui passera l’appel (la liste apparaît une fois l’identifiant configuré).
   - **Webhook Url (optional)** : une URL à laquelle envoyer les données de l’appel.
   - **Additional Fields** : cliquez sur **Add Field** pour envoyer des données supplémentaires sous forme de paires **Field Name** / **Field Value**.

> **Astuce :** Plutôt que de saisir des valeurs fixes, utilisez les expressions n8n pour reprendre les données de l’étape précédente (par exemple `{{ $json.phone }}` pour le téléphone envoyé par votre formulaire ou votre CRM).

### Étape 6 : Activer et tester

1. Cliquez sur **Execute step** (ou **Execute workflow**) pour passer un appel de test vers un vrai numéro que vous contrôlez.
2. Quand tout fonctionne, cliquez sur **Publish** pour que le workflow s’exécute automatiquement.

## Conseils & remarques

- **Utilisez vos données** : avec les expressions n8n, transmettez les valeurs du déclencheur (nom, téléphone, email) aux champs de **Start call**.
- **Logique conditionnelle** : ajoutez des nœuds **IF** ou **Switch** pour des automatisations plus complexes (par exemple n’appeler que les leads d’un pays donné).
- **Recevez les résultats des appels** : collez l’URL d’un déclencheur **On a Webhook call** de n8n dans la **Synchronisation des données (webhook post-appel)** de l’agent pour recevoir dans n8n les détails de chaque appel terminé.
- **Workflows enchaînés** : combinez Callin.io avec des CRM et des outils de messagerie dans un seul processus continu.

## Dépannage

**Symptôme :** La liste **Agent Name or ID** est vide\
**Cause probable :** L’identifiant n’est pas configuré ou la clé API est incorrecte. Configurez de nouveau l’identifiant avec une clé valide de **Profil → Clés API**.

**Symptôme :** Ça ne fonctionne plus après un changement de clé\
**Cause probable :** La clé API a été régénérée. Mettez à jour l’identifiant dans n8n avec la nouvelle clé.

**Symptôme :** Le workflow ne se lance pas\
**Cause probable :** Vérifiez que le workflow est publié et que son déclencheur reçoit bien des données.

**Symptôme :** L’appel n’est pas passé\
**Cause probable :** Vérifiez que **Phone** contient un numéro valide au format international (par exemple `+15550102040`) et qu’un numéro de téléphone est attribué à l’agent.

## Note finale

Connecter Callin.io à n8n ouvre un monde d’automatisation intelligente.\
Commencez simplement, par exemple en appelant chaque nouveau lead qui arrive depuis le formulaire de votre site, et vous verrez vite comment n8n fait de Callin.io un véritable centre d’automatisation.
