## À quoi sert la base de connaissances

La **base de connaissances** est l’endroit où vous stockez des informations que vos agents IA peuvent utiliser pendant les conversations, afin de ne pas dépendre uniquement du prompt principal. Elle convient aux contenus longs ou détaillés, comme des manuels, des FAQ ou des politiques, qui ne tiennent pas dans le prompt.

Cas d’usage typiques :

- Répondre aux questions sur votre activité (services, tarifs, politiques, horaires).
- Guider les utilisateurs dans des démarches (étapes de remboursement, préparation d’un rendez-vous, onboarding).
- Garder des réponses cohérentes entre plusieurs agents.

Accès ici : [Base de connaissances](https://app.callin.io/knowledge-base)

La page comporte deux onglets, en haut à droite :

- **Fichiers** : les documents que vous importez (PDF, DOC, DOCX, TXT), organisés en groupes.
- **Web** : des pages Web (URL) dont l’agent s’inspire, que vous pouvez organiser en dossiers.

<Tip>
  Considérez la base de connaissances comme un « matériel de référence validé » que l’agent peut consulter quand un appelant pose des questions détaillées.
</Tip>

## Comment cela se relie aux agents IA

Vous n’ajoutez pas le contenu directement dans un agent. À la place :

<Steps>
  <Step>
    Vous créez le contenu ici, dans la base de connaissances (fichiers ou URL Web).
  </Step>
  <Step>
    Ensuite, dans l’éditeur de l’agent, vous ouvrez l’onglet **Base de connaissances** et **ajoutez les documents** que cet agent doit utiliser.
  </Step>
</Steps>

Un même document peut être utilisé par plusieurs agents.

## Base de connaissances avec des fichiers

L’onglet **Fichiers** sert à importer les documents dont votre agent doit s’inspirer (par exemple : une politique en PDF, un script en DOCX ou une FAQ en TXT). Les fichiers sont organisés en **groupes**, pour garder ensemble les documents liés.

À côté de **Créer une base de connaissances**, vous pouvez passer d’une vue à l’autre : une **liste** de tous vos fichiers, ou vos **groupes** affichés comme des dossiers. Utilisez **Rechercher des fichiers…** pour trouver un document.

### Créer un groupe de fichiers et importer des documents

<Steps>
  <Step>
    Ouvrez l’onglet **Fichiers**.
  </Step>
  <Step>
    Cliquez sur **Créer une base de connaissances**.
  </Step>
  <Step>
    Dans la fenêtre **Téléverser des fichiers**, saisissez un **Nom du groupe** (obligatoire). Les fichiers importés seront regroupés sous ce nom.
  </Step>
  <Step>
    Ajoutez vos documents :
    - Glissez-déposez les fichiers dans la zone d’import, ou
    - Cliquez sur **Sélectionner des fichiers** pour les parcourir.
  </Step>
  <Step>
    Cliquez sur **Téléverser des fichiers** pour terminer.
  </Step>
</Steps>

Formats et limites pris en charge (tels qu’indiqués dans l’outil d’import) :

- PDF, DOC, DOCX, TXT
- 5MB maximum par fichier

<Frame caption="Capture d’écran : la fenêtre Téléverser des fichiers, où vous nommez le groupe et ajoutez vos documents.">
  <img src="/images/knowledgebase1.png" alt="La fenêtre Téléverser des fichiers avec le champ Nom du groupe, la zone de glisser-déposer avec le bouton Sélectionner des fichiers, les formats pris en charge (PDF, DOC, DOCX, TXT, 5MB maximum par fichier) et le bouton Téléverser des fichiers." />
</Frame>

<Warning>
  **Erreur fréquente :** Mettre plusieurs documents sans lien dans un seul groupe. Si vous avez des usages différents (Ventes vs Support), créez des groupes séparés afin d’associer la bonne connaissance à chaque agent.
</Warning>

### Gérer et mettre à jour les fichiers d’un groupe

Une fois un groupe créé, vous pouvez l’ouvrir pour gérer son contenu :

- Ajouter d’autres documents.
- Voir la liste des **Fichiers actuels** déjà inclus.
- Retirer les fichiers que l’agent ne doit plus consulter.

<Tip>
  Utilisez des noms de groupe clairs comme **« Politiques de support »**, **« Tarifs et forfaits »** ou **« Script d’accueil de la clinique »** pour retrouver facilement les bons documents plus tard.
</Tip>

## Base de connaissances avec des URL Web

L’onglet **Web** sert à faire apprendre votre agent à partir de pages Web. C’est utile quand vos informations de référence se trouvent sur votre site (centre d’aide, documentation, pages de politiques, landing pages).

La liste affiche chaque URL avec son **Nom**, son adresse et sa **Dernière mise à jour**. Utilisez **Rechercher dans la base de connaissances...** pour en trouver une.

### Ajouter une URL

<Steps>
  <Step>
    Ouvrez l’onglet **Web**.
  </Step>
  <Step>
    Cliquez sur **Ajouter une URL**.
  </Step>
  <Step>
    Remplissez :
    - **Dossier parent** : où l’enregistrer. Par défaut, **Base de connaissances (niveau racine)**.
    - **Titre** (obligatoire) : un nom clair pour cette page (par exemple « Page des tarifs »).
    - **URL** (obligatoire) : le lien vers la page Web.
  </Step>
  <Step>
    (Facultatif) Activez l’**Actualisation automatique** pour que Callin relise la page régulièrement. Choisissez ensuite l’**Intervalle** et l’**Unité d’intervalle** (**Jours** ou **Heures**). Par défaut, tous les **7 jours**.
  </Step>
  <Step>
    Cliquez sur **Ajouter l’URL** pour l’enregistrer.
  </Step>
</Steps>

  Activez l’**Actualisation automatique** pour les pages qui changent souvent, comme les tarifs ou les horaires, afin que votre agent réponde toujours avec les informations les plus récentes.

### Organiser les URL en dossiers

Pour regrouper des pages liées (par exemple toutes les pages de votre site), cliquez sur **Créer un dossier** :

<Steps>
  <Step>
    Choisissez le **Dossier parent** (ou laissez **Base de connaissances (niveau racine)**).
  </Step>
  <Step>
    Saisissez le **Nom du dossier** (obligatoire).
  </Step>
  <Step>
    (Facultatif) Activez l’**Actualisation automatique** pour actualiser toutes les URL du dossier à l’intervalle choisi.
  </Step>
  <Step>
    Cliquez sur **Créer un dossier**.
  </Step>
</Steps>

Ensuite, quand vous ajoutez une URL, choisissez ce dossier dans **Dossier parent**.

<Tip>
  Gardez des dossiers ciblés. Par exemple, un dossier pour les pages **« Tarifs et facturation »** et un autre pour les pages **« Politique de remboursement »**.
</Tip>

### Voir, actualiser ou supprimer une URL

Cliquez sur **⋯** à droite d’une URL pour ouvrir son menu :

- **Voir les détails** : ouvre un panneau avec l’**ID du document**, la **Dernière mise à jour**, la **Taille du document**, l’**URL source** et l’**Actualisation automatique**, et à droite le **Contenu de l’URL** (le texte que votre agent lit réellement sur cette page). Cliquez sur **Actualiser le contenu** pour relire la page immédiatement.
- **Copier l’ID** : copie l’ID du document.
- **Supprimer** : retire l’URL de la base de connaissances.

<Frame caption="Capture d’écran : Voir les détails affiche le texte que l’agent lit sur la page.">
  <img src="/images/knowledge-base-details.png" alt="Le panneau de détails d'une URL avec l'ID du document, la dernière mise à jour, la taille du document, l'URL source et l'actualisation automatique à gauche, et le contenu de l'URL avec le bouton Actualiser le contenu à droite." />

<Warning>
  Vérifiez le **Contenu de l’URL** après avoir ajouté une page. S’il est vide ou affiche un mauvais texte (par exemple un bandeau de cookies), l’agent ne pourra pas utiliser cette page. Essayez une autre URL avec les mêmes informations.
</Warning>

## Sélectionner une base de connaissances pour un agent

Une fois vos documents ajoutés (fichiers ou URL Web), vous les associez à un agent dans l’éditeur de l’agent.

<Frame caption="Capture d’écran : ajouter un document de la base de connaissances pendant la modification d’un agent IA.">
  <img src="/images/knowledgebase3.png" alt="L'onglet Base de connaissances de l'agent avec la liste Ajouter un document ouverte : une recherche, les documents de la base de connaissances et un bouton Ajouter un document en bas." />
</Frame>

### Associer un groupe à un agent

<Steps>
  <Step>
    Allez dans **Agents IA** et ouvrez un agent à modifier.
  </Step>
  <Step>
    Ouvrez l’onglet **Base de connaissances**.
  </Step>
  <Step>
    Cliquez sur **Ajouter un document**.
  </Step>
  <Step>
    Utilisez **Rechercher des documents...** pour trouver le document voulu, puis cliquez dessus pour l’ajouter à l’agent.
  </Step>
  <Step>
    Répétez pour chaque document dont l’agent a besoin.
  </Step>
</Steps>

Si le document dont vous avez besoin n’existe pas encore, cliquez sur **Ajouter un document** en bas de la liste. Vous arrivez sur la page **Base de connaissances** pour le créer.

<Tip>
  Si vous avez plusieurs agents avec des rôles différents, donnez à chacun uniquement les documents dont il a besoin, pour qu’ils restent ciblés et ne répondent pas hors de leur périmètre.
</Tip>

## Exemple concret

Imaginons que vous gériez un cabinet dentaire avec deux agents :

- **Agent d’accueil** (rendez-vous, horaires, accès)
- **Agent de facturation** (tarifs, factures, questions d’assurance)

Une bonne configuration pourrait être :

- Groupe de fichiers : **« FAQ du cabinet (TXT) »** pour des réponses rapides et des scripts
- Dossier Web : **« Pages tarifs et assurances »** avec les pages publiques de votre site, avec l’**Actualisation automatique** activée

Ensuite :

- L’**Agent d’accueil** reçoit les documents de la FAQ.
- L’**Agent de facturation** reçoit les pages tarifs et assurances.
