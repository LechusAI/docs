## Avant de commencer

Make (anciennement Integromat) est une plateforme d’automatisation visuelle qui relie Callin.io à des milliers d’applications sans coder.\
Dans Make, les automatisations s’appellent des **scénarios**. Chaque scénario relie des modules, et chaque module est une étape de votre processus.

L’application Callin.io sur Make vous offre :

- **Un déclencheur, Surveiller la transcription** (« Obtenez les résultats de vos tâches ») : il lance un scénario chaque fois que Callin.io envoie les résultats d’un appel.
- **Une action, Activer un agent** (« Active un agent pour passer des appels ») : elle met au travail l’un de vos agents Callin.io depuis une autre application, par exemple pour appeler un nouveau lead.

Vous pouvez ainsi :

- Recevoir automatiquement les transcriptions des appels.
- Déclencher des appels sortants depuis votre CRM ou vos formulaires web.
- Enregistrer les données d’appels dans des feuilles de calcul ou des bases de données.
- Prévenir votre équipe à la fin d’un appel.

<Note>
  La page de l’application Callin.io sur Make est en anglais. Dans ce guide, les noms des modules et des boutons sont traduits : à l’écran, vous pouvez les voir en anglais.
</Note>

## Étape 1. Accéder au panneau des intégrations dans Callin.io

<Steps>
  <Step>
    Connectez-vous à votre [compte Callin.io](https://app.callin.io).
  </Step>
  <Step>
    Dans le menu de gauche, ouvrez **Intégrations → Actions** ([ouvrir ici](https://app.callin.io/actions)).
  </Step>
  <Step>
    Utilisez le filtre **Automatisation** (ou parcourez **Toutes**), trouvez **Make.com** et cliquez sur **Connecter**.
  </Step>
</Steps>

Un nouvel onglet s’ouvre sur Make pour terminer la configuration.

## Étape 2. Créer un compte Make ou se connecter

Si vous avez déjà un compte Make, connectez-vous comme d’habitude.\
Sinon, vous pouvez en créer un gratuitement sur [make.com](https://www.make.com).

Une fois connecté, vous voyez la page de l’application **Callin.io**, partagée par l’équipe Callin.io. Elle présente le déclencheur et l’action proposés par l’application. Cliquez sur **Installer** pour ajouter l’application à votre organisation Make.

## Étape 3. Récupérer votre clé API dans Callin.io

Make a besoin de votre clé API pour authentifier votre compte Callin.io.

<Steps>
  <Step>
    Ouvrez votre [profil Callin.io](https://app.callin.io/profile?subSection=api) et allez dans l’onglet **Clés API**.
  </Step>
  <Step>
    Si vous n’avez pas encore de clé (« Aucune clé API trouvée »), cliquez sur **Régénérer la clé** pour en créer une.
  </Step>
  <Step>
    Utilisez l’icône de copie pour copier la clé.
  </Step>
</Steps>

Gardez votre clé API en sécurité. Si elle est compromise, régénérez-la immédiatement. En la régénérant, l’ancienne clé cesse de fonctionner : vous devrez donc mettre à jour la connexion dans Make.

## Étape 4. Connecter Callin.io à Make

<Steps>
  <Step>
    Dans votre scénario Make, cliquez sur l’icône **+** et cherchez **Callin.io**.
  </Step>
  <Step>
    Choisissez un module : **Surveiller la transcription** ou **Activer un agent**.
  </Step>
  <Step>
    Quand Make demande une connexion, cliquez sur **Ajouter**, collez votre clé API et cliquez sur **Enregistrer**.
  </Step>
</Steps>

Votre compte Callin.io apparaît alors comme connecté, et vous pouvez réutiliser cette connexion dans n’importe quel module Callin.io.

## Étape 5. Créer votre premier scénario

Créons un exemple simple : enregistrer la transcription de chaque appel dans Google Sheets.

<Steps>
  <Step>
    Dans Make, cliquez sur **Créer un nouveau scénario**.
  </Step>
  <Step>
    Ajoutez **Callin.io – Surveiller la transcription** comme premier module (le déclencheur).
  </Step>
  <Step>
    Ajoutez un second module : **Google Sheets – Ajouter une ligne**.
  </Step>
  <Step>
    Choisissez votre feuille et associez les champs de Callin.io aux colonnes de la feuille.
  </Step>
  <Step>
    Enregistrez le scénario et activez-le.
  </Step>
</Steps>

Désormais, chaque appel terminé enverra automatiquement sa transcription dans votre feuille.

## Configuration avancée

Avec Make, vous pouvez combiner plusieurs modules et conditions pour créer des automatisations puissantes :

- **Lancer vos agents depuis d’autres applications** : ajoutez **Callin.io – Activer un agent** après un déclencheur de votre CRM ou de votre formulaire, pour qu’un agent appelle chaque nouveau lead.
- Envoyer des notifications Slack quand certains critères sont remplis.
- Stocker les transcriptions dans Google Drive ou un autre service cloud.

La connexion se lance depuis [Intégrations → Actions → Make.com](https://app.callin.io/actions) dans votre tableau de bord Callin.io, et les scénarios se gèrent dans Make.

## Problèmes courants et solutions

**La connexion échoue en saisissant la clé API.**\
Vérifiez qu’il n’y a pas d’espaces en trop au moment de la coller. Si le problème persiste, régénérez la clé depuis la [section Clés API](https://app.callin.io/profile?subSection=api) et mettez à jour la connexion dans Make.

**Je ne trouve pas Callin.io en cherchant dans Make.**\
Installez d’abord l’application : cliquez sur **Connecter** sur **Make.com** dans [Intégrations → Actions](https://app.callin.io/actions), puis sur **Installer** sur la page de l’application Callin.io.

**Le scénario ne reçoit pas de données.**\
Vérifiez que le premier module est **Callin.io – Surveiller la transcription** et que le scénario est activé.

**Le scénario ne s’exécute pas automatiquement.**\
Assurez-vous qu’il est enregistré et activé. Vous pouvez le tester manuellement avec **Exécuter une fois**.

## Note finale

Intégrer Callin.io à Make vous permet de concevoir visuellement des flux sur mesure et d’automatiser facilement vos tâches de communication.\
Dès que votre premier scénario fonctionne, vous verrez combien il est simple de l’étendre et de connecter Callin.io à tous les outils que vous utilisez au quotidien.
