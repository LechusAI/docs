## Vue d’ensemble

Les numéros de téléphone font le lien entre vos agents IA et les vrais appels. Dans Callin.io, vous les gérez à deux endroits :

- **Numéros** : achetez des numéros via Callin.io, importez-les depuis d’autres fournisseurs ou vérifiez un numéro personnel.
- **BYOC (tronc SIP)** : utilisez votre propre opérateur en connectant Telnyx ou n’importe quel fournisseur SIP.

Utilisez ces raccourcis pour accéder directement à l’application :

- Aller dans **Numéros** : [Ouvrir Numéros](https://app.callin.io/numbers)
- Aller dans **BYOC (tronc SIP)** : [Ouvrir BYOC](https://app.callin.io/byoc)

<Tip>
  Pour démarrer vite, achetez un numéro des **États-Unis ou du Canada** (c’est instantané). Si vous avez besoin d’un numéro international, préparez-vous à fournir des documents (les règles varient selon le pays).
</Tip>

## Numéros

La page **Numéros** affiche tous les numéros connectés à votre espace de travail (achetés, importés, personnels, Telnyx ou BYOC). Depuis cette page, vous pouvez ajouter des numéros et vérifier l’état de chacun.

### Ce que vous pouvez faire depuis Numéros

La page comporte deux onglets :

- **Numéros** : tous les numéros de votre espace de travail, avec leur **Type** et leur **Statut** (par exemple, la date d’ajout et la date de renouvellement).
- **Demandes de Numéros** : vos demandes d’achat pour les pays hors États-Unis et Canada. Voir la section **Suivre vos demandes**, plus bas.

Quand vous cliquez sur **+ Ajouter un numéro**, vous voyez ces options :

- **Acheter un numéro** (via Callin.io)
- **Importer depuis Twilio**
- **Ajouter un numéro personnel**
- **Ajouter un numéro Telnyx** (après avoir connecté Telnyx)

Utilisez les filtres **Tout**, **Acheté**, **Twilio**, **Personnel**, **Telnyx** et **BYOC (Tronc SIP)**, ou le champ **Rechercher des numéros…**, pour trouver rapidement ce que vous cherchez.

### Option A : Acheter un numéro via Callin.io

Acheter des numéros via Callin.io est la façon la plus simple de commencer.

#### États-Unis et Canada : achat instantané

Pour les **États-Unis** et le **Canada**, l’achat est instantané :

<Frame caption="Vidéo : + Ajouter un numéro → Acheter un numéro → Rechercher des numéros → sélectionner un numéro.">
  <video autoPlay muted loop playsInline src="/images/numbers-purchase.mp4" />
</Frame>

<Steps>
  <Step>
    Allez dans [Ouvrir Numéros](https://app.callin.io/numbers).
  </Step>
  <Step>
    Cliquez sur **+ Ajouter un numéro** → **Acheter un numéro**.
  </Step>
  <Step>
    Choisissez le **Pays**. Vous pouvez rechercher dans la liste par nom, code ISO ou indicatif.
  </Step>
  <Step>
    Choisissez un type :
    - **Local** : indicatif régional standard.
    - **Gratuit** : préfixes comme 800 ou 888.
  </Step>
  <Step>
    (Facultatif) Utilisez **Rechercher par indicatif régional** (exemple : `415`).
  </Step>
  <Step>
    Cliquez sur **Rechercher des numéros**.
  </Step>
  <Step>
    Sélectionnez un numéro dans la liste. Chacun indique son État ou sa province (par exemple, `NV`).
  </Step>
  <Step>
    Cliquez sur **Acheter le numéro sélectionné**.
  </Step>
</Steps>

<Warning>
  Après l’achat, le numéro doit apparaître dans votre liste. Si vous voyez l’avertissement **Ce numéro n’est attribué à aucun agent**, vous devez encore l’attribuer à un agent avant de l’utiliser.
</Warning>

#### Autres pays : demande + documentation

<Frame caption="Capture d’écran : pour les pays hors États-Unis et Canada, vous choisissez le type de demande et un numéro, puis cliquez sur Démarrer la demande pour charger les documents du pays.">
  <img src="/images/numbers13.png" alt="Fenêtre Acheter un nouveau numéro pour l’Espagne, avec les options de Type de demande Nouveau numéro et Portage, la liste des numéros disponibles, la note Exigences documentaires et le bouton Démarrer la demande." />
</Frame>

Pour les pays **hors États-Unis et Canada**, l’achat suit un parcours **sur demande** plutôt qu’un achat instantané :

<Steps>
  <Step>
    Cliquez sur **+ Ajouter un numéro** → **Acheter un numéro** et choisissez le **Pays**.
  </Step>
  <Step>
    Choisissez le **Type de demande** :
    - **Nouveau numéro** : obtenir un nouveau numéro.
    - **Portage** : conserver votre numéro actuel (voir plus bas).
  </Step>
  <Step>
    Choisissez l’un des **numéros** disponibles. Chacun indique l’opérateur qui le fournit (par exemple, **telnyx**). Selon le pays, vous pouvez aussi choisir le type de numéro (par exemple **Local** ou **Mobile**).
  </Step>
  <Step>
    Cliquez sur **Démarrer la demande**. La plateforme charge alors les informations et les **Exigences documentaires** propres au pays.
  </Step>
  <Step>
    Remplissez les champs obligatoires, téléversez les documents et enregistrez chaque élément.
  </Step>
  <Step>
    Envoyez la demande et payez les frais éventuels. Un opérateur examine ensuite la demande.
  </Step>
</Steps>

Vous pouvez suivre toutes vos demandes dans l’onglet **Demandes de Numéros**.

##### Porter un numéro existant

Le **Portage** vous permet de transférer un numéro que vous avez déjà chez un autre fournisseur, pour que vos clients continuent d’appeler le même numéro.

<Steps>
  <Step>
    Dans **Acheter un nouveau numéro**, choisissez le **Pays** et sélectionnez **Portage** comme **Type de demande**.
  </Step>
  <Step>
    Saisissez votre numéro dans **Numéro à porter** et cliquez sur **Vérifier la portabilité**.
  </Step>
  <Step>
    Si le numéro peut être porté, cliquez sur **Démarrer la demande** et complétez les **Exigences documentaires**, comme pour un nouveau numéro.
  </Step>
</Steps>

<Tip>
  Le portage prend généralement plus de temps que l’achat d’un nouveau numéro, car votre fournisseur actuel doit le libérer. Ne résiliez pas votre ligne actuelle avant que le numéro n’apparaisse dans votre liste **Numéros**.
</Tip>

Cette étape est importante, car les exigences ne sont pas toujours les mêmes. Elles peuvent changer selon le **pays**, le **type de numéro** et selon que la demande est faite par un **particulier**, une **entreprise individuelle** ou une **société**.

##### Comment fonctionne l’étape de documentation

Après avoir cliqué sur **Démarrer la demande**, le formulaire peut afficher une combinaison de :

- Champs de texte à remplir manuellement
- Champs de téléversement pour les justificatifs
- Un bouton **Enregistrer** pour chaque exigence
- Un statut **En attente** tant que l’élément n’est pas correctement enregistré ou téléversé

La demande se complète donc généralement **élément par élément**, et non d’un seul coup. Si un champ ou un téléversement affiche encore **En attente**, cette exigence n’est normalement pas encore remplie.

Dans de nombreux pays avec demande, le formulaire peut demander des informations comme :

- **Type de pièce d’identité**
- **Numéro de la pièce d’identité**
- **Date de naissance**
- **Lieu de naissance**
- **Autorité de délivrance de la pièce d’identité**
- **Date d’expiration de la pièce d’identité**
- **Adresse locale dans le même pays**
- **Code fiscal personnel**
- **Numéro de TVA**
- **Code fiscal de l’entreprise**
- **Type de client IT**
- **Justificatif de domicile**
- **Copie du passeport/de la pièce d’identité**
- **Certificat d’immatriculation de l’entreprise**

Certaines étiquettes précisent aussi qui doit fournir chaque élément, par exemple :

- **Pour les personnes morales uniquement**
- **Pour les personnes morales et les entreprises individuelles uniquement**
- **Pour les personnes physiques et les entreprises individuelles uniquement**

Ainsi, même si deux clients demandent des numéros dans le même pays, les documents requis peuvent varier selon le type d’activité et la catégorie exacte du numéro.

<Tip>
  Dans le formulaire de demande, certains champs ont leur propre bouton **Enregistrer**. Saisir une valeur ne suffit pas toujours : l’élément peut continuer d’afficher **En attente** tant que vous n’avez pas cliqué sur **Enregistrer**.
</Tip>

##### Exigences documentaires courantes (exemples)

Les exigences exactes dépendent du pays et du type de numéro, mais on peut vous demander des éléments comme :

| Exigence | Ce que cela signifie | Exemple |
| --- | --- | --- |
| Adresse correspondant à l’indicatif du numéro | Il peut vous falloir une adresse dans la même ville, région ou zone de couverture que le numéro demandé | « Via Roma 22, Milan » pour un numéro local de Milan |
| Pièce d’identité / numéro fiscal | Identification personnelle ou professionnelle pour valider le demandeur | Numéro de passeport, carte d’identité, code fiscal, numéro de TVA |
| Coordonnées | Une personne ou un contact d’entreprise joignable pour la demande | « Luca Bianchi, +39 345 000 1111 » |
| Justificatif de domicile (téléversement) | Un document montrant l’adresse saisie dans la demande | Facture d’énergie, relevé bancaire, bail ou courrier officiel de l’administration |
| Copie du passeport/de la pièce d’identité (téléversement) | Vérification d’identité d’un particulier ou d’un représentant de l’entreprise | Scan du passeport ou copie recto verso de la carte d’identité |
| Certificat d’entreprise (téléversement) | Preuve que l’entreprise est légalement immatriculée | Statuts, extrait Kbis ou équivalent |
| Code fiscal de l’entreprise / numéro de TVA | Informations fiscales de l’entreprise pour les demandes professionnelles | Numéro de TVA ou numéro fiscal de l’entreprise |
| Date et lieu de naissance | Données d’identification personnelle exigées dans certains pays | « 14 mars 1988, Naples » |
| Autorité de délivrance et date d’expiration de la pièce d’identité | Informations sur l’autorité qui l’a délivrée et sa validité | « Délivrée par la Comune di Torino, expire en 08/2028 » |

##### Justificatif de domicile : ce qui pose le plus souvent problème

Le **justificatif de domicile** est l’une des causes les plus fréquentes de retard d’une demande.

Dans de nombreux pays, le justificatif téléversé doit remplir toutes ces conditions :

- Afficher clairement le **même nom** que dans la demande, ou le nom de l’entreprise si la demande est professionnelle
- Afficher clairement la **même adresse** que celle saisie dans le formulaire
- Être **récent**
- Être complet et lisible
- Ne pas être recadré au point de masquer des informations importantes

Une règle très importante : la facture ou le justificatif doit souvent dater de **moins de 3 mois** au moment de l’envoi.

Il faut donc généralement téléverser un document récent comme :

- Une facture d’énergie des 3 derniers mois
- Un relevé bancaire des 3 derniers mois
- Un courrier officiel de l’administration ou des impôts des 3 derniers mois

Les documents plus anciens peuvent être refusés même si l’adresse est correcte.

<Warning>
  Quand vous téléversez une facture ou un relevé bancaire comme justificatif de domicile, vérifiez qu’il date de **moins de 3 mois**. S’il est plus ancien, la demande peut rester en attente ou être refusée lors de l’examen.
</Warning>

##### Comment préparer les documents avant le téléversement

Pour éviter les retards, vérifiez chaque document avant de le téléverser.

Un bon document doit être :

- **Clair et lisible**
- **Complet**, sans bords coupés
- **Cohérent** avec les données saisies dans le formulaire
- **Récent**, surtout pour les justificatifs de domicile
- **Adapté** au type de demandeur, particulier ou entreprise

Par exemple, si la demande concerne une entreprise, l’examinateur peut s’attendre à ce que le nom de l’entreprise, son numéro d’immatriculation, ses informations fiscales et ses documents d’immatriculation concordent. Pour un particulier, il peut vérifier que le nom, la pièce d’identité et le justificatif de domicile concordent.

Problèmes fréquents qui ralentissent l’approbation :

- L’adresse du formulaire ne correspond pas au document téléversé
- La facture téléversée a plus de 3 mois
- La copie du passeport ou de la pièce d’identité est floue
- Une demande d’entreprise est envoyée avec uniquement des documents personnels
- Un champ est rempli, mais l’utilisateur n’a pas cliqué sur **Enregistrer**
- Un document a été téléversé, mais son statut affiche toujours **En attente**

<Warning>
  **Erreur fréquente :** Téléverser le bon fichier ne suffit pas toujours. Après chaque téléversement ou saisie, vérifiez que l’exigence n’affiche plus **En attente**.
</Warning>

##### Frais + révision

Certains pays affichent une étape de **paiement** une fois la documentation terminée. Elle peut inclure :

- Des **frais d’activation uniques**
- Le **coût mensuel** du numéro

La demande n’avance généralement qu’une fois les documents requis téléversés et le paiement effectué.

Après l’envoi et le paiement :

- Vous recevez un **ID de demande**
- Un opérateur examine la demande
- Une fois approuvé, le numéro apparaît dans votre liste **Numéros**

L’examen est souvent manuel, c’est pourquoi l’approbation n’est pas toujours immédiate.

<Warning>
  Le délai d’approbation varie selon le pays, les règles du fournisseur et la qualité des documents. Si vous avez besoin du numéro pour un lancement ou une campagne, envoyez la demande le plus tôt possible avec des documents récents et bien lisibles.
</Warning>

### Suivre vos demandes (Demandes de Numéros)

L’onglet **Demandes de Numéros** liste vos demandes d’achat et de portage pour les pays hors États-Unis et Canada.

<Frame caption="Capture d’écran : chaque carte est une demande. Utilisez les filtres pour trouver celles qui demandent votre attention.">
  <img src="/images/numbers-requests.png" alt="Onglet Demandes de Numéros avec les filtres Statut, Flux et Statut du Paiement, le bouton Actualiser et une carte par demande indiquant le pays, le statut, le type de numéro, le flux, le numéro choisi, la date et le statut du paiement." />
</Frame>

Chaque carte indique le **pays**, le **statut** de la demande, le **Type de Numéro**, le **Flux**, le **Numéro Choisi**, la date et le statut du paiement.

Utilisez les filtres pour affiner la liste :

| Filtre | Options |
| --- | --- |
| **Statut** | **Brouillon**, **En attente**, **Approuvé**, **Info requise**, **Rejeté**, **Terminé**, **Annulé** |
| **Flux** | **Commande** (nouveau numéro), **Portage** (numéro existant) |
| **Statut du Paiement** | **Dû**, **Payé** |

Cliquez sur **Actualiser** pour voir le statut le plus récent.

<Tip>
  Consultez régulièrement cet onglet tant qu’une demande est ouverte. Une demande en **Info requise** attend que vous corrigiez ou ajoutiez quelque chose, et **Paiement Dû** signifie qu’elle n’avancera pas tant que vous n’aurez pas payé.
</Tip>

### Option B : Importer des numéros depuis Twilio

Si vous avez déjà des numéros chez Twilio, vous pouvez les importer dans Callin.io :

<Steps>
  <Step>
    Allez dans [Ouvrir Numéros](https://app.callin.io/numbers).
  </Step>
  <Step>
    Cliquez sur **+ Ajouter un numéro** → **Importer depuis Twilio**.
  </Step>
  <Step>
    Saisissez votre **Twilio Account SID** et votre **Twilio Auth Token**.
  </Step>
  <Step>
    Cliquez sur **Rechercher les numéros Twilio** et sélectionnez les numéros à importer.
  </Step>
  <Step>
    Attribuez les numéros importés à un agent IA quand vous voulez les utiliser.
  </Step>
</Steps>

<Warning>
  **Erreur fréquente :** Copier les mauvais identifiants Twilio (par exemple, ceux de test au lieu des identifiants réels). Si aucun numéro n’apparaît, vérifiez votre projet Twilio et ses autorisations.
</Warning>

### Option C : Ajouter un numéro personnel (appels sortants uniquement)

Un **numéro personnel** est utile pour passer des appels sortants depuis votre propre numéro, mais il ne peut pas recevoir d’appels entrants dans Callin.io.

<Frame caption="Capture d’écran : la fenêtre Ajouter un numéro personnel, avec le champ du téléphone et le processus de vérification (vous recevez un appel et saisissez le code).">
  <img src="/images/numbers2.png" alt="Fenêtre Ajouter un numéro personnel avec le sélecteur de pays, le champ du téléphone, le message de numéro invalide et les étapes du processus de vérification." />

#### Comment vérifier votre numéro personnel

<Steps>
  <Step>
    Allez dans [Ouvrir Numéros](https://app.callin.io/numbers).
  </Step>
  <Step>
    Cliquez sur **+ Ajouter un numéro** → **Ajouter un numéro personnel**.
  </Step>
  <Step>
    Sélectionnez l’indicatif du pays et saisissez votre numéro de téléphone.
  </Step>
  <Step>
    Cliquez sur **Vérifier le numéro**.
  </Step>
  <Step>
    Vous recevez un **appel de vérification** de Twilio.
  </Step>
  <Step>
    Saisissez le code de vérification quand il vous est demandé.
  </Step>
  <Step>
    Après la vérification, le numéro est ajouté à votre compte.
  </Step>
</Steps>

<Warning>
  Les numéros personnels servent **uniquement aux appels sortants**. Si vous devez recevoir des appels, utilisez un numéro acheté ou importé, ou BYOC.
</Warning>

### Option D : Ajouter/importer des numéros Telnyx

Si votre compte Telnyx est connecté (via BYOC), vous pouvez importer vos numéros Telnyx actifs dans Callin.io :

<Steps>
  <Step>
    Allez dans [Ouvrir Numéros](https://app.callin.io/numbers).
  </Step>
  <Step>
    Cliquez sur **+ Ajouter un numéro** → **Ajouter un numéro Telnyx**.

  <Step>

### Gérer vos numéros

Dans la liste **Numéros**, cliquez sur le menu **⋮** d’un numéro pour le gérer :

- **Modifier l’étiquette** : donnez au numéro un nom reconnaissable, par exemple le client ou la campagne concernés.
- **Annuler l’abonnement** (numéros achetés) : arrêtez le renouvellement d’un numéro acheté via Callin.io.
- **Supprimer** (numéros personnels) : retirez un numéro personnel de votre compte.

<Warning>
  Avant d’annuler ou de supprimer un numéro, attribuez un autre numéro aux agents qui l’utilisent, pour qu’ils puissent continuer à passer et recevoir des appels.
</Warning>

### Attribuer un numéro à un agent

Acheter ou importer un numéro n’est que la première étape : votre agent doit encore l’utiliser. Si la liste **Numéros** affiche **Ce numéro n’est attribué à aucun agent**, attribuez-le avant la mise en service :

<Steps>
  <Step>
    Allez dans **Agents IA**.
  </Step>
  <Step>
    Cliquez sur le menu **⋮** de l’agent et choisissez **Attribuer un numéro**.
  </Step>
  <Step>
    Dans la fenêtre d’attribution, trouvez le numéro (vous pouvez rechercher par numéro, étiquette ou opérateur) et cliquez sur **Attribuer**.
  </Step>
</Steps>

<Frame caption="Capture d’écran : la fenêtre Attribuer un numéro indique quels numéros sont libres et lesquels sont déjà utilisés par un autre agent.">
  <img src="/images/numbers-assign.png" alt="Fenêtre Attribuer un numéro d’un agent, avec la liste des numéros, leur statut (attribué à un autre agent ou non attribué), l’opérateur et un bouton Attribuer, ainsi que le lien pour acheter de nouveaux numéros." />
</Frame>

La colonne **Statut** indique si chaque numéro est **Non attribué** ou déjà attribué à un autre agent. Si vous n’avez pas de numéro adapté, cliquez sur le lien pour **acheter de nouveaux numéros**.

<Warning>
  **Erreur fréquente :** Attribuer un numéro déjà utilisé par un autre agent. Comme la fenêtre l’indique, l’attribuer ici **le détachera de l’autre agent**, qui cessera de l’utiliser.
</Warning>

<Tip>
  Gardez un numéro « de test » séparé de celui de production pendant que vous ajustez les instructions et les parcours d’appel.
</Tip>

## BYOC (tronc SIP)

**BYOC** signifie *Bring Your Own Carrier*, c’est-à-dire utiliser votre propre opérateur. Au lieu d’acheter des numéros via Callin.io, vous connectez votre fournisseur de téléphonie avec un tronc SIP.

Raisons habituelles d’utiliser BYOC :

- Vous avez déjà un contrat avec un opérateur (téléphonie d’entreprise)
- Vous avez besoin d’un routage sur mesure, de contrôler le SBC ou de respecter des contraintes réglementaires
- Vous voulez éviter les règles de la téléphonie gérée par Callin en utilisant votre propre fournisseur

Configurez-le ici : [Ouvrir BYOC](https://app.callin.io/byoc)

<Frame caption="Capture d’écran : la configuration BYOC, où vous pouvez connecter Telnyx et synchroniser vos numéros avec Callin.io.">
  <img src="/images/byoc1.png" alt="Page BYOC sur l’onglet Telnyx, avec le champ Clé API Telnyx, le bouton Démarrer et les étapes de configuration : enregistrer la clé, récupérer les numéros, les enregistrer, provisionner le tronc SIP et créer les numéros de téléphone." />
</Frame>

### Qu’est-ce qu’un tronc SIP (simplement)

Un **tronc SIP** est une connexion entre un opérateur téléphonique et votre système d’appels. Voyez-le comme une « ligne téléphonique par internet » qui gère les appels entrants et sortants, très utilisée par les entreprises.

---

### Option 1 : Connecter Telnyx

Si vous utilisez **Telnyx**, Callin.io vous guide dans la configuration avec une clé API :

<Steps>
  <Step>
    Allez dans [Ouvrir BYOC](https://app.callin.io/byoc).
  </Step>
  <Step>
    Sélectionnez l’onglet **Telnyx**.
  </Step>
  <Step>
    Collez votre **Clé API Telnyx**.
  </Step>
  <Step>
    Cliquez sur **Démarrer**.
  </Step>
</Steps>

Pendant la configuration, vous verrez des étapes comme :

- Enregistrement de la clé API Telnyx
- Récupération des numéros Telnyx actifs (DID)
- Enregistrement des numéros dans votre compte Callin.io
- Provisionnement du tronc SIP (entrant et sortant)
- Création des numéros de téléphone du fournisseur

Une fois terminé, vos numéros Telnyx doivent apparaître dans **Numéros**.

<Warning>
  Si votre clé Telnyx n’a pas l’autorisation de lire les numéros (DID), Callin.io ne pourra pas les récupérer.
</Warning>

### Option 2 : Connecter un autre fournisseur (trunk SIP générique)

Si votre fournisseur n’est pas Telnyx, utilisez l’onglet **Autre fournisseur SIP** (**Trunk SIP générique / Extension PBX (tout fournisseur)**). Il fonctionne avec un numéro de tronc SIP (DID) et aussi avec une **extension de votre standard téléphonique** (PBX). Vous configurerez trois onglets : **Basique**, **Entrant** et **Sortant**.

  <img src="/images/byoc-sip.png" alt="Onglet Autre fournisseur SIP dans BYOC, avec les onglets Basique, Entrant et Sortant, les champs Étiquette et Numéro de téléphone / Extension, les cases pour les appels entrants et sortants, et les boutons Enregistrer et importer et Réinitialiser." />
</Frame>

#### Base

- **Étiquette** : un nom facile à reconnaître (exemple : « Tronc SIP siège »)
- **Numéro de téléphone / Extension (E.164 ou extension)** : le numéro complet au format international (exemple : `+15551234567`) ou l’extension du standard (exemple : `101`)
- **Prend en charge l’entrée** et **Prend en charge la sortie** : cochez les sens d’appel que ce numéro gérera

#### Entrant

Les appels entrants vont de l’opérateur vers votre système.

- **SBC / FQDN entrant** : votre adresse SIP (exemple : `sip.example.com:5061`)
- **Transport** : **TLS**, **TCP** ou **UDP**
- **Chiffrement des médias** : **Autorisé**, **Requis** ou **Désactivé**

<Tip>
  Les appels entrants ne nécessitent souvent **pas** d’identifiants. De nombreux opérateurs les authentifient par liste d’adresses IP autorisées ou par la configuration du tronc.
</Tip>

#### Sortant

Les appels sortants vont de Callin.io vers votre opérateur.

- **SBC / FQDN sortant** : le serveur SIP de votre fournisseur
- **Transport** et **Chiffrement des médias** (mêmes options que pour l’entrant)
- **Nom d’utilisateur** et **Mot de passe** : vos identifiants SIP
- **Pays autorisés (sortants)** : **Monde entier** ou une **Liste personnalisée**

Une fois terminé, cliquez sur **Enregistrer et importer**. Pour tout recommencer, cliquez sur **Réinitialiser**.

Après l’enregistrement, Callin.io vérifie que le numéro peut être utilisé pour appeler. Si vos paramètres SIP doivent être corrigés, des indications s’affichent sur cette page. En attendant, le numéro peut quand même apparaître dans votre liste **Numéros**.

<Warning>
  **Erreur fréquente :** Utiliser un SBC/FQDN ou des identifiants incorrects. Si les appels sortants échouent, vérifiez votre nom d’utilisateur et votre mot de passe SIP, et si votre fournisseur exige un port ou un transport précis.
</Warning>

## Minutes et facturation (l’essentiel)

La facturation peut avoir deux parties : l’**utilisation de Callin** et les **frais de l’opérateur téléphonique**. Ce que vous voyez dépend de la façon dont vous connectez vos numéros.

### Minutes de traitement Callin

Les **minutes de traitement** correspondent au temps pendant lequel votre agent IA est actif (il écoute, traite et répond). C’est l’indicateur principal d’utilisation des appels avec IA.

### Avis important de facturation (première minute)

Quand vous passez des appels avec la **téléphonie gérée par Callin** (par exemple, des numéros achetés via Callin.io et acheminés par l’opérateur de Callin), une règle de **facturation de la première minute** s’applique :

- La facturation minimale est de **1 minute**
- Après la première minute, la facturation suit la durée réelle de l’appel
- Cette règle **ne s’applique pas** :
  - Aux **appels de test dans le navigateur**
  - À la **numérotation propre importée** (Telnyx ou Twilio)
  - Au **tronc SIP externe (BYOC)**

<Warning>
  Le comportement exact peut varier selon votre configuration et le routage du fournisseur. Si vous voulez éviter les règles de la téléphonie gérée par Callin, importez vos propres numéros ou utilisez BYOC.
</Warning>

### Rappel : facturation avec un numéro personnel

Les numéros personnels servent **uniquement aux appels sortants**, et les appels passés avec un numéro personnel peuvent quand même relever des règles de la téléphonie gérée par Callin, selon l’acheminement des appels de votre compte.

## Dépannage

### “Je n’arrive pas à passer des appels”

- Vérifiez que vous avez au moins **un numéro actif**
- Assurez-vous que le numéro est **attribué à un agent**
- Si vous utilisez BYOC, vérifiez les paramètres de votre tronc SIP (SBC/FQDN, transport, identifiants)

### “Mon agent ne répond pas aux appels entrants”

- Vérifiez que le numéro est **attribué à l’agent** : allez dans **Agents IA**, ouvrez le menu **⋮** de l’agent et choisissez **Attribuer un numéro** (voir « Attribuer un numéro à un agent », plus haut)
- Vérifiez la **Direction d'appel** dans l’onglet **Agent** : elle doit être sur **Entrant** ou **Les deux**. Les nouveaux agents commencent en **Sortant**, et un agent sortant ne répond pas aux appels entrants
- Il n’est pas nécessaire d’avoir des règles de transfert pour que l’agent réponde

### “Mon numéro personnel ne reçoit pas d’appels entrants”

- C’est normal : **les numéros personnels servent uniquement aux appels sortants**
- Utilisez un numéro acheté ou importé, ou BYOC, pour recevoir des appels

### “Le nom de mon entreprise peut-il s’afficher sur les appels sortants (CNAM) ?”

- Le nom de l’appelant (CNAM) est enregistré auprès de l’opérateur du numéro, pas dans Callin
- Si vous utilisez un numéro importé depuis Twilio, configurez le nom de l’appelant dans votre compte Twilio. Il s’applique ensuite aux appels que vos agents passent depuis Callin
- Pour les autres numéros, écrivez à [support@callin.io](mailto:support@callin.io)

### “Mes numéros importés n’apparaissent pas”

- Vérifiez les identifiants (Twilio Account SID et Auth Token, ou clé API Telnyx)
- Confirmez que les numéros sont actifs dans le compte du fournisseur
- Réessayez en vérifiant que vous utilisez le bon projet ou le bon sous-compte chez le fournisseur

## Note finale

Pour la configuration la plus rapide, commencez par **un numéro des États-Unis ou du Canada acheté dans Callin.io**. Si vous avez besoin d’un routage avancé ou si vous avez déjà un opérateur, connectez **BYOC**.

Une fois votre numéro ajouté et attribué, vos agents IA peuvent passer et recevoir de vrais appels à grande échelle.
