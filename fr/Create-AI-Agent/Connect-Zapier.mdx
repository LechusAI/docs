## Avant de commencer

Zapier est une plateforme qui relie différentes applications pour qu’elles fonctionnent ensemble automatiquement. Ces flux s’appellent des Zaps.\
Chaque Zap suit une règle simple : quand quelque chose se passe dans une application, une action s’exécute dans une autre.

Par exemple, quand votre agent Callin.io termine un appel, Zapier peut enregistrer la transcription dans Google Sheets, l’envoyer par e-mail ou la publier dans Slack.

L’application Callin.io sur Zapier vous offre :

- **Un déclencheur, Obtenir la transcription** : il lance un Zap chaque fois que Callin.io envoie la transcription d’un appel.
- **Une action, Activer l’agent** : elle met au travail l’un de vos agents Callin.io depuis une autre application (par exemple pour appeler un nouveau lead de votre CRM ou d’un formulaire).

Vous pouvez ainsi :

- Recevoir automatiquement les transcriptions des appels.
- Déclencher des appels sortants depuis votre CRM ou vos formulaires.
- Relier Callin.io à des milliers d’applications compatibles.

> **Remarque :** L’interface de Zapier est en anglais. Dans ce guide, les noms des boutons et options sont traduits : à l’écran, vous les verrez en anglais.

## Étape 1. Ouvrir le panneau des intégrations dans Callin.io

1. Connectez-vous à votre [compte Callin.io](https://app.callin.io).
2. Dans le menu de gauche, ouvrez **Intégrations → Actions** ([ouvrir ici](https://app.callin.io/actions)).
3. Utilisez le filtre **Automatisation** (ou parcourez **Toutes**), trouvez **Zapier** et cliquez sur **Connecter**.

Un nouvel onglet s’ouvre sur Zapier pour terminer la configuration.

## Étape 2. Se connecter ou créer un compte Zapier

Si vous avez déjà un compte Zapier, connectez-vous comme d’habitude.\
Sinon, vous pouvez en créer un gratuitement sur [zapier.com](https://zapier.com).

Une fois connecté, vous voyez la page **« Vous avez été invité à utiliser Callin.io sur Zapier ! »**, envoyée par l’équipe Callin.io. Cliquez sur **Accepter l’invitation et créer un Zap** pour activer l’intégration. Zapier ouvre l’éditeur de Zaps.

## Étape 3. Récupérer votre clé API dans Callin.io

Zapier doit vérifier votre compte de façon sécurisée avec une clé API.

1. Ouvrez votre [profil Callin.io](https://app.callin.io/profile) et allez dans l’onglet **Clés API**.
2. Si vous n’avez pas encore de clé (« Aucune clé API trouvée »), cliquez sur **Régénérer la clé** pour en créer une.
3. Utilisez l’icône de copie pour copier la clé.

Gardez votre clé API en sécurité. Si elle est compromise, régénérez-la immédiatement. En la régénérant, l’ancienne clé cesse de fonctionner : vous devrez donc reconnecter votre compte dans Zapier.

## Étape 4. Autoriser la connexion dans Zapier

1. Dans une étape Callin.io de votre Zap, allez dans **Compte** et cliquez sur **Se connecter** (ou sur **Modifier** → **Connecter un nouveau compte**).
2. Une fenêtre de Zapier demande l’accès à votre compte Callin.io. Collez votre clé API et confirmez.

Votre compte Callin.io apparaît alors comme connecté dans **Compte**.

Si vous voyez **« La connexion de ce compte a expiré »**, cliquez sur **Reconnecter ce compte** et saisissez de nouveau votre clé actuelle.

## Étape 5. Créer votre premier Zap

Créons votre première automatisation : recevoir automatiquement les transcriptions des appels.

1. Dans Zapier, cliquez sur **Créer** → **Zaps**.
2. Cliquez sur **Déclencheur**, cherchez **callin** et choisissez **Callin.io (1.0.1)**.
3. Dans **Événement déclencheur**, choisissez **Obtenir la transcription** (« Se déclenche à la réception des données de transcription d’un service externe »).
4. Sélectionnez votre compte Callin.io et cliquez sur **Continuer**.

Choisissez maintenant ce qui se passe ensuite. Par exemple :

- Enregistrer la transcription dans Google Sheets.
- Envoyer un message dans Slack.
- Créer une fiche dans votre CRM, comme HubSpot ou Zoho.

À la fin de chaque appel, Zapier exécutera automatiquement l’action choisie.

> **Astuce :** En cherchant **callin**, vous pouvez voir deux versions : **Callin.io (1.0.1)** et **Callin.io (1.0.2)**, qui apparaît comme **Callin** avec l’étiquette **Ancienne version**. Utilisez **Callin.io (1.0.1)** : elle propose le déclencheur **Obtenir la transcription** et l’action **Activer l’agent**.

## Configuration avancée

Cette intégration permet bien plus :

- **Lancer vos agents depuis d’autres applications** : ajoutez une étape Callin.io comme action et choisissez **Activer l’agent** (« Active un agent sur Callin.io »). Par exemple, activez un agent chaque fois qu’un nouveau lead est créé dans votre CRM ou un formulaire.
- Synchroniser les données d’appels avec Airtable, Notion ou des outils d’analyse.
- Envoyer des événements à vos outils marketing pour le reporting ou le suivi.

## Problèmes courants et solutions

**Le Zap ne se déclenche pas.**\
Vérifiez que l’événement déclencheur est bien configuré, que le compte Callin.io est connecté et que le Zap est publié.

**Clé API invalide ou erreur d’authentification.**\
Générez une nouvelle clé depuis la [section Clés API](https://app.callin.io/profile) et reconnectez votre compte.

**« La connexion de ce compte a expiré ».**\
Cliquez sur **Reconnecter ce compte** et collez votre clé API actuelle.

**L’application apparaît comme « Brouillon ».**\
Cela signifie simplement que l’intégration est partagée sur invitation et qu’elle est encore en bêta. Elle fonctionne pleinement.

**Je ne vois pas le déclencheur Obtenir la transcription.**\
Vérifiez que vous avez choisi **Callin.io (1.0.1)** et non l’**Ancienne version**.

## Note finale

En connectant Callin.io et Zapier, vous supprimez les tâches répétitives et centralisez facilement les données de vos appels.\
Dès votre premier Zap, vous verrez à quel point il est simple d’automatiser le travail autour des appels, de partager les transcriptions et de fluidifier vos processus dans tous vos outils préférés.
