## Présentation

L’**Historique des appels** est l’endroit où vous consultez tous les appels passés de votre espace de travail. Depuis cette page, vous pouvez :

- **Rechercher dans les transcriptions** et **filtrer** les appels (par numéro de téléphone, agent, squad, statut, date, sentiment, etc.).
- **Voir les résultats de l’appel** en un coup d’œil : messagerie vocale détectée, données extraites et appel transféré.
- **Exporter** la liste en **CSV**, en choisissant exactement les colonnes à inclure.
- **Ouvrir les détails de l’appel** pour lire la transcription, voir le résumé et le sentiment, consulter les données extraites et les objectifs, et revoir les moments clés.
- **Écouter** et **télécharger** l’enregistrement de l’appel.

Utilisez ce lien direct pour ouvrir la page :
[Ouvrir l’historique des appels](https://app.callin.io/call-history)

> **Conseil :** Ajoutez le lien ci-dessus à vos favoris si vous consultez les appels chaque jour.

## Ouvrir l’historique des appels

1. Dans la barre latérale gauche, allez dans **Évaluer**.
2. Cliquez sur **Historique des appels**.

Le tableau affiche une ligne par appel, du plus récent au plus ancien :

| Colonne | Ce qu’elle affiche |
| --- | --- |
| **Informations d’appel** | Le numéro de téléphone de l’appelant, ainsi que la date et l’heure de l’appel. Les appels de test passés depuis le navigateur n’ont pas de numéro. |
| **Agent / Squad** | L’agent ou le squad qui a traité l’appel. |
| **Durée** | La durée de l’appel. |
| **Origine** | La provenance de l’appel, par exemple **Application**. |
| **Statut** | Le statut final de l’appel, par exemple **Terminé** ou **Pas de réponse**. |
| **Résultats de l’appel** | Des icônes qui résument ce qui s’est passé pendant l’appel. Voir ci-dessous. |

## Filtrer et rechercher des appels

En haut de la page, vous trouverez :

- **Rechercher dans les transcriptions...** : saisissez un mot ou une phrase pour trouver les appels où il a été prononcé.
- **Boutons de filtre** : cliquez sur l’un d’eux pour ouvrir ses options. Vous pouvez en combiner plusieurs.
- **Exporter CSV** : téléchargez les appels affichés.

| Filtre | À quoi il sert | Options |
| --- | --- | --- |
| **Numéro de téléphone** | Trouver les appels d’un numéro précis | Saisissez le numéro |
| **ID de l’appel** | Accéder directement à un appel précis | Collez l’ID de l’appel |
| **Agent** | Voir les appels traités par un agent | Choisissez dans la liste (avec recherche) |
| **Squad** | Voir les appels traités par un squad | Choisissez dans la liste |
| **Statut** | Filtrer par statut d’appel | **En cours**, **Terminé**, **Annulé**, **Occupé**, **Pas de réponse**, **Inconnu** |
| **Direction** | Séparer les appels entrants et sortants | **Entrant**, **Sortant** |
| **Rendez-vous** | Trouver les appels où un rendez-vous a été planifié | **Oui**, **Non** |
| **Transfert d’appel** | Trouver les appels transférés | **Oui**, **Non** |
| **Messagerie vocale** | Trouver les appels où une messagerie vocale ou un répondeur a été détecté | **Oui**, **Non** |
| **Plage de dates** | Vous concentrer sur une période | **Aujourd’hui**, **Hier**, **7 derniers jours**, **30 derniers jours**, **Cette semaine**, **Ce mois-ci**, **Mois dernier**, **Plage personnalisée** |
| **Durée de l’appel** | Filtrer par durée | **Moins d’une minute**, **1 - 5 minutes**, **5 - 10 minutes**, **Plus de 10 minutes** |
| **Origine** | Voir la provenance de l’appel | **Application**, **Zapier**, **Make**, **N8N**, **Google Meet**, **Webhook personnalisé** |
| **ID de la campagne** | Voir les appels d’une campagne | Collez l’ID de la campagne |
| **Sentiment** | Trouver les appels selon l’humeur générale de l’appelant | **Positif**, **Neutre**, **Négatif** |
| **ID du ticket** | Trouver l’appel associé à un ticket | Collez l’ID du ticket |

> **Erreur fréquente :** Appliquer trop de filtres à la fois peut ne renvoyer aucun résultat. Si le tableau est vide, retirez un filtre et réessayez.

## Comprendre les résultats de l’appel (icônes)

La colonne **Résultats de l’appel** affiche trois icônes pour chaque appel. Une icône s’allume en couleur quand ce résultat s’est produit :

- **Icône de robot (verte)** : une **messagerie vocale ou un répondeur** a été détecté.
- **Icône de base de données (violette)** : l’agent a **extrait des données** pendant l’appel. Ouvrez l’appel pour les voir dans l’onglet **Données extraites**.
- **Icône de téléphone avec flèche** : l’appel a été **transféré** vers un autre numéro ou agent.

Les icônes grises indiquent que ce résultat ne s’est pas produit pendant cet appel.

> **Conseil :** Pour trouver les appels où un rendez-vous a été planifié, utilisez le filtre **Rendez-vous**.

## Exporter l’historique des appels en CSV

Vous pouvez exporter les appels affichés, y compris les filtres appliqués.

1. Cliquez sur **Exporter CSV**.
2. Dans la fenêtre **Exporter l’historique des appels**, sélectionnez les colonnes à inclure. Les 27 colonnes sont sélectionnées par défaut.
   - Utilisez **Tout sélectionner** ou **Tout désélectionner** pour aller plus vite.
3. Cliquez sur **Exporter CSV** pour télécharger le fichier.

Les colonnes disponibles sont :

- **Données de l’appel** : ID de l’appel, Numéro du contact, Nom du contact, Email du client, Direction, Statut, Durée, Commencé le, Terminé le, Créé le, Origine de l’appel, ID de la campagne, ID de Ticket.
- **Agent** : Nom de l’agent, ID de l’agent.
- **Résultats** : Machine détectée, Rendez-vous planifié, Appel transféré, Données extraites.
- **Transfert d’appel** : Durée de l’appel transféré, Statut de l’appel transféré, URL de l’enregistrement transféré, Transcription de l’appel transféré, Numéro de transfert, Nom de l’agent de transfert.
- **Contenu** : URL de l’enregistrement, Transcription.

## Ouvrir les détails d’un appel pour l’analyser

Cliquez sur n’importe quelle ligne du tableau. Le panneau **Détails de l’appel** s’ouvre.

En haut du panneau, vous trouverez :

- L’**ID de l’appel**. Cliquez dessus pour le copier.
- **Rechercher dans la transcription...** : trouvez un mot ou une phrase dans la conversation.
- **Copier** : copiez la transcription.

### Transcription

À gauche s’affiche la conversation complète, tour par tour. À côté de chaque message de l’appelant, une étiquette indique le **sentiment** de ce tour (**Positif**, **Neutre** ou **Négatif**) avec son score.

### Onglets d’analyse

À droite, vous trouverez ces onglets :

| Onglet | Ce que vous y trouverez |
| --- | --- |
| **Aperçu** | Un **Résumé** de l’appel et ses **Métadonnées** : ID de conversation, date et heure de début, agent (cliquez dessus pour ouvrir l’agent), statut, sentiment, durée et origine de l’appel. |
| **Données extraites** | Les champs que l’agent a recueillis pendant l’appel, avec le nombre de champs remplis. Les champs vides affichent **Non capturé**. Cliquez sur **Copier en JSON** pour les copier. N’apparaît que lorsque l’agent extrait des données. |
| **Objectifs** | Si chaque objectif de l’agent a été atteint pendant cet appel. Vous définissez les objectifs dans l’onglet **Conversation** de l’agent. Si l’agent n’a pas d’objectifs, vous verrez **Aucun objectif n’a été évalué pour cet appel**. |
| **Moments clés** | Les moments les plus importants de l’appel. Chacun indique qui l’a dit (**Utilisateur** ou **Assistant**), son type (par exemple **Question**, **Engagement**, **Objection**, **Signal d’achat** ou **Frustration**) et les mots exacts. |

> **Important :** Le résumé, le sentiment, les objectifs et les moments clés sont générés par l’IA. Comme l’indique le panneau, il s’agit d’une **analyse assistée par l’IA — à titre indicatif**.

## Télécharger l’audio de l’appel (enregistrement)

Le lecteur de l’enregistrement se trouve en bas du panneau **Détails de l’appel**. Depuis ce lecteur, vous pouvez :

- Cliquer sur **Lire** pour écouter l’appel, et utiliser les boutons de chaque côté pour reculer ou avancer.
- Cliquer sur le bouton de vitesse (**1.0x**) pour changer la vitesse de lecture : 0.5x, 0.75x, 1x, 1.25x, 1.5x ou 2x.
- Cliquer sur l’icône de **téléchargement** à gauche pour **Télécharger l’enregistrement**.

> **Important :** Si vous ne voyez pas le lecteur ou l’icône de téléchargement, cet appel n’a pas d’enregistrement. L’enregistrement peut être désactivé dans les paramètres de l’agent.
