## À quoi sert cette section

**Analytique UTM** vous aide à comprendre quels liens marketing amènent des utilisateurs dans votre espace white label. Elle affiche l’attribution marketing **capturée lors de l’inscription et du démarrage de l’essai gratuit**.

Elle est utile pour répondre à des questions comme :

- « Quelle campagne amène vraiment des inscriptions ? »
- « Les utilisateurs viennent-ils des annonces, des partenaires ou de sources organiques ? »
- « Quelle page d’atterrissage convertit le mieux ? »

Vous la trouverez dans la Plateforme white label, dans **Analytique et Marketing** ([ouvrez-la ici](https://app.callin.io/cms/utm)).

<Tip>
  Si vous voyez **Aucun résultat correspondant** et « Aucune donnée UTM disponible pour cette requête », les utilisateurs se sont inscrits sans paramètres UTM dans le lien, ou la campagne n’a pas encore généré d’inscriptions.
</Tip>

### Aperçu

- **Total** : les utilisateurs de la vue actuelle
- **Avec UTM** : combien d’entre eux ont des données UTM capturées
- **Couverture** : le pourcentage d’utilisateurs de la vue qui ont des données UTM

En dessous, vous voyez le nombre d’**enregistrements** et la page où vous êtes.

### Source et Campagne

Ces cartes répartissent vos utilisateurs avec données UTM par **Source** et par **Campagne**. Tant qu’il n’y a pas de données, elles affichent **—**.

### Rafraîchir et Exporter CSV

- **Rafraîchir** : charge les données les plus récentes
- **Exporter CSV** : télécharge la liste pour vos rapports. Disponible quand la liste contient des enregistrements.

### Le tableau

Chaque ligne est un utilisateur avec des données UTM :

- **Utilisateur**
- **A rejoint** : la date d’inscription
- **Source**, **Campagne** et **URL de destination**
- **Actions** : ouvre tous les champs UTM capturés pour cet utilisateur

Choisissez le nombre de lignes par page (**10**, **20** ou **50**) dans le sélecteur à droite. Au-dessus du tableau, vous voyez quels enregistrements sont affichés.

<Tip>
  Vous pouvez aussi voir les données UTM d’un client depuis [Utilisateurs](/fr/Automations/Whitelabel/Clients), dans l’onglet **UTM** de ses détails.
</Tip>

## Comment rechercher et filtrer

### Recherche

Utilisez **Rechercher des utilisateurs…** pour trouver un utilisateur précis (par exemple par e-mail ou par nom).

### Plage de dates

Utilisez les sélecteurs de date **De** et **à** pour vous concentrer sur une période (par exemple, les 7 derniers jours ou ce mois-ci).

### Filtres

Cliquez sur **Filtres** pour afficher trois champs de plus : **Source**, **Campagne** et **Support**. Saisissez une valeur dans l’un d’eux pour affiner les résultats.

Le nombre à côté de **Filtres** indique combien de filtres sont actifs, et chacun apparaît comme une étiquette sous les champs (par exemple, **Source : newsletter**). Cliquez sur le **×** d’une étiquette pour retirer ce filtre.

<Frame caption="Capture d’écran : trois filtres actifs, chacun sous forme d’étiquette que vous pouvez retirer.">
  <img src="/images/wl-utm-filters.png" alt="Filtres ouverts avec les champs Source, Campagne et Support remplis avec newsletter, spring_offer et email, les étiquettes des trois filtres actifs et le bouton Effacer" />
</Frame>

### Effacer

Utilisez **Effacer** pour retirer tous les filtres et revenir à la vue par défaut.

## Ce que signifient les champs UTM (en termes simples)

Les paramètres UTM sont des étiquettes ajoutées à un lien pour savoir d’où vient le trafic. Le tableau affiche les principaux, et **Actions** affiche tous les champs capturés pour un utilisateur :

| Champ                     | Ce que cela signifie                                  | Exemple                            |
| ------------------------- | ----------------------------------------------------- | ---------------------------------- |
| Source                    | La plateforme ou l’origine                            | `google`, `facebook`, `newsletter` |
| Support                   | Le type de canal                                      | `cpc`, `email`, `social`           |
| Campagne                  | Le nom de la campagne                                 | `summer_promo`, `launch_2026`      |
| Contenu                   | La version de l’annonce ou du lien                    | `banner_a`, `cta_button`           |
| Terme                     | Le mot-clé de recherche payante                       | `ai_receptionist`                  |
| ID de campagne            | L’ID de la campagne dans votre plateforme publicitaire | `spring_2026_01`                  |
| Plateforme source         | La plateforme qui gère la campagne                    | `google_ads`                       |
| Format créatif            | Le format de l’annonce                                | `video`, `display`                 |
| Tactique marketing        | L’approche de ciblage                                 | `remarketing`, `prospecting`       |
| Référent                  | La page d’où vient l’utilisateur                      | `https://partner.example/blog`     |
| URL de destination        | La page sur laquelle l’utilisateur est arrivé         | `/pricing`, `/signup`, `/promo`    |
| ID de clic Google (gclid) | Ajouté automatiquement par Google Ads                 | —                                  |
| ID de clic Facebook (fbclid) | Ajouté automatiquement par Facebook et Instagram   | —                                  |

<Warning>
  **Erreur fréquente :** Utiliser des noms différents pour la même chose (par exemple `Facebook`, `facebook`, `fb`). Choisissez un style et gardez-le pour des rapports propres.
</Warning>

## Exemples pratiques

### Exemple 1 : Suivre une newsletter

Ajoutez des paramètres UTM au lien de votre newsletter, par exemple :

`?utm_source=newsletter&utm_medium=email&utm_campaign=spring_offer`

Ensuite, dans **Filtres**, saisissez `newsletter` dans **Source** et `spring_offer` dans **Campagne** pour voir les utilisateurs inscrits depuis cet e-mail.

### Exemple 2 : Comparer des pages d’atterrissage

Envoyez deux versions d’une page d’atterrissage avec des noms de campagne différents :

- Campagne A : `pricing_page_test`
- Campagne B : `homepage_test`

Au bout d’une semaine, utilisez les dates **De** et **à** et comparez la carte **Campagne** pour voir quelle page a amené le plus d’inscriptions.

## Quand quelqu’un demande « D’où vient cette inscription ? »

Une petite liste de vérification :

<Steps>
  <Step>
    Recherchez l’utilisateur dans **Analytique UTM**
  </Step>
  <Step>
    Regardez sa **Source** et sa **Campagne**, ou cliquez sur **Actions** pour voir tous les champs
  </Step>
  <Step>
    Si c’est vide, vérifiez qu’il a utilisé le bon lien (avec paramètres UTM)
  </Step>
</Steps>

<Tip>
  Pour des rapports cohérents, créez une « règle de nommage des liens » pour votre équipe (par exemple : source en minuscules, campagnes avec des tirets bas et sans espaces).
</Tip>
