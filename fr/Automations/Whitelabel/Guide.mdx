## À quoi sert cette section

**Guides** vous permet d’ajouter **vos propres liens de documentation** pour vos clients dans Callin.

C’est utile si vous voulez que vos sous-comptes ouvrent des ressources d’aide directement depuis l’application, par exemple :

- Une base de connaissances (par exemple Mintlify)
- Un espace Notion
- Un centre d’aide sur votre site
- Un document Google ou un wiki interne

<Warning>
  Les sous-comptes ne verront pas ici la documentation officielle de Callin. Elle porte la marque Callin : en White Label, publiez **votre propre** documentation et ajoutez son lien dans cette section.
</Warning>

Vous la trouverez dans la Plateforme white label, dans **Gestion du contenu** ([ouvrez-la ici](https://app.callin.io/cms/guides)).

## Comment ça fonctionne

Chaque élément ajouté ici est un **lien** que vos sous-comptes voient tant qu’il est actif. Quand quelqu’un a besoin d’aide, il clique sur le guide et arrive sur l’URL que vous avez indiquée.

Un guide comprend :

- Un **Titre** : il apparaît dans le menu de navigation latéral
- Une **Description** : le sujet du guide
- Une **URL** : la page où l’utilisateur est envoyé
- Un interrupteur **Actif** : pour l’afficher ou le masquer

## Ajouter un nouveau lien de guide

<Steps>
  <Step>
    Cliquez sur **Ajouter nouveau**.
  </Step>
  <Step>
    Remplissez les champs (les trois sont obligatoires) :
    - **Titre** : le nom que les utilisateurs reconnaîtront (par exemple « Centre d’aide »). 50 caractères maximum.
    - **Description** : une courte explication (par exemple « Tutoriels pas à pas et FAQ »).
    - **URL** : le lien complet que les utilisateurs doivent ouvrir (par exemple votre site Mintlify ou votre propre site d’assistance).
  </Step>
  <Step>
    Laissez **Actif** activé si vous voulez que les sous-comptes le voient tout de suite. Il est activé par défaut.
  </Step>
  <Step>
    Cliquez sur **Enregistrer**.
  </Step>
</Steps>

### Exemple pratique

Si votre documentation est hébergée sur Mintlify, vous pourriez créer :

- Titre : **Documentation**
- Description : « Guides de configuration, de facturation et bonnes pratiques. »
- URL : « L’URL de votre documentation Mintlify »
- Actif : **Activé**

Ainsi, quand un client demande « Où trouver le guide de configuration ? », vous pouvez lui indiquer le lien publié ici.

## Gérer les guides existants

La liste affiche le **Titre**, la **Description**, l’**URL** et le **Statut** de chaque guide. Depuis la liste, vous pouvez :

- Utiliser **Rechercher des guides...** pour trouver un guide rapidement.
- Cliquer sur **⋮** → **Modifier** pour changer le titre, la description ou l’URL, ou désactiver **Actif** pour le masquer.
- Cliquer sur **⋮** → **Supprimer** pour le retirer.

<Warning>
  **Erreur fréquente :** Mettre le lien d’une page privée. Vérifiez que vos clients peuvent ouvrir l’URL (ou indiquez clairement s’ils doivent se connecter).
</Warning>
