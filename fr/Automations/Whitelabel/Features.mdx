## À quoi sert cette section

**Fonctionnalités et Capacités** est l’endroit où un compte White Label crée les « briques » qui apparaissent ensuite quand vous créez ou modifiez un **Forfait d’abonnement**.

Une façon simple de voir les choses :

- **Forfaits d’abonnement** = les niveaux que vous vendez (Essentiel, Pro, etc.)
- **Fonctionnalités et Capacités** = ce que comprend chaque niveau (outils activés, limites chiffrées ou options au choix)

Si vous ne créez pas d’abord les fonctionnalités ici, l’assistant des forfaits affiche **Aucune fonctionnalité disponible. Veuillez en créer d'abord.**

Vous la trouverez dans la Plateforme white label, dans **Plans et facturation** ([ouvrez-la ici](https://app.callin.io/cms/features-capabilities)).

## Comment les fonctionnalités sont utilisées dans les forfaits d’abonnement

Quand vous créez un forfait, l’étape **Vérifier et confirmer** comprend **Configurer les fonctionnalités**. C’est là que vous donnez une valeur à chaque fonctionnalité définie ici :

- Les fonctionnalités **Activé / Désactivé (toggle)** sont activées ou désactivées.
- Les fonctionnalités **Limite d'utilisation (limit)** prennent un nombre.
- Les fonctionnalités **Accès avec options (capability)** prennent un texte (par exemple, « Voix premium »).

Le déroulement est donc :

1. Créez une fonctionnalité (ici)
2. Donnez une valeur à cette fonctionnalité dans chaque forfait (dans [Forfaits d’abonnement](/fr/Automations/Whitelabel/SubscriptionsPlans))
3. La valeur du forfait est ce que reçoivent les sous-comptes qui utilisent ce forfait

> **Important :** Pour créer des forfaits, votre White Label doit avoir Stripe connecté. Vous pouvez créer des fonctionnalités à tout moment, même avant de connecter Stripe.

## Créer une fonctionnalité ou une capacité

Cliquez sur **Créer Fonctionnalité/Capacité** et remplissez ces champs. Les champs marqués d’un **\*** sont obligatoires. Quand vous avez terminé, cliquez sur **Créer**.

### Nom

Un libellé court qui sera affiché dans la configuration du forfait.

Bons exemples :

- **Minutes par mois**
- **Option d’enregistrement des appels**
- **Niveau du pack de voix**

Mauvais exemples (trop vagues) :

- **Minutes**
- **Fonctionnalité 1**
- **Accès**

> **Astuce :** Utilisez des noms qui se lisent comme un avantage ou une règle claire. « Minutes par mois » est plus clair que « Minutes ».

> **Erreur fréquente :** Si **Créer** affiche une erreur avec `duplicate key value`, ce nom est déjà pris. Choisissez un nom plus précis (par exemple, « Option d’enregistrement des appels » au lieu de « Enregistrement des appels »).

### Description

Obligatoire. Écrivez une phrase courte pour que votre équipe sache exactement ce que contrôle cette fonctionnalité.

Exemple :

- « Minutes d’appel incluses chaque mois dans le forfait. »

### Traductions

Les onglets du haut vous permettent de traduire le **Nom** et la **Description** dans chaque langue de votre plateforme : **English**, **Español**, **Italiano**, **Português**, **हिन्दी**, **Deutsch**, **Nederlands**, **Français** et **Português (Brasil)**.

- **Par défaut** contient le texte principal. Son **Nom** et sa **Description** sont obligatoires.
- Les onglets de langue sont facultatifs. Les champs vides affichent en gris le texte de **Par défaut**.
- Le type et la catégorie sont les mêmes pour toutes les langues.

### Comment les formules accordent-elles cette fonctionnalité ?

C’est le choix le plus important. Il définit le type de valeur que les forfaits vont fixer.

#### Activé / Désactivé (toggle)

Activation ou désactivation simple.

Exemple :

- Fonctionnalité : **Option d’enregistrement des appels**
  - Forfait Essentiel : **Désactivé**
  - Forfait Pro : **Activé**

Idéal pour :

- Des options comme « Enregistrement des appels », « Suppression de la marque » ou « Support prioritaire » (si votre configuration les inclut)

#### Limite d'utilisation (limit)

Autoriser un montant fixe par période de facturation.

Exemple :

- Fonctionnalité : **Minutes par mois**
  - Forfait Essentiel : **400**
  - Forfait Pro : **1 000**

Idéal pour :

- Les minutes, les utilisateurs, le nombre d’agents, le nombre de numéros ou toute règle du type « X par mois » (selon ce que prend en charge votre compte)

#### Accès avec options (capability)

Activer l’accès avec des options sélectionnables. Dans chaque forfait, vous écrivez l’option sous forme de texte.

Exemple :

- Fonctionnalité : **Niveau du pack de voix**
  - Forfait Essentiel : **Voix de base**
  - Forfait Pro : **Voix premium**

Idéal pour :

- Les droits du type « choisissez un de ces packs » ou « choisissez un niveau »

> **Erreur fréquente :** Choisir **toggle** pour quelque chose qui devrait être un nombre (comme les minutes). Si cela peut varier selon le forfait, c’est généralement un **limit**.

### Catégorie

Obligatoire. Les catégories regroupent vos fonctionnalités dans la liste et gardent la configuration des forfaits bien rangée.

- Choisissez une catégorie existante dans **Sélectionnez une catégorie**.
- Ou cliquez sur **+** pour en créer une nouvelle et saisissez-la dans **Entrez le nom de la nouvelle catégorie**. Cliquez sur **×** pour revenir à la liste.

Catégories pratiques :

- **Limites** (minutes, utilisateurs, plafonds d’utilisation)
- **Options** (enregistrement, portail à votre marque, etc.)
- **Capacités** (packs de voix, modes de routage, intégrations… selon ce que vous proposez)

> **Astuce :** Gardez des catégories cohérentes entre les fonctionnalités. Si vous créez « Limite » et « Limites », le regroupement sera désordonné.

## Exemple pratique (configuration réaliste)

Imaginez que vous vendez deux niveaux à vos sous-comptes :

- **Essentiel** : 400 minutes par mois pour un prix fixe
- **Pro** : 1 000 minutes par mois + enregistrement des appels

Créez ces fonctionnalités dans **Fonctionnalités et Capacités** :

1. **Minutes par mois** → **Limite d'utilisation (limit)**, catégorie **Limites**\
   Description : « Minutes d’appel incluses chaque mois dans le forfait. »
2. **Option d’enregistrement des appels** → **Activé / Désactivé (toggle)**, catégorie **Options**\
   Description : « Enregistre les appels traités par les agents. »

Ensuite, dans **Forfaits d’abonnement** :

- Forfait Essentiel :
  - Minutes par mois = **400**
  - Option d’enregistrement des appels = **Désactivé**
- Forfait Pro :
  - Minutes par mois = **1 000**
  - Option d’enregistrement des appels = **Activé**

Ainsi, les sous-comptes comprennent tout de suite ce qui change d’un niveau à l’autre, et vos prix sont plus faciles à justifier.

## Modifier une fonctionnalité ou une capacité existante

Dans la liste, cliquez sur **⋮** sur la ligne de la fonctionnalité :

- **Modifier** ouvre **Modifier Fonctionnalité/Capacité**, avec les mêmes champs : **Nom**, **Description**, traductions, type et **Catégorie**. Cliquez sur **Mettre à jour** pour enregistrer.
- **Supprimer** efface la fonctionnalité. Cette action ne peut pas être annulée.

> **Important :** Changer le type d’une fonctionnalité déjà utilisée dans des forfaits peut modifier la façon dont les forfaits enregistrent ou affichent cette valeur. En cas de doute, créez une nouvelle fonctionnalité et passez vos forfaits dessus.
