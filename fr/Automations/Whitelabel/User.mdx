## Ce que vous trouverez sur cette page

**Configuration White Label** est le centre de contrôle de votre application à votre marque. C’est la première section de la Plateforme white label, dans **Configuration de l'application**. En haut, vous verrez deux onglets :

- **Configuration** : les réglages de base de l’application (nom, domaine, valeurs de facturation, pages légales et e-mail d’alerte de minutes épuisées).
- **Apparence** : l’image que verront vos clients (couleurs, langue des e-mails, logos, favicon et thème par défaut).

Ouvrez-la ici : [Ouvrir Configuration White Label](https://app.callin.io/cms/white-label-configuration)

## Configuration

### Nom de l’app

Le **Nom de l’app** est affiché dans la barre latérale, les titres et les e-mails. C’est le nom que reconnaîtront vos clients.

Une bonne règle : utilisez le même nom que dans vos supports commerciaux.\
Exemple : si vous vendez « Northwind Reception », saisissez **Northwind Reception** comme nom de l’app.

### Domaine personnalisé (recommandé : utiliser un sous-domaine)

Dans **Domaine personnalisé**, saisissez le domaine par lequel vos clients accéderont à l’application, sans `http://` ni `https://`.

Callin recommande un **sous-domaine que vous contrôlez**, par exemple :

- `app.votredomaine.com`

Pourquoi un sous-domaine compte :

- Votre **domaine racine** (comme `votredomaine.com`) héberge généralement votre site, vos pages d’atterrissage, votre blog et vos scripts de suivi.
- Garder le produit sur `app.votredomaine.com` évite les conflits et laisse votre site indépendant.

> **Astuce :** Choisissez un sous-domaine facile à retenir : `app`, `portal` ou `dashboard`.

### Configuration DNS

Après avoir saisi votre domaine, cliquez sur **Enregistrer**, puis sur **Configuration DNS**. Tant que le domaine n’est pas enregistré, vous verrez le message **Veuillez d’abord enregistrer votre domaine avant d’installer le SSL ou de configurer le DNS.**

**Configuration DNS** ouvre un panneau latéral avec deux façons de configurer le DNS :

- **Fournisseur** (assistée)
- **Manuel** (vous ajoutez les enregistrements vous-même)

#### Fournisseur (configuration assistée/automatique)

Utilisez **Fournisseur** si votre domaine est chez **Cloudflare**, **GoDaddy** ou **Namecheap**. Vous choisissez votre fournisseur et Callin vous aide à configurer le domaine automatiquement.

Ce que vous faites :

1. Ouvrez l’onglet **Fournisseur**.
2. Dans **Fournisseur DNS**, choisissez le vôtre : **Cloudflare**, **GoDaddy** ou **Namecheap**.
3. Cliquez sur **Découvrir**.

À quoi vous attendre :

- Callin essaiera de vous guider dans la configuration DNS du domaine saisi.
- En cas de problème, un message d’erreur vous demande de vérifier la configuration et les enregistrements DNS, puis de réessayer plus tard. Cela signifie en général que les enregistrements DNS ne correspondent pas encore. Patientez un peu ou utilisez **Manuel**.

#### Manuel (ajouter vous-même les enregistrements DNS)

Utilisez **Manuel** si :

- Votre fournisseur n’est pas dans la liste,
- La configuration par fournisseur échoue, ou
- Vous préférez gérer le DNS vous-même.

Dans l’onglet **Manuel**, Callin affiche **Ajoutez ces enregistrements DNS chez votre registrar** et un tableau avec les enregistrements de votre domaine. Par exemple, pour `app.northwindreception.com` :

| Type | Nom | Valeur | TTL |
| --- | --- | --- | --- |
| A | `@` | l’adresse IP indiquée dans votre panneau | 300 ou automatique |
| CNAME | `app` | `northwindreception.com` | 300 ou automatique |

Le tableau comprend :

- **Type** (par exemple A ou CNAME)
- **Nom** (par exemple `@` ou `app`)
- **Valeur** (la destination)
- **TTL** (souvent « 300 ou automatique », selon votre fournisseur)

Les étapes :

1. Ouvrez **Manuel**.
2. Ajoutez chaque enregistrement DNS exactement comme dans le tableau.
3. Une fois les enregistrements en place, cliquez sur **Installer le SSL** pour terminer.

### Devise

La **Devise** sert pour les prix des forfaits et la facturation. Vous pouvez choisir **USD - Dollar américain**, **AUD - Dollar australien**, **CAD - Dollar canadien**, **EUR - Euro**, **GBP - Livre sterling** ou **BRL - Réal brésilien**. Tapez dans la recherche pour la trouver plus vite.

Choisissez la devise dans laquelle vous facturerez vos clients. C’est d’autant plus important si vous créez des **forfaits d’abonnement** et encaissez via Stripe : vos clients s’attendent à ce que le prix et le prélèvement correspondent.

### Langue de l’app

La **Langue de l'Application** est la langue par défaut de l’application pour vos clients. Vous pouvez choisir English, Español, Italiano, Português, हिन्दी (hindi), Deutsch, Nederlands, Français ou Português (Brasil).

Si vous avez des clients dans plusieurs pays, choisissez la langue de votre public principal.

### Emplacement du serveur

L’**Emplacement du serveur** vous permet de choisir la région où vos données sont hébergées, pour respecter les exigences de résidence des données et de conformité. Vous pouvez choisir **États-Unis – Ashburn (Virginie)** ou **Allemagne – Francfort**.

Si vous travaillez avec des clients aux exigences strictes (santé, finance, secteur public), choisissez ce qui est prévu au contrat.

### Politique de confidentialité et Conditions d’utilisation

Ces champs renvoient vers vos pages légales :

- **Politique de confidentialité** : où vous expliquez comment vous traitez les données personnelles.
- **Conditions d’utilisation** : les règles que vos clients acceptent en utilisant votre service.

Collez l’URL complète de chaque page, par exemple `https://votredomaine.com/confidentialite`.

> **Astuce :** Même si vous êtes une agence, traitez cela comme un produit : publiez ces pages sur votre site (domaine racine) et ajoutez les liens ici.

### E-mail d’alerte de minutes épuisées

L’**E-mail d'alerte lorsque les minutes sont épuisées** prévient vos clients par e-mail quand ils ont utilisé toutes leurs minutes incluses.

1. Activez **Activer l'e-mail d'alerte**. L’éditeur de l’e-mail s’ouvre.
2. Saisissez l’**Objet**.
3. Choisissez le **Type de contenu** : **Texte normal** (texte brut ; les retours à la ligne sont conservés) ou **HTML** (HTML brut).
4. Rédigez le **Contenu**. Par défaut, il comprend le nom de votre application et votre domaine.
5. Cliquez sur **Aperçu de l'e-mail** pour voir l’e-mail final que recevront vos clients, puis sur **Fermer**.

Pour le modifier plus tard, cliquez sur **Configurer l'e-mail**. N’oubliez pas de cliquer sur **Enregistrer**.

### Couleurs

Cliquez sur un carré de couleur pour choisir la couleur :

- **Couleur primaire** : pour les boutons et les éléments mis en avant dans l’application.
- **Couleur secondaire** : pour les accents et les états.
- **Couleur Principale des Emails** : la couleur principale de vos e-mails transactionnels.
- **Couleur du Bouton CTA** : la couleur des boutons et liens principaux de vos e-mails.

> **Astuce :** Si votre marque a déjà une charte graphique, partez de votre couleur principale et choisissez une couleur secondaire lisible sur fond clair comme sur fond sombre.

### Langue des e-mails

La **Langue des e-mails** est la langue par défaut des e-mails que reçoivent vos clients. Elle propose les mêmes langues que la **Langue de l'Application**.

### Logos (clair et sombre)

Importez deux versions de votre logo :

- **Logo** (**Sélectionner le logo**) : pour les fonds clairs.
- **Logo Sombre** (**Sélectionner le logo sombre**) : pour les fonds sombres.

Utilisez du PNG ou du SVG, jusqu’à 2 Mo, idéalement avec un fond transparent. Le même logo n’est pas toujours lisible sur les deux thèmes.

> **Important :** Si votre logo apparaît minuscule, l’image a souvent une grande marge blanche autour : Callin réduit l’image entière pour qu’elle tienne. Un PNG transparent bien recadré règle généralement le problème.

### Favicon

Le **Favicon** est la petite icône affichée dans l’onglet du navigateur et dans les favoris. Cliquez sur **Sélectionner le favicon** et importez un ICO ou un PNG de 32×32 ou 48×48 pixels, jusqu’à 1 Mo.

### Thème par défaut

Le **Thème Par Défaut** définit l’apparence de l’application par défaut :

- **Système** : suit le thème de l’appareil de chaque utilisateur.
- **Clair** : mode clair.
- **Sombre** : mode sombre.

Une approche pratique : choisissez **Système** pour que l’application s’adapte aux préférences de chaque utilisateur.

Quand vous avez terminé, cliquez sur **Enregistrer**.
