## À quoi sert cette page

La page **Intégrations** est l’endroit où vous connectez votre application White Label aux services qui rendent possible le travail au quotidien :

- **Paiements et abonnements** avec Stripe (pour facturer vos clients)
- **Voix et SMS** avec Twilio (pour que les appels et les messages fonctionnent)
- **Envoi d’e-mails** avec SendGrid (pour que vos clients reçoivent les e-mails importants)
- **Chat en direct** avec Intercom ou Brevo Chat (pour que vos clients parlent à votre équipe en temps réel)
- **Suivi marketing** avec Google Ads et Google Analytics (pour mesurer l’acquisition et les conversions)

Vous la trouverez dans la Plateforme white label, dans **Configuration de l'application** ([ouvrez-la ici](https://app.callin.io/cms/api-keys)). Utilisez **Rechercher des intégrations...** pour en trouver une rapidement.

## Avant de connecter quoi que ce soit

Quelques bonnes habitudes rendent les intégrations plus simples (et plus sûres) :

- **Utilisez le bon compte administrateur** chez chaque fournisseur (Stripe, Twilio, etc.) pour accéder aux clés et aux réglages.
- **Conservez les clés en lieu sûr** (traitez-les comme des mots de passe).
- **Limitez l’accès** aux personnes qui en ont besoin. Ne collez pas de clés dans des documents ou des chats partagés.

> **Astuce :** Si une intégration ne fonctionne pas tout de suite, vérifiez qu’il n’y a pas d’espace au début ou à la fin de la clé avant d’essayer autre chose.

## Comment se connecte une intégration

1. Cliquez sur la carte d’une intégration. Un panneau latéral s’ouvre.
2. Lisez l’encadré bleu en haut : il explique où trouver chaque valeur.
3. Pour **Stripe**, cliquez sur **Connecter** et connectez-vous à Stripe. Pour les autres, copiez les valeurs depuis le tableau de bord du fournisseur et collez-les dans les champs (ceux marqués `*` sont obligatoires).
4. Cliquez sur **Enregistrer**.

Pour fermer un panneau sans enregistrer, cliquez sur le **X** en haut à droite.

## Stripe

**À quoi elle sert :** Stripe sert au **traitement des paiements** : encaisser, gérer les abonnements et recevoir les versements. C’est ce qui vous permet d’avoir une vraie activité par abonnement.

**Quand en avez-vous besoin :** Si vous créez des forfaits payants et facturez vos clients, Stripe est l’une des premières intégrations à configurer.

### Comment connecter Stripe

1. Ouvrez la carte **Stripe**. Le panneau **Se connecter à Stripe** s’ouvre.
2. Cliquez sur **Connecter**.
3. Connectez-vous à votre compte Stripe, ou créez-en un quand on vous le propose.
4. À la fin, vous revenez sur Callin et votre compte est lié automatiquement.

> **Important :** Connectez le compte Stripe sur lequel vous voulez recevoir les paiements de vos clients. Si vous utilisez un autre compte plus tard, reconnectez-le depuis cette carte.

## Twilio

**À quoi elle sert :** Twilio permet les **appels vocaux et les SMS**, ainsi que la gestion des numéros de téléphone.

**Quand en avez-vous besoin :** Si votre White Label comprend des appels entrants ou sortants ou des SMS, Twilio est indispensable. C’est pourquoi elle est marquée **Obligatoire**.

### Ce dont vous aurez besoin (comme indiqué dans le panneau)

- **Account SID**\*
- **Auth Token**\*

### Comment connecter Twilio

1. Ouvrez la carte **Twilio**. Le panneau **Ajouter les clés API Twilio** s’ouvre.
2. Depuis votre tableau de bord Twilio, copiez votre **Account SID** et votre **Auth Token**.
3. Collez-les dans les champs correspondants. Cliquez sur l’icône en forme d’œil pour vérifier le jeton collé.
4. Cliquez sur **Enregistrer**.

> **Astuce :** Si les appels ou les SMS cessent de fonctionner plus tard, Twilio est la première intégration à vérifier.

## SendGrid

**À quoi elle sert :** SendGrid **envoie les e-mails** de votre application White Label : les e-mails automatiques et les notifications dont vos clients ont besoin.

**Quand en avez-vous besoin :** Si vos clients doivent recevoir des e-mails de votre application à votre marque, configurez SendGrid tôt. Elle est marquée **Obligatoire**.

### Ce dont vous aurez besoin (comme indiqué dans le panneau)

- **Clé API**\*
- **Sender Email**\* (une adresse d’expéditeur vérifiée dans SendGrid)

### Comment connecter SendGrid

1. Ouvrez la carte **SendGrid**. Le panneau **Ajouter les clés API SendGrid** s’ouvre.
2. Copiez votre **Clé API** depuis SendGrid.
3. Dans **Sender Email**, saisissez une adresse vérifiée dans SendGrid.
4. Cliquez sur **Enregistrer**.

> **Erreur fréquente :** Utiliser une adresse d’expéditeur non vérifiée dans SendGrid. Si les e-mails ne partent pas, vérifiez d’abord l’expéditeur.

## Intercom

**À quoi elle sert :** Intercom ajoute un **chat en direct et un support client** au tableau de bord de vos clients, pour qu’ils écrivent à votre équipe sans quitter l’application.

**Quand en avez-vous besoin :** Si le support et l’accompagnement font partie de ce que vous vendez. Elle est facultative.

### Ce dont vous aurez besoin (comme indiqué dans le panneau)

- **App ID**\* (dans les paramètres de votre espace de travail Intercom)

## Clés API Analytics & Tracking

**À quoi elle sert :** Cette intégration relie votre White Label au **suivi marketing et à l’analytique** :

- Les conversions **Google Ads**, avec un ID de pixel
- **Google Analytics (GA4)**, avec un ID de mesure

**Pourquoi c’est important en White Label :** Si vous lancez des campagnes payantes, vous voulez mesurer le trafic et les conversions de votre marque pour savoir ce qui marche. Les deux champs sont facultatifs : remplissez seulement ceux que vous utilisez.

### Ce dont vous aurez besoin (comme indiqué dans le panneau)

- **ID de pixel Google Ads** (format : `AW-123456789`)
- **Google Analytics Measurement ID (GA4)** (format : `G-XXXXXXXXXX`)

### Comment connecter le tracking

1. Ouvrez **Clés API Analytics & Tracking**.
2. Dans Google Ads, allez dans **Outils et paramètres → Conversions**, créez ou ouvrez une action de conversion de site web et copiez l’ID de conversion (format `AW-123456789`). Collez-le dans **ID de pixel Google Ads**.
3. Dans Google Analytics (GA4), allez dans **Administration → Flux de données → Web**, choisissez le flux de votre site et copiez l’ID de mesure (format `G-XXXXXXXXXX`). Collez-le dans le champ GA4.
4. Cliquez sur **Enregistrer**.

### Ce qui se passe après l’enregistrement (tel que décrit dans le panneau)

- Pour votre marque uniquement, l’application ajoute automatiquement les scripts Google Ads et GA4 avec les ID saisis.
- Le trafic et les conversions sont mesurés séparément pour chaque marque White Label.
- Si un champ reste vide, le script de ce fournisseur n’est pas chargé pour votre marque.
- Seuls les administrateurs et propriétaires de la marque ayant accès à la Plateforme white label peuvent voir ou modifier ces ID.

> **Astuce :** Connectez le suivi avant vos premières campagnes, pour ne pas perdre de données d’attribution.
