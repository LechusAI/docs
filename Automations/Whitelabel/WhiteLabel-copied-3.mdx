## Panoramica
Personalizza la tua app Callin con il nome del tuo brand, il logo e il dominio. Questa guida ti accompagna nella configurazione white-label e nella configurazione del dominio (automatica o manuale), oltre alle opzioni per logo e valuta.

Prima di iniziare:
- Devi possedere un dominio e avere accesso al DNS (Cloudflare, GoDaddy, Namecheap, ecc.).
- È consigliato usare un sottodominio come `app.tuodominio.com`.
- Per il DNS automatico, prepara le credenziali API con permessi di modifica DNS.
- Apri [CMS → White-Label Settings](https://app.callin.io/cms).

## Passaggi

### 1. Dai un nome alla tua app
In **App Name**, inserisci il nome del tuo brand. Questo nome comparirà nell’interfaccia e nelle email.

### 2. Collega il tuo dominio
Vai su **Custom Domain**.  
Scegli la configurazione DNS automatica (consigliata) oppure manuale.

**Inserisci il sottodominio completo**, ad esempio `app.tuodominio.com`.

#### DNS in 2 minuti
- Un record **A** collega un nome a un indirizzo IP.
- Un record **CNAME** collega un nome a un altro hostname (alias).
- Il **TTL** (Time To Live) definisce la durata della cache; usa 300 per aggiornamenti rapidi.
- La **propagazione** può richiedere 5–30 minuti, fino a 24 ore a seconda del provider.

**Consiglio:** usa un sottodominio (non `@`) per evitare di impattare il tuo sito principale.

#### Opzione A — Configurazione automatica
1. Scegli il tuo **provider DNS**: Cloudflare, GoDaddy o Namecheap.
2. Inserisci le credenziali:
   - **Cloudflare**: API Token (permesso “Edit DNS” sulla zona).
   - **GoDaddy**: API Key + Secret.
   - **Namecheap**: API User, Key e Client IP inserito in whitelist.
3. Fai clic su **Discover Provider**.
4. Callin verifica l’accesso e crea i record.
5. L’SSL viene emesso automaticamente.

**Importante (Cloudflare):** se la validazione fallisce con **orange cloud (proxied)**, passa a **DNS Only (grey)**, completa l’emissione SSL, poi riattiva il proxy se necessario.

#### Opzione B — Configurazione manuale
1. Seleziona **Manual**.
2. Aggiungi i record DNS mostrati nella tabella del CMS presso il tuo registrar:
   - `Type: A` → `Host: @ o sottodominio` → `Value: <IP>` → `TTL: 300`
   - `Type: CNAME` → `Host: www` (se presente) → `Value: <host>` → `TTL: 300`
3. Torna nel CMS e fai clic su **Install SSL**.

**Avviso:** evita record duplicati o in conflitto — bloccano la verifica.

### 3. Colori e loghi
Imposta i **Primary/Secondary Colors** e carica:
- **Logo** (PNG/SVG, sfondo trasparente).
- **Favicon** (ICO/PNG, 32×32 o 48×48).

### 4. Valuta predefinita
Scegli la **Default Currency** per i prezzi dei piani. Vedi [[Create-AI-Agent/Billing]].

### 5. Impostazioni avanzate delle chiamate (opzionale)
- **[BYOC]**: Bring Your Own Carrier (aggiungi il tuo trunk SIP).
- **[Recordings]**: salva le registrazioni delle chiamate nel tuo bucket S3 compatibile.
- **[AMD]**: ottimizza il rilevamento umano vs segreteria.

## Suggerimenti e note
- Preferisci `app.tuodominio.com` per evitare problemi sul dominio root.
- TTL 300 assicura una propagazione più rapida durante la configurazione.
- Su Cloudflare usa **DNS Only (grey)** durante l’emissione dell’SSL.

## Risoluzione dei problemi

**Verifica del dominio fallita**  
**Causa:** host errato, conflitti o ritardo di propagazione.  
**Soluzione:**
- Controlla l’host (deve essere `app`, non `www`).
- Rimuovi record duplicati.
- Imposta TTL a 300.
- Attendi fino a 30 minuti.

**SSL non emesso**  
**Causa:** verifica incompleta.  
**Soluzione:**
- Fai clic su **Install SSL**.
- Verifica che l’hostname risolva verso l’IP di Callin.
- Assicurati che HSTS/proxy non blocchino la challenge ACME.

**Credenziali API non valide**  
**Soluzione:**
- Verifica che i token abbiano permessi **Edit DNS** sulla zona corretta.
- Namecheap: aggiungi il tuo IP in whitelist.

**Il sito apex (root) si è rotto**  
**Soluzione:** usa sempre un sottodominio (come `app.`). Non modificare i record `@`.

**Le modifiche non sono visibili**  
**Soluzione:** svuota la cache DNS o cambia rete. Usa un lookup DNS per confermare i record.
