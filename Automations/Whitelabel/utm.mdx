## What this section is for

**UTM Analytics** helps you understand which marketing links are bringing users into your white-label workspace. It shows the marketing attribution **captured at signup and starting free trial**.

This is useful when you want to answer questions like:

- “Which campaign is actually bringing signups?”
- “Are users coming from ads, partners, or organic sources?”
- “Which landing page converts best?”

You’ll find it in the White Label Platform, under **Analytics & Marketing** ([open it here](https://app.callin.io/cms/utm)).

</Tip>

### Overview

- **Total**: users in the current view
- **With UTM**: how many of them have UTM data captured
- **Coverage**: the percentage of users in the view that include UTM data

Below, you see the number of **records** and the page you’re on.

### Source and Campaign

These cards break down your users with UTM data by **Source** and by **Campaign**. While there’s no data, they show **—**.

### Refresh and Export CSV

- **Refresh**: reload the latest data
- **Export CSV**: download the list for reporting. It’s available when the list has records.

### The table

Each row is a user with UTM data:

- **User**
- **Joined**: the signup date
- **Source**, **Campaign** and **Landing URL**
- **Actions**: open all the UTM fields captured for that user

Choose how many rows to see per page (**10**, **20** or **50**) in the selector on the right. **Showing** tells you which records you’re looking at.

<Tip>
  You can also see a customer’s UTM data from [Users](/Automations/Whitelabel/Clients), in the **UTM** tab of their details.
</Tip>

## How to search and filter

### Search

Use **Search users…** to find a specific user (for example, by email or name).

### Date range

Use the **From** and **to** date selectors to focus on a period (for example, the last 7 days or this month).

### Filters

Click **Filters** to show three more fields: **Source**, **Campaign** and **Medium**. Type a value in any of them to narrow the results.

The number next to **Filters** tells you how many filters are active, and each one appears as a tag under the fields (for example, **Source: newsletter**). Click the **×** on a tag to remove that filter.

<Frame caption="Screenshot: three active filters, each one shown as a tag you can remove.">
  <img src="/images/wl-utm-filters.png" alt="Filters open with the Source, Campaign and Medium fields filled in with newsletter, spring_offer and email, the tags of the three active filters and the Clear button" />

### Clear

Use **Clear** to reset all filters and return to the default view.

## What UTM fields mean (in plain language)

UTM parameters are labels added to a link so you can tell where traffic came from. The table shows the main ones, and **Actions** shows every field captured for a user:

| Field                     | What it means                                  | Example                            |
| ------------------------- | ---------------------------------------------- | ---------------------------------- |
| Source                    | The platform or origin                         | `google`, `facebook`, `newsletter` |
| Medium                    | The type of channel                            | `cpc`, `email`, `social`           |
| Campaign                  | The campaign name                              | `summer_promo`, `launch_2026`      |
| Content                   | The ad or link version                         | `banner_a`, `cta_button`           |
| Term                      | The paid search keyword                        | `ai_receptionist`                  |
| Campaign ID               | The campaign’s ID in your ad platform          | `spring_2026_01`                   |
| Source Platform           | The platform that manages the campaign         | `google_ads`                       |
| Creative Format           | The ad format                                  | `video`, `display`                 |
| Marketing Tactic          | The targeting approach                         | `remarketing`, `prospecting`       |
| Referrer                  | The page the user came from                    | `https://partner.example/blog`     |
| Landing URL               | The page the user landed on                    | `/pricing`, `/signup`, `/promo`    |
| Google Click ID (gclid)   | Added automatically by Google Ads              | —                                  |
| Facebook Click ID (fbclid)| Added automatically by Facebook and Instagram  | —                                  |

<Warning>
  **Common mistake:** Using inconsistent names (e.g., `Facebook`, `facebook`, `fb`). Pick one style and stick to it so reports are clean.
</Warning>

## Practical examples

### Example 1: Tracking a newsletter

Add UTM parameters to the link in your newsletter, for example:

`?utm_source=newsletter&utm_medium=email&utm_campaign=spring_offer`

Then, in **Filters**, type `newsletter` in **Source** and `spring_offer` in **Campaign** to see the users who signed up from that email.

### Example 2: Comparing landing pages

Send two versions of a landing page with different campaign names:

- Campaign A: `pricing_page_test`
- Campaign B: `homepage_test`

After a week, use the **From** and **to** dates and compare the **Campaign** card to see which landing page brought more signups.

## When a user asks “Where did this signup come from?”

A simple checklist:

<Steps>
  <Step>
    Search the user in **UTM Analytics**
  </Step>
  <Step>
    Check the user’s **Source** and **Campaign**, or click **Actions** to see all the fields
  </Step>
  <Step>
    If it’s blank, confirm they used the correct link (with UTM parameters)
  </Step>
</Steps>

<Tip>
  For consistent reporting, create a “link naming rule” for your team (for example: source in lowercase, campaigns with underscores, no spaces).
</Tip>
