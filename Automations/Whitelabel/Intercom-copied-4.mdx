## Avant de commencer
Intercom est bien plus qu’une simple fenêtre de chat. C’est une plateforme de support client qui vous permet de :
- Afficher un widget de chat dans votre application afin que les utilisateurs puissent poser des questions instantanément.
- Répondre depuis une console centralisée où toute votre équipe support travaille.
- Automatiser des messages, envoyer des visites guidées et même intégrer d’autres canaux comme l’e-mail, WhatsApp ou Slack.

Lorsque vous connectez Intercom à votre application, vous donnez à vos utilisateurs la possibilité d’obtenir de l’aide exactement au moment où ils en ont besoin, sans quitter l’écran.

Mais contrairement à Stripe ou SendGrid, cette intégration ne consiste pas seulement à coller une clé. En tant qu’administrateur, vous configurez l’**App ID** dans le CMS, puis un développeur doit insérer un petit extrait de code dans le frontend de votre application. C’est ce qui fait réellement apparaître le chat pour les utilisateurs.

## Étape 1 : Ouvrir le CMS et aller sur Intercom
Connectez-vous à votre CMS ici : allez dans le CMS.  
Dans le menu de gauche, cliquez sur **Integrations**, puis sélectionnez **Intercom**.

Un panneau s’affichera en demandant une valeur appelée `app_id`. Il s’agit de l’identifiant unique de votre projet Intercom, et c’est ce qui relie votre application à votre compte Intercom.

## Étape 2 : Trouver votre App ID dans Intercom
Pour récupérer votre App ID :
1. Connectez-vous à Intercom.
2. Allez dans **Settings > Messenger > Install**.
3. Vous y verrez un extrait de code (snippet).

La valeur dont vous avez besoin est celle de `app_id` (remplacez `"YOUR_APP_ID"` par votre App ID Intercom réel).

## Étape 3 : Ajouter l’App ID dans le CMS
De retour dans le CMS, dans la section Intercom :
1. Cliquez sur **Add API Key**.
2. Laissez le nom de clé sur `app_id`.
3. Collez votre App ID Intercom dans **Key Value**.
4. Marquez-le comme **Active** et enregistrez les modifications.

Votre application « sait » maintenant à quel compte Intercom elle doit se connecter.

## Étape 4 : Partager l’extrait de code avec votre développeur
C’est ici que votre développeur intervient. Ajouter l’App ID dans le CMS ne fera pas apparaître le chat à lui seul. L’extrait de code vu dans Intercom doit être inséré dans le frontend de votre application.

Où l’ajouter ?
- Dans une application React, votre développeur le placera généralement dans le fichier de layout principal.
- Sur un site statique, il peut être ajouté dans le `<head>` ou juste avant la balise de fermeture `</body>`.

Pourquoi un développeur ?
Parce que l’extrait peut aussi être personnalisé avec les données de vos utilisateurs (nom, e-mail, date d’inscription). Ainsi, lorsqu’un utilisateur ouvre le chat, votre équipe support sait déjà à qui elle parle, ce qui rend les échanges plus rapides et plus personnalisés.

## Étape 5 : Tester le chat
Une fois que votre développeur a ajouté le code :
1. Connectez-vous à votre application en tant qu’utilisateur normal.
2. Vous devriez voir l’icône Intercom en bas à droite.
3. Ouvrez-la et envoyez un message de test.
4. Votre équipe support doit voir ce message immédiatement dans la console Intercom.

## Erreurs fréquentes à éviter
- Oublier d’activer l’App ID dans le CMS → même si le code est installé, sans App ID actif le chat ne se connectera pas.
- Utiliser le mauvais App ID → chaque projet Intercom a son propre identifiant ; assurez-vous de copier le bon.
- Ne pas tester avec un vrai utilisateur → testez toujours en tant qu’utilisateur standard, pas uniquement en tant qu’administrateur.
- Ne pas transmettre l’extrait à votre développeur → rappelez-vous : les deux étapes sont obligatoires, **CMS + code frontend**.

## Intercom comme nouveau point d’accueil
Avec Intercom connecté, votre application devient plus qu’un simple logiciel. C’est un espace où les utilisateurs savent qu’ils peuvent vous joindre instantanément. Cela renforce la confiance, maintient l’engagement et donne à votre équipe support une visibilité en temps réel sur ce qui se passe.

Donc : configurez votre **App ID**, transmettez l’extrait à votre développeur et vérifiez que le chat s’affiche. Une fois fait, vous avez débloqué un canal de communication direct dans votre application.
