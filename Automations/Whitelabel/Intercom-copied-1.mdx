## Bevor du beginnst
Intercom ist mehr als nur ein Chat-Fenster. Es ist eine Customer-Support-Plattform, mit der du:
- Ein Chat-Widget in deiner Anwendung anzeigen kannst, damit Nutzer sofort Fragen stellen können.
- Aus einer zentralen Konsole antworten kannst, in der dein gesamtes Support-Team arbeitet.
- Nachrichten automatisieren, Guided Tours senden und sogar weitere Kanäle wie E-Mail, WhatsApp oder Slack integrieren kannst.

Wenn du Intercom mit deiner App verbindest, gibst du deinen Nutzern die Möglichkeit, genau dann Hilfe zu bekommen, wenn sie sie brauchen — ohne den Bildschirm zu verlassen.

Aber anders als bei Stripe oder SendGrid geht es bei dieser Integration nicht nur darum, einen Key einzufügen. Du als Admin konfigurierst die App ID im CMS, und anschließend muss ein Entwickler ein kleines Code-Snippet im Frontend deiner Anwendung einfügen. Erst dadurch erscheint der Chat für die Nutzer.

## Schritt 1: CMS öffnen und zu Intercom gehen
Melde dich hier in deinem CMS an: go to CMS.  
Klicke im linken Menü auf Integrations und wähle anschließend Intercom.  
Es erscheint ein Panel, das nach einem Wert namens app_id fragt. Das ist die eindeutige Kennung deines Intercom-Projekts und verbindet deine Anwendung mit deinem Intercom-Konto.

## Schritt 2: App ID in Intercom finden
So bekommst du deine App ID:
Melde dich bei Intercom an.  
Gehe zu Settings > Messenger > Install.

Der Wert, den du brauchst, ist der in app_id; ersetze YOUR_APP_ID durch deine tatsächliche Intercom App ID.

## Schritt 3: App ID im CMS hinzufügen
Zurück im CMS, im Intercom-Bereich:
Klicke auf Add API Key.  
Lass den Key-Namen auf app_id.  
Füge deine Intercom App ID in Key Value ein.  
Markiere es als Active und speichere die Änderungen.  
Jetzt „weiß“ deine App, mit welchem Intercom-Konto sie sich verbinden soll.

## Schritt 4: Code-Snippet an deinen Entwickler weitergeben
Hier kommt dein Entwickler ins Spiel. Das Eintragen der App ID im CMS sorgt nicht automatisch dafür, dass der Chat erscheint. Das Code-Snippet, das du in Intercom gesehen hast, muss im Frontend deiner App eingebunden werden.

Wo wird es eingefügt?
In einer React-App platziert man es normalerweise in der Haupt-Layout-Datei.  
Auf einer statischen Website kann es im head oder direkt vor dem schließenden body-Tag eingefügt werden.

Warum der Entwickler? Weil das Snippet außerdem mit Nutzerdaten angepasst werden kann: Name, E-Mail, Registrierungsdatum. So weiß dein Support-Team beim Öffnen des Chats sofort, mit wem es spricht — Gespräche werden schneller und persönlicher.

## Schritt 5: Chat testen
Sobald dein Entwickler den Code eingebunden hat:
Melde dich in deiner Anwendung als normaler Nutzer an.  
Du solltest das Intercom-Icon unten rechts sehen.  
Öffne es und sende eine Testnachricht.  
Dein Support-Team sollte diese Nachricht sofort in der Intercom-Konsole sehen.

## Häufige Fehler vermeiden
App ID im CMS nicht aktiviert → selbst wenn der Code installiert ist, verbindet sich der Chat ohne aktive App ID nicht.  
Falsche App ID verwendet → jedes Intercom-Projekt hat seine eigene ID; stelle sicher, dass du die richtige kopierst.  
Nicht mit einem echten Nutzer testen → teste immer als Standardnutzer, nicht nur als Admin.  
Snippet nicht an den Entwickler weitergegeben → beide Schritte sind erforderlich: CMS + Frontend-Code.

## Intercom als deine neue „Rezeption“
Mit verbundenem Intercom wird deine App mehr als nur Software. Sie wird zu einem Ort, an dem Nutzer wissen, dass sie dich sofort erreichen können. Das schafft Vertrauen, hält Nutzer engagiert und gibt deinem Support-Team in Echtzeit Einblick in das, was passiert.

Also: Konfiguriere deine App ID, gib das Snippet an deinen Entwickler weiter und bestätige, dass der Chat erscheint. Danach hast du einen direkten Kommunikationskanal in deiner App freigeschaltet.
