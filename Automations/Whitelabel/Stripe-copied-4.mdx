## Avant de commencer
Stripe est la passerelle de paiement qui permet à votre application de traiter les paiements de manière sécurisée et professionnelle. En le connectant, vous pouvez accepter des cartes de crédit, des cartes de débit et même des moyens de paiement locaux selon le pays dans lequel vous opérez.

Vous n’avez pas besoin de connaissances techniques avancées : Stripe gère toutes les exigences de sécurité et de conformité (comme la norme PCI DSS), tandis que votre application s’intègre de façon fluide pour que vos clients puissent payer sans complications.

## Étape 1 : Accéder à la section Intégrations
Dans le CMS, ouvrez le menu de gauche et cliquez sur **Integrations**. Vous verrez ici quatre options : Stripe, Twilio, Sendgrid et Intercom.  
Sélectionnez **Stripe**. C’est l’intégration qui active et gère les paiements dans votre application.

## Étape 2 : Démarrer le processus de connexion
Après avoir cliqué sur Stripe, vous serez redirigé vers la page officielle de connexion de Stripe. Là, vous pouvez soit vous connecter avec un compte existant, soit en créer un nouveau si vous n’en avez pas encore.

L’écran affichera un formulaire intitulé « Get started with Stripe ». Vous devez y saisir votre adresse e-mail.  
- Si vous avez déjà un compte Stripe, utilisez le même e-mail pour le lier.  
- Si vous n’en avez pas, Stripe vous guidera pour créer un nouveau compte avec les informations de votre entreprise.

## Étape 3 : Compléter les informations de votre entreprise dans Stripe
Avant de finaliser la connexion, Stripe vous demandera de confirmer ou de compléter certains éléments :

- **Informations sur l’entreprise :** raison sociale, adresse de l’entreprise, pays.  
- **Représentant de l’entreprise :** une personne ayant des responsabilités de gestion dans l’entreprise.  
- **Compte bancaire :** le compte sur lequel Stripe versera les paiements.  
- **Informations fiscales :** selon le pays, Stripe peut demander un numéro de TVA, un numéro fiscal (TIN) ou l’équivalent.

Conseil pratique : préparez ces informations à l’avance. Si l’inscription est interrompue parce qu’il manque quelque chose, vous devrez relancer le processus.

## Étape 4 : Autoriser l’accès et connecter votre application
Une fois toutes les informations renseignées, Stripe vous demandera de confirmer que vous autorisez votre application à traiter des paiements en votre nom.  
Cliquez sur **Authorize access**.

Quand le processus est terminé, vous reviendrez automatiquement dans le CMS de votre application et vous verrez que l’intégration Stripe est active.

## Erreurs fréquentes et solutions
- **Mauvais e-mail** → assurez-vous d’utiliser l’e-mail associé à votre compte Stripe.  
- **Informations d’entreprise incomplètes** → s’il manque des informations fiscales ou bancaires, Stripe ne vous laissera pas finaliser.  
- **Compte bancaire invalide** → vérifiez qu’il est dans le même pays que l’entreprise enregistrée et qu’il accepte les virements.  
- **Pas de redirection vers le CMS** → vérifiez que les pop-ups ou redirections ne sont pas bloqués par votre navigateur.

## Votre application est prête à encaisser des paiements
Avec Stripe intégré, votre application peut désormais accepter des paiements sécurisés et les transférer directement sur votre compte bancaire. Vous pouvez ainsi monétiser vos services de manière transparente et fiable pour vos clients.
