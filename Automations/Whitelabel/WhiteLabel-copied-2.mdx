## Resumen
Personaliza tu app de Callin con el nombre de tu marca, logo y dominio. Esta guía te lleva paso a paso por la configuración white-label y la configuración del dominio (automática o manual), además de opciones de logo y moneda.

Antes de empezar:
- Tener un dominio y acceso a DNS (Cloudflare, GoDaddy, Namecheap, etc).
- Preferir usar un subdominio como `app.tudominio.com`.
- Para DNS automático, preparar credenciales de API con permisos de edición de DNS.
- Abrir [CMS → White-Label Settings](https://app.callin.io/cms).

## Pasos

### 1. Nombra tu app
En **App Name**, introduce tu marca. Este nombre aparece en tu interfaz y en emails.

### 2. Conecta tu dominio
Ve a **Custom Domain**.
Elige configuración automática (recomendada) o manual de DNS.

**Introduce tu subdominio completo**, por ejemplo `app.tudominio.com`.

#### DNS en 2 minutos
- Un **registro A** asigna un nombre a una dirección IP.
- Un **CNAME** asigna un nombre a otro hostname (alias).
- **TTL** (Time To Live) define la duración del caché; usa 300 para actualizaciones rápidas.
- La **propagación** puede tardar 5–30 min, hasta 24h según el proveedor.

**Tip:** Usa un subdominio (no `@`) para evitar afectar tu web principal.

#### Opción A — Configuración automática
1. Elige tu **DNS Provider**: Cloudflare, GoDaddy o Namecheap.
2. Introduce credenciales:
   - **Cloudflare**: API Token (Edit DNS en la zona).
   - **GoDaddy**: API Key + Secret.
   - **Namecheap**: API User, Key y Client IP en lista blanca.
3. Haz clic en **Discover Provider**.
4. Callin valida el acceso y crea los registros.
5. SSL se emite automáticamente.

**Important (Cloudflare):** Si la validación falla con **orange cloud (proxied)**, cambia a **DNS Only (grey)**, completa la emisión de SSL y luego vuelve a activar el proxy si lo necesitas.

#### Opción B — Configuración manual
1. Selecciona **Manual**.
2. Añade los registros DNS que aparecen en la tabla del CMS en tu registrador:
   - `Type: A` → `Host: @ or subdomain` → `Value: <IP>` → `TTL: 300`
   - `Type: CNAME` → `Host: www` (si aparece) → `Value: <host>` → `TTL: 300`
3. Vuelve al CMS y haz clic en **Install SSL**.

**Warning:** Evita registros duplicados o en conflicto — bloquean la verificación.

### 3. Colores y logos
Configura tus **Primary/Secondary Colors** y sube:
- **Logo** (PNG/SVG, fondo transparente).
- **Favicon** (ICO/PNG, 32×32 o 48×48).

### 4. Moneda por defecto
Elige tu **Default Currency** para el precio de planes. Ver [[Create-AI-Agent/Billing]].

### 5. Ajustes avanzados de llamadas (opcional)
- **[BYOC]**: Bring Your Own Carrier (añade tu troncal SIP).
- **[Recordings]**: Guarda grabaciones en tu propio bucket compatible con S3.
- **[AMD]**: Ajusta la detección de humano vs buzón de voz.

## Consejos y notas
- Prefiere `app.tudominio.com` para evitar romper el dominio raíz.
- TTL 300 asegura propagación rápida durante la configuración.
- Usa **DNS Only (grey)** en Cloudflare al emitir SSL.

## Solución de problemas

**Falló la verificación del dominio**  
**Causa:** Host incorrecto, conflictos o retraso de propagación.  
**Solución:**
- Revisa el host (`app`, no `www`).
- Elimina registros duplicados.
- Ajusta TTL a 300.
- Espera hasta 30 min.

**SSL no se emite**  
**Causa:** Verificación incompleta.  
**Solución:**
- Haz clic en **Install SSL**.
- Confirma que el hostname resuelve a la IP de Callin.
- Asegúrate de que HSTS/proxies no bloquean el challenge de ACME.

**Credenciales de API inválidas**  
**Solución:**
- Asegúrate de que los tokens tienen **Edit DNS** en la zona correcta.
- Namecheap: añade tu IP a la whitelist.

**Se rompió el sitio apex**  
**Solución:** Usa siempre un subdominio (como `app.`). No cambies registros `@`.

**Los cambios no se ven**  
**Solución:** Limpia la caché DNS o cambia de red. Usa una búsqueda DNS para confirmar registros.
