## Warum SendGrid wichtig ist
Stell dir vor, ein Nutzer registriert sich in deiner App. Er erwartet innerhalb von Sekunden eine Bestätigungs-E-Mail. Wenn diese E-Mail nie ankommt, ist die erste Erfahrung bereits kaputt. Das Gleiche gilt für Passwort-Resets oder Benachrichtigungen: Ohne einen vertrauenswürdigen E-Mail-Dienst wirkt deine App unzuverlässig.  

Genau das löst SendGrid. Es ist eine professionelle Plattform für E-Mail-Zustellung, die dafür sorgt, dass deine Nachrichten im Posteingang landen statt im Spam. Wenn du SendGrid verbindest, gibst du deiner App einen verifizierten „Zusteller“, der zuverlässig liefert.  

Damit es funktioniert, braucht deine App zwei Dinge:  
- **Einen API Key** → das ist der sichere Weg, wie sich deine App automatisch bei SendGrid authentifiziert.  
- **Eine Absender-E-Mail** → das ist die „From“-Adresse, die Nutzer im Posteingang sehen, und sie sollte professionell wirken.  

## Schritt 1: CMS öffnen und zu SendGrid gehen
Starte, indem du dich in deinem CMS anmeldest. Klicke links auf **Integrations** und wähle dann **SendGrid**. Du siehst zwei Felder: api_key und sender_email.  

Sieh diese beiden wie ein Schloss und ein Namensschild:  
- Der **API Key** ist das Schloss-und-Schlüssel-System, das deiner App Zugriff auf SendGrid gibt.  
- Die **Sender Email** ist das Namensschild, das deinen Nutzern sagt: „Diese E-Mail kommt von uns.“  

Ohne beides kann deine App keine E-Mails senden.  

## Schritt 2: API Key in SendGrid erstellen
Jetzt holen wir den Schlüssel, der SendGrid für deine App „aufschließt“.  

1. Melde dich bei https://app.sendgrid.com an.  
2. Gehe zu **Settings > API Keys**.  
3. Klicke auf **Create API Key**. Gib ihm einen klaren Namen wie „App Integration“.  
4. Wähle Berechtigungen. Wenn du unsicher bist, wähle **Full Access**, mindestens brauchst du **Mail Send**.  
5. Kopiere den API Key.  

Er sieht ungefähr so aus:  
SG.YOUR_API_KEY_EXAMPLE  

Dieser Key wird jedes Mal benötigt, wenn deine App eine E-Mail sendet. Wenn der Key falsch ist, schlägt jede einzelne E-Mail fehl. Behandle ihn wie ein Passwort: sicher und geheim.  

## Schritt 3: API Key im CMS hinzufügen
Zurück im CMS, unter SendGrid:  
1. Klicke auf **Add API Key**.  
2. Lass **Key Name** auf api_key und ändere ihn nicht.  
3. Füge deinen SendGrid-Key in **Key Value** ein.  
4. Füge eine Beschreibung hinzu, z. B. „Main SendGrid Key“.  
5. Markiere es als **Active** und klicke auf **Save Key**.  

Jetzt weiß deine App, wie sie sich bei SendGrid anmelden kann.  

## Schritt 4: Absender-E-Mail hinzufügen
Die nächste Frage ist: „Wenn meine App eine E-Mail sendet, von wem sieht es aus, als käme sie?“  

Hier legst du die sender_email fest. Sie sollte professionell sein und zu deiner Marke passen. Zum Beispiel:  
- support@yourcompany.com  
- notifications@yourcompany.com  

Vermeide persönliche Gmail- oder Outlook-Adressen, weil sie unprofessionell wirken und häufiger als Spam markiert werden.  

Zurück im CMS, klicke erneut auf **Add API Key** und fülle es so aus:  
- Key Name: sender_email (so lassen, nicht ändern).  
- Key Value: die von dir gewählte E-Mail-Adresse.  
- Description: z. B. „Support Email Address“.  
- Als Active markieren und speichern.  

Wichtig: SendGrid sendet nur von Domains, die du verifiziert hast. Das heißt: Wenn du support@yourcompany.com einträgst, musst du yourcompany.com zuerst in SendGrid authentifizieren. Andernfalls können E-Mails direkt im Spam landen.  

## Schritt 5: Setup testen
Vertrau nicht nur den Einstellungen — teste es.  

Registriere dich mit einem neuen Testkonto in deiner App oder fordere einen Passwort-Reset an. Innerhalb weniger Sekunden solltest du die E-Mail in deinem Posteingang sehen.  

Wenn sie nicht ankommt: Prüfe zuerst den Spam-Ordner und bestätige dann, dass deine Absender-Domain in SendGrid verifiziert ist.  

## Häufige Fehler
- Keys sind inaktiv: Wenn der Toggle nicht auf Active steht, versucht die App gar nicht zu senden.  
- Key-Namen geändert: Das System erkennt nur api_key und sender_email.  
- Unverifizierte Domains: Authentifiziere immer deine Absender-Domain in SendGrid.  
- Falscher Key kopiert: SendGrid zeigt den vollständigen API Key nur einmal. Wenn du ihn verlierst, musst du einen neuen generieren.  

## Deine App ist bereit, E-Mails zu senden
Mit SendGrid verbunden erhalten deine Nutzer Bestätigungen, Resets und Updates zuverlässig und pünktlich. Kein manuelles Versenden, kein Rätselraten, ob es im Spam gelandet ist — einfach reibungslose, verlässliche Kommunikation.  

Sobald das steht, eliminierst du eine der größten Frustrationen neuer Nutzer: „Ich habe mich registriert, aber nie eine E-Mail erhalten.“
