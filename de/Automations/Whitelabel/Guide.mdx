## Wofür dieser Bereich gedacht ist

Unter **Anleitungen** fügen Sie **Ihre eigenen Dokumentations-Links** für Ihre Kunden in Callin hinzu.

Das ist nützlich, wenn Ihre Unterkonten Hilfe direkt aus der App öffnen sollen, zum Beispiel:

- Eine Wissensdatenbank (zum Beispiel Mintlify)
- Einen Notion-Bereich
- Ein Hilfecenter auf Ihrer Website
- Ein Google-Dokument oder ein internes Wiki

> **Wichtig:** Unterkonten sehen hier nicht die offizielle Callin-Dokumentation. Diese trägt das Callin-Branding. Veröffentlichen Sie deshalb im White Label **Ihre eigene** Dokumentation und verlinken Sie sie in diesem Bereich.

Sie finden sie in der White-Label-Plattform unter **Inhaltsverwaltung** ([hier öffnen](https://app.callin.io/cms/guides)).

## So funktioniert es

Jeder Eintrag hier ist ein **Link**, den Ihre Unterkonten sehen, solange er aktiv ist. Wer Hilfe braucht, klickt auf die Anleitung und landet auf der angegebenen URL.

Eine Anleitung enthält:

- Einen **Titel**: Er erscheint im seitlichen Navigationsmenü
- Eine **Beschreibung**: worum es in der Anleitung geht
- Eine **URL**: wohin der Nutzer geleitet wird
- Einen Schalter **Aktiv**: zum Ein- oder Ausblenden

## Einen neuen Anleitungs-Link hinzufügen

1. Klicken Sie auf **Neu hinzufügen**.
2. Füllen Sie die Felder aus (alle drei sind Pflichtfelder):
   - **Titel**: der Name, den Nutzer wiedererkennen (zum Beispiel „Hilfecenter“). Maximal 50 Zeichen.
   - **Beschreibung**: eine kurze Erklärung (zum Beispiel „Schritt-für-Schritt-Tutorials und FAQs“).
   - **URL**: der vollständige Link, den Nutzer öffnen sollen (zum Beispiel Ihre Mintlify-Seite oder Ihre eigene Support-Seite).
3. Lassen Sie **Aktiv** eingeschaltet, wenn Unterkonten die Anleitung sofort sehen sollen. Der Schalter ist standardmäßig an.
4. Klicken Sie auf **Speichern**.

### Praxisbeispiel

Wenn Ihre Dokumentation auf Mintlify liegt, könnten Sie Folgendes anlegen:

- Titel: **Dokumentation**
- Beschreibung: „Anleitungen zu Einrichtung, Abrechnung und Best Practices.“
- URL: „Die URL Ihrer Mintlify-Dokumentation“
- Aktiv: **Ein**

Fragt ein Kunde dann „Wo finde ich die Einrichtungsanleitung?“, verweisen Sie ihn auf den hier veröffentlichten Link.

## Bestehende Anleitungen verwalten

Die Liste zeigt für jede Anleitung **Titel**, **Beschreibung**, **URL** und **Status**. Dort können Sie:

- Mit **Anleitungen suchen...** eine Anleitung schnell finden.
- Auf **⋮** → **Bearbeiten** klicken, um Titel, Beschreibung oder URL zu ändern oder **Aktiv** auszuschalten und sie auszublenden.
- Auf **⋮** → **Löschen** klicken, um sie zu entfernen.

> **Häufiger Fehler:** Auf eine private Seite verlinken. Stellen Sie sicher, dass Ihre Kunden die URL öffnen können (oder erklären Sie klar, falls eine Anmeldung nötig ist).
