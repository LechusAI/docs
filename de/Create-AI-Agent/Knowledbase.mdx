## Wofür die Wissensdatenbank gedacht ist

Die **Wissensdatenbank** ist der Ort, an dem Sie Informationen speichern, die Ihre KI-Agenten während Gesprächen nutzen können – damit sie nicht nur vom Haupt-Prompt abhängen. Sie eignet sich für lange oder detaillierte Inhalte wie Handbücher, FAQs oder Richtlinien, die nicht in den Prompt passen.

Typische Anwendungsfälle:

- Fragen zu Ihrem Unternehmen beantworten (Leistungen, Preise, Richtlinien, Öffnungszeiten).
- Nutzer durch Abläufe führen (Schritte zur Erstattung, Terminvorbereitung, Onboarding).
- Einheitliche Antworten über mehrere Agenten hinweg sicherstellen.

Hier geht es zur Seite: [Wissensdatenbank](https://app.callin.io/knowledge-base)

Die Seite hat oben rechts zwei Tabs:

- **Dateien**: Dokumente, die Sie hochladen (PDF, DOC, DOCX, TXT), in Gruppen organisiert.
- **Web**: Webseiten (URLs), aus denen der Agent lernt und die Sie in Ordnern organisieren können.

<Tip>
  Sehen Sie die Wissensdatenbank als „freigegebenes Referenzmaterial“, das der Agent heranziehen kann, wenn jemand detaillierte Fragen stellt.
</Tip>

## Wie das mit KI-Agenten zusammenhängt

Sie fügen die Inhalte nicht direkt in einen Agenten ein. Stattdessen:

<Steps>
  <Step>
    Erstellen Sie die Inhalte hier in der Wissensdatenbank (Dateien oder Web-URLs).
  </Step>
  <Step>
    Danach öffnen Sie im Agenten-Editor den Tab **Wissensdatenbank** und **fügen die Dokumente hinzu**, die dieser Agent nutzen soll.
  </Step>
</Steps>

Dasselbe Dokument kann von mehreren Agenten genutzt werden.

## Wissensdatenbank mit Dateien

Im Tab **Dateien** laden Sie Dokumente hoch, aus denen Ihr Agent lernen soll (zum Beispiel eine Richtlinie als PDF, ein Skript als DOCX oder eine FAQ als TXT). Dateien werden in **Gruppen** organisiert, damit zusammengehörige Dokumente beieinander bleiben.

Neben **Wissensdatenbank erstellen** können Sie zwischen zwei Ansichten wechseln: einer **Liste** aller Dateien oder Ihren **Gruppen** als Ordner. Mit **Dateien suchen...** finden Sie ein Dokument.

### Eine Dateigruppe erstellen und Dokumente hochladen

<Steps>
  <Step>
    Öffnen Sie den Tab **Dateien**.
  </Step>
  <Step>
    Klicken Sie auf **Wissensdatenbank erstellen**.
  </Step>
  <Step>
    Geben Sie im Fenster **Dateien hochladen** einen **Gruppennamen** ein (Pflichtfeld). Die hochgeladenen Dateien werden unter diesem Namen gruppiert.
  </Step>
  <Step>
    Fügen Sie Ihre Dokumente hinzu:
    - Ziehen Sie die Dateien per Drag & Drop in den Upload-Bereich, oder
    - Klicken Sie auf **Dateien auswählen**, um sie auszuwählen.
  </Step>
  <Step>
    Klicken Sie auf **Dateien hochladen**, um abzuschließen.
  </Step>
</Steps>

Unterstützte Formate und Limits (wie im Upload-Fenster angezeigt):

- PDF, DOC, DOCX, TXT
- Max. 5MB pro Datei

<Frame caption="Screenshot: Das Fenster Dateien hochladen, in dem Sie die Gruppe benennen und Ihre Dokumente hinzufügen.">
  <img src="/images/knowledgebase1.png" alt="Das Fenster Dateien hochladen mit dem Feld Gruppenname, dem Drag-and-drop-Bereich mit der Schaltfläche Dateien auswählen, den unterstützten Formaten (PDF, DOC, DOCX, TXT, max. 5MB pro Datei) und der Schaltfläche Dateien hochladen." />
</Frame>

<Warning>
  **Häufiger Fehler:** Mehrere themenfremde Dokumente in eine Gruppe zu packen. Wenn Sie unterschiedliche Anwendungsfälle haben (Vertrieb vs. Support), erstellen Sie getrennte Gruppen, damit jeder Agent das passende Wissen bekommt.
</Warning>

### Dateien in einer Gruppe verwalten und aktualisieren

Sobald eine Gruppe existiert, können Sie sie öffnen und ihren Inhalt verwalten:

- Weitere Dokumente hinzufügen.
- Die Liste der **Aktuellen Dateien** ansehen, die bereits enthalten sind.
- Dateien entfernen, die der Agent nicht mehr nutzen soll.

<Tip>
  Verwenden Sie klare Gruppennamen wie **„Support-Richtlinien“**, **„Preise & Tarife“** oder **„Aufnahmeskript der Praxis“**, damit Sie später schnell die richtigen Dokumente finden.
</Tip>

## Wissensdatenbank mit Web-URLs

Im Tab **Web** lernt Ihr Agent aus Webseiten. Das ist hilfreich, wenn Ihre maßgeblichen Informationen auf Ihrer Website liegen (Hilfecenter, Dokumentation, Richtlinienseiten, Landingpages).

Die Liste zeigt jede URL mit **Name**, Adresse und **Zuletzt aktualisiert**. Mit **Wissensdatenbank durchsuchen...** finden Sie eine URL.

### Eine URL hinzufügen

<Steps>
  <Step>
    Öffnen Sie den Tab **Web**.
  </Step>
  <Step>
    Klicken Sie auf **URL hinzufügen**.
  </Step>
  <Step>
    Füllen Sie aus:
    - **Übergeordneter Ordner**: wo die URL gespeichert wird. Standardmäßig **Wissensdatenbank (oberste Ebene)**.
    - **Titel** (Pflichtfeld): ein klarer Name für diese Seite (zum Beispiel „Preisseite“).
    - **URL** (Pflichtfeld): der Link zur Webseite.
  </Step>
  <Step>
    (Optional) Aktivieren Sie die **Automatische Aktualisierung**, damit Callin die Seite regelmäßig neu einliest. Wählen Sie dann das **Intervall** und die **Einheit** (**Tage** oder **Stunden**). Standardmäßig alle **7 Tage**.
  </Step>
  <Step>
    Klicken Sie auf **URL hinzufügen**, um sie zu speichern.
  </Step>
</Steps>

<Frame caption="Video: URL hinzufügen → Titel und URL → automatische Aktualisierung mit Intervall → Ordner erstellen → Details einer URL anzeigen.">
  <video autoPlay muted loop playsInline src="/images/knowledge-base-web.mp4" />
</Frame>

Mit aktivierter automatischer Aktualisierung sieht das Fenster so aus:

<Frame caption="Screenshot: Das Fenster URL hinzufügen mit aktivierter automatischer Aktualisierung.">

<Tip>
  Aktivieren Sie die **Automatische Aktualisierung** für Seiten, die sich oft ändern, etwa Preise oder Öffnungszeiten, damit Ihr Agent immer mit den aktuellsten Informationen antwortet.
</Tip>

### URLs in Ordnern organisieren

Um zusammengehörige Seiten zu bündeln (zum Beispiel alle Seiten Ihrer Website), klicken Sie auf **Ordner erstellen**:

<Steps>
  <Step>
    Wählen Sie den **Übergeordneten Ordner** (oder lassen Sie **Wissensdatenbank (oberste Ebene)**).
  </Step>
  <Step>
    Geben Sie den **Ordnernamen** ein (Pflichtfeld).
  </Step>
  <Step>
    (Optional) Aktivieren Sie die **Automatische Aktualisierung**, um alle URLs im Ordner im gewählten Intervall zu aktualisieren.
  </Step>
  <Step>
    Klicken Sie auf **Ordner erstellen**.
  </Step>
</Steps>

Wenn Sie danach eine URL hinzufügen, wählen Sie diesen Ordner unter **Übergeordneter Ordner**.

<Tip>
  Halten Sie Ordner fokussiert. Zum Beispiel ein Ordner für die Seiten **„Preise & Abrechnung“** und ein anderer für **„Erstattungsrichtlinie“**.
</Tip>

### Eine URL ansehen, aktualisieren oder löschen

Klicken Sie rechts neben einer URL auf **⋯**, um ihr Menü zu öffnen:

- **Details anzeigen**: öffnet ein Fenster mit **Dokument-ID**, **Zuletzt aktualisiert**, **Dokumentgröße**, **Quell-URL** und **Automatische Aktualisierung**, und rechts mit dem **URL-Inhalt** (dem Text, den Ihr Agent tatsächlich von dieser Seite liest). Mit **Inhalt aktualisieren** wird die Seite sofort neu eingelesen.
- **ID kopieren**: kopiert die Dokument-ID.
- **Löschen**: entfernt die URL aus der Wissensdatenbank.

<Frame caption="Screenshot: Details anzeigen zeigt den Text, den der Agent von der Seite liest.">
  <img src="/images/knowledge-base-details.png" alt="Das Detailfenster einer URL mit Dokument-ID, Zuletzt aktualisiert, Dokumentgröße, Quell-URL und automatischer Aktualisierung links und dem URL-Inhalt mit der Schaltfläche Inhalt aktualisieren rechts." />
</Frame>

<Warning>
  Prüfen Sie nach dem Hinzufügen einer Seite den **URL-Inhalt**. Ist er leer oder zeigt er den falschen Text (zum Beispiel einen Cookie-Hinweis), kann der Agent diese Seite nicht nutzen. Versuchen Sie eine andere URL mit denselben Informationen.
</Warning>

## Eine Wissensdatenbank für einen Agenten auswählen

Sobald Ihre Dokumente angelegt sind (Dateien oder Web-URLs), weisen Sie sie im Agenten-Editor einem Agenten zu.

<Frame caption="Screenshot: Ein Dokument aus der Wissensdatenbank beim Bearbeiten eines KI-Agenten hinzufügen.">
  <img src="/images/knowledgebase3.png" alt="Der Tab Wissensdatenbank des Agenten mit geöffneter Liste Dokument hinzufügen: ein Suchfeld, die Dokumente der Wissensdatenbank und unten eine Schaltfläche Dokument hinzufügen." />
</Frame>

### Eine Gruppe einem Agenten zuweisen

<Steps>
  <Step>
    Gehen Sie zu **KI-Agenten** und öffnen Sie einen Agenten zum Bearbeiten.
  </Step>
  <Step>
    Öffnen Sie den Tab **Wissensdatenbank**.
  </Step>
  <Step>
    Klicken Sie auf **Dokument hinzufügen**.
  </Step>
  <Step>
    Suchen Sie mit **Dokumente suchen...** das gewünschte Dokument und klicken Sie darauf, um es dem Agenten hinzuzufügen.
  </Step>
  <Step>
    Wiederholen Sie das für jedes Dokument, das der Agent braucht.
  </Step>
</Steps>

Wenn das benötigte Dokument noch nicht existiert, klicken Sie unten in der Liste auf **Dokument hinzufügen**. Sie gelangen dann zur Seite **Wissensdatenbank**, um es anzulegen.

<Tip>
  Wenn Sie mehrere Agenten mit unterschiedlichen Rollen haben, geben Sie jedem nur die Dokumente, die er braucht, damit sie fokussiert bleiben und nicht außerhalb ihres Aufgabenbereichs antworten.
</Tip>

## Praxisbeispiel

Angenommen, Sie betreiben eine Zahnarztpraxis und haben zwei Agenten:

- **Empfangs-Agent** (Termine, Öffnungszeiten, Anfahrt)
- **Abrechnungs-Agent** (Preise, Rechnungen, Versicherungsfragen)

Ein gutes Setup könnte so aussehen:

- Dateigruppe: **„Praxis-FAQs (TXT)“** für schnelle Antworten und Skripte
- Web-Ordner: **„Preis- & Versicherungsseiten“** mit den öffentlichen Seiten Ihrer Website, mit aktivierter **Automatischer Aktualisierung**

Dann:

- Der **Empfangs-Agent** erhält die FAQ-Dokumente.
- Der **Abrechnungs-Agent** erhält die Preis- und Versicherungsseiten.
