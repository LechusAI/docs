The Callin connector lets Claude place real phone calls on your behalf with your Callin voice agents, and read your agents, call history and transcripts. It works in Claude on the web, on desktop and in the mobile apps.

## What you can do

- **Make a call for you** — "Call +39 06 1234 5678 and book a table for two tomorrow at 8 pm, name Rossi." Claude confirms the number and the goal with you, a Callin agent makes the call in the right language, and you get the outcome, a summary and the transcript in the chat.
- **Follow a call** — "How did the call go?" Claude checks the status and reports back when the call ends.
- **Review your calls** — "Show my latest inbound calls", "Summarize yesterday's call with +44…", "Find calls of my Reception agent this week."
- **Check your agents** — "Show my Callin agents."

Once connected, Claude has these tools:

| Tool | What Claude uses it for |
|------|-------------------------|
| **List Callin agents** / **Get Callin agent** | See your agents and the details of one agent |
| **List Callin calls** / **Get Callin call** | See your call history and the details of one call |
| **Search Callin calls** | Find calls by agent, date, direction or phone number |
| **Read Callin transcript** | Read what was said in a call |
| **Get phone call status** | Follow a call while it is in progress |
| **Place a phone call** | Make a call for you, only after you approve it |

More questions you can ask:

- "Show my latest 10 calls."
- "Summarize my latest customer call."
- "Show my inbound calls from today."
- "Find calls handled by my sales agent this week."

## Requirements

- A Callin account ([app.callin.io](https://app.callin.io)).
- A Claude account (web, desktop or mobile app).
- For calls: an outbound agent with a phone number (an agent named "Task Caller" is used first), a Callin API key and available minutes.

You'll find your API key in Callin, in your **Profile → API Keys** ([open it](https://app.callin.io/profile?subSection=api)). If it says "No API key found", click **Regenerate Key** to create one.

## Connect

You can start from Claude or from Callin. Both ways end on the same Callin consent screen.

### From Claude

<Steps>
  <Step>
    In Claude, open **Customize → Connectors**.
  </Step>
  <Step>
    Find **Callin** and click **Connect**. If Callin isn't listed yet, click **Add → Add custom connector**, enter the name **Callin** and the URL `https://claude-mcp.callin.io/mcp`, click **Add**, and then **Connect**.
  </Step>
  <Step>
    Sign in to Callin if asked, and click **Allow access** on the consent screen.
  </Step>
  <Step>
    Start a new chat and ask Claude to call someone or about your calls.
  </Step>
</Steps>

### From Callin

<Steps>
  <Step>
    In Callin, go to **Actions** and click **Connect** on the **Claude** card. The **Claude × Callin** page opens.
  </Step>
  <Step>
    Under **Callin connector URL**, click **Copy URL**.
  </Step>
  <Step>
    Click **Connect Claude**. Claude opens in a new tab.
  </Step>
  <Step>
    In Claude, open **Customize → Connectors**, click **Add → Add custom connector**, and paste the URL. Then click **Add** and **Connect**.
  </Step>
  <Step>
    Click **Allow access** on the Callin consent screen.
  </Step>
</Steps>

### Choose when Claude can use each tool

In Claude, open **Customize → Connectors → Callin** to see the connector's tools, grouped as read-only tools and write tools (**Place a phone call**). By default, each one needs your approval: the first time Claude wants to use a tool in a chat, it asks you, and you can allow it once or always.

<Note>
  Keep **Place a phone call** on approval, so that no call is placed without your OK.
</Note>

## How calls work

<Note>
  Claude always asks you to approve a call before it is placed.
</Note>

- The agent opens every call by saying it is an AI assistant calling on behalf of a customer.
- Supported call languages: Italian, English, Spanish, French, German, Portuguese and Dutch.
- Only full international numbers (for example +39…, +44…, +1…) can be called. Emergency and short numbers cannot.
- At most 10 calls per hour per account. Calls use your Callin minutes like any other call.
- Calls are recorded and transcribed as in your Callin account, and appear in your Callin call history.

## Privacy and security

- Claude only sees the agents and calls of your own Callin account (or your team's).
- Claude never receives your API key, agent prompts or billing data, and cannot change agents or settings.
- Transcripts may contain what the other person said; Claude treats them as information, never as instructions.
- See the [Callin privacy policy](https://callin.io/legal-pages/privacy-policy).

## Disconnect

Remove the connector in Claude (**Customize → Connectors → Callin → Disconnect**) or in Callin (**Actions → Claude → Disconnect Claude**). Existing tokens stop working immediately.

## Troubleshooting

| Message | What to do |
|---------|------------|
| "Phone calls need a Callin API key" | Create one in Callin → Profile → API Keys, then try again. |
| "No outbound Callin agent with a phone number" | Create an outbound agent and assign it a number. |
| "Call limit reached" | Wait up to an hour; the limit is 10 calls per hour. |
| The call fails right away | Check that the agent's number is active and that you have minutes left. |
| Callin doesn't appear in Claude's connector list | Use **Add custom connector** with the URL `https://claude-mcp.callin.io/mcp`. |
| Claude says you have no agents or calls | The connector may be connected to another Callin account. Disconnect it and connect again with the right account. |
| "Connection request expired" on the consent screen | Start the connection again from Claude. If it keeps happening, check that your browser isn't blocking cookies. |
